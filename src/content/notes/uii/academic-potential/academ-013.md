# What "figural pattern" items actually test

### 🟢 Lite — Quick Review (1h–1d)
> Rapid summary for last-minute revision before your exam.

**Figural sequence reasoning (penalaran figural)** asks you to find the rule binding a series of pictures and pick the image that continues it. The four attribute families to scan are: **shape**, **count of elements**, **colour/shading**, and **orientation** (rotation, reflection, translation). A correct solve names the rule in one sentence before looking at options.

| Attribute family | What to count or compare |
|---|---|
| Shape | sides, vertices, curve vs. straight |
| Count | number of dots/lines/symbols per cell |
| Colour/shading | black/white toggle, fill density |
| Orientation | rotation angle, mirror axis |

- The fastest solve eliminates options that violate **even one** of the tracked attributes.
- When two attributes shift in parallel, predict the **next pair** of values, then check the answer that carries both.

### 🟡 Standard — Regular Study (2d–2mo)
> Standard content for students with a few days to months.

#### What "figural pattern" items actually test
Item 13 of the UI Entrance *Academic Potential* (TPA) subtest groups all visual-reasoning items: a stem shows 3–5 figures, four answer choices follow, and exactly one choice obeys the same generative rule as the stem. The cognitive load is **rule induction under time**, not image recognition.

#### The four rule families
1. **Arithmetic on attributes.** A count increases by +1, +2 or by a fixed step; rotations climb by 45°/90°.
2. **Cycle / modulo.** A short pattern (A→B→C→A→B…) repeats across positions.
3. **Recursive transformation.** Each figure is built from the previous one by one operation (e.g., add one line and flip shading).
4. **Analogy mapping.** A is to B as C is to ?; the rule is transferred, not extended.

#### Worked relationship
Track **two attributes in parallel** when one attribute is ambiguous. Suppose a stem changes shading and line count together: position 1 = 3 lines/white, position 2 = 4 lines/black, position 3 = 5 lines/white. The next figure must have **6 lines and black fill**. Any option matching the line count but keeping the wrong shading is a designed distractor — eliminate it.

#### Quick reference table

| Rule type | Diagnostic cue | Time budget |
|---|---|---|
| Arithmetic | Counts visible at a glance | ≤60 s |
| Cycle | Same shapes reshuffled | ≤75 s |
| Recursive | Each figure resembles the prior | ≤90 s |
| Analogy | Two-figure stem repeated | ≤75 s |

#### Exam-level pointers
- Roughly 5–10 figural items appear per UI Entrance sitting; treat each as worth ≈3% of the section.
- Verbal sub-tests and numerical sub-tests share the same logic grammar — practice transfers.
- Mark and skip if no rule resolves within 90 s; return in the final review pass.

### 🔴 Extended — Deep Study (3mo+)
> Comprehensive coverage for students on a longer study timeline.

#### Edge cases examiners use
- **Superimposed figures.** Two layers stack; count symbols per layer, not in total, or you mis-read the rule.
- **Mixed-base cycles.** A 3-step colour cycle coexists with a 2-step rotation; only items tracking both survive.
- **Decoys that match shape but break orientation** — and the mirror pair, matching orientation but breaking shape.
- **Matrix completion (3×3).** The rule may run along rows **or** columns; checking one direction only is the classic fail.

#### Mechanism checklist (run in order)
1. List every attribute visible in frame 1.
2. Diff frames 1→2, 2→3, 3→4 to identify which attribute changed.
3. Confirm the change is consistent across at least two steps.
4. Predict frame 5; eliminate options violating the prediction on any attribute.

#### Adjacent-topic links
- Same rule-grammar drives verbal-analogy items in the TPA section — spotting A:B :: C:? follows the identical four-step mechanism.
- Numerical-series items use arithmetic and recursive subclasses verbatim; treat them as the numerical twin of figural patterns.

#### Common mistakes
- Anchoring on colour because it is the most salient pixel feature.
- Stopping after one rule is found; the real rule may sit on a second attribute.
- Forcing an arithmetic reading onto a cycle (or vice versa) when the data fits neither cleanly.

#### Practice prompts
1. A stem rotates a triangle 45° clockwise per step and adds one dot. Which option continues both rules simultaneously?
2. A 3×3 matrix has rows alternating two shapes; identify the missing cell by checking rows **and** columns before locking the answer.
