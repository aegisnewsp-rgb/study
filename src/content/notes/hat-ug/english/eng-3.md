# Analogies

### 🟢 Lite — Quick Review (1h–1d)
> Rapid summary for last-minute revision before your exam.

An analogy question gives a pair of words and asks you to find another pair that shares the **same type of relationship** (A : B :: C : D). On the HAT-UG English section, analogies appear as standard four-option MCQs and reward two skills: a working vocabulary and fast classification of the **stem pair's relationship**.

**Must-know relationship types**: **synonym** (Brave : Courageous), **antonym** (Hot : Cold), **part-of** (Wheel : Bicycle), **tool-for** (Pen : Write), **worker-tool** (Carpenter : Saw), **material-product** (Silk : Saree), **degree** (Warm : Hot), **cause-effect** (Virus : Disease), **sequence** (Seed : Tree), **male-female** (Bull : Cow), **young-adult** (Puppy : Dog), and **place** (Fish : Aquarium).

**Strategy**: name the relationship in plain English (e.g., "Pen is used to Write"), then test only the option whose words slot into the same sentence frame. Eliminate choices that merely share a topical word with the stem.

### 🟡 Standard — Regular Study (2d–2mo)
> Standard content for students with a few days to months.

#### What the test measures
Analogies measure **analogical reasoning** — perceiving how two words relate and transferring that same link to a new pair. Each HAT-UG item shows a stem pair (A : B) and four candidate pairs; only one preserves an **identical relational logic**.

#### Classifying the stem pair
Read the stem and assign a label before scanning options. Common labels:

| Label | Stem example | Sentence-frame check |
|---|---|---|
| Synonym | Happy : Joyful | A means the same as B |
| Antonym | Weak : Strong | A is the opposite of B |
| Part-of | Page : Book | A is a part of B |
| Whole-part | Book : Page | B is a part of A (direction matters) |
| Tool-for | Knife : Cut | A is used to do B |
| Worker-tool | Surgeon : Scalpel | A uses B to work |
| Material-product | Clay : Pot | B is made from A |
| Cause-effect | Drought : Famine | A results in B |
| Degree | Warm : Hot | B is a stronger form of A |
| Sequence | Egg : Butterfly | A precedes B in growth |
| Male-female | Lion : Lioness | A is male, B is female |
| Young-adult | Calf : Cow | A is the young of B |
| Place (habitat) | Eagle : Nest | B is the home of A |

#### The sentence-frame trick
Build a fill-in template such as *"______ is related to ______ in the same way that ______ is related to ______."* Plug the stem pair in, then try each option. The pair that makes the sentence read naturally with **the same relationship direction** wins.

#### Distractor logic
HAT-UG options are not random. A typical trap pair shares a topical word with the stem (e.g., for *Carpenter : Saw*, the trap *Carpenter : Wood* keeps the worker but changes the relationship from tool to material). Another trap flips direction (e.g., *Hand : Finger* instead of *Finger : Hand*). Naming the relationship in advance neutralises both traps.

### 🔴 Extended — Deep Study (3mo+)
> Comprehensive coverage for students on a longer study timeline.

#### Direction and grammatical parity
Two subtleties decide most ties on the HAT-UG. **First, direction**: *Author : Book* (creator-product) must not be matched with *Book : Author*; the production flow moves creator → output. **Second, grammatical parity**: if the stem is *noun : verb* (e.g., *Chef : Cook*), the answer should also be *noun : verb*, not *verb : noun*. Examiners exploit mismatched part-of-speech structures as silent distractors.

#### Multi-step and double relationships
Higher-difficulty items embed two linked links. For *Teacher : School :: Doctor : ?*, the path is *profession : workplace*, giving *Hospital*. For *Pen : Write :: Knife : ?*, the path is *tool : action it performs*, giving *Cut*. Always map the stem as a **chain** rather than a single label.

#### Common pitfalls
1. **Word-association bias**: picking an option because it *feels* related (e.g., choosing *Sun : Heat* for *Cause : Effect* even when the stem was actually a *part-whole* pair).
2. **Direction inversion**: confusing *part : whole* with *whole : part* — the order in the stem is sacred.
3. **Category substitution**: matching *Bird : Sparrow* with *Mammal : Whale* — both are category-member, but examine whether the *category breadth* matches.
4. **Ignoring intensity**: *Cold : Cool* is a degree pair; pairing it with *Hot : Warm* (the wrong direction of intensity) loses marks.

#### Worked micro-example
Stem: *Oar : Boat :: ?*
- Map stem: *Oar is the tool used to propel a Boat* → tool-for / part-of function.
- Option A *Paddle : Canoe* → tool used to propel a canoe ✔
- Option B *Boat : Oar* → direction flipped ✘
- Option C *Wood : Oar* → material-product ✘
- Option D *River : Boat* → place ✘

Answer: **A**.

2. *Puppy : Dog :: Calf : ?* (Cow)

#### Exam-specific strategy
The English section carries roughly 3% weight in HAT-UG; analogies cluster with vocabulary and verbal-reasoning items. Budget **45–60 seconds per analogy**: 10 s to label the stem, 25 s to test options against the sentence frame, 10 s to verify direction. Skip and return if the label is unclear — a fresh read often surfaces the link.
