# Algebra, Number and Structure — VCE Mathematical Methods (VCAA 2023) Notes

Algebra, number and structure is one of the four Areas of Study in VCE Mathematical Methods Units 3 and 4. The 2023 Study Design covers algebraic manipulation, exact values, indices, surds, logarithms, sequences and series, and the formal language of mathematical reasoning. The strand is assessed across both papers but is more heavily weighted in Examination 1.

### 🟢 Lite — Quick Review (1h–1d)

#### Core facts in one pass

- **Laws of indices.** a^m × a^n = a^(m+n). a^m / a^n = a^(m−n). (a^m)^n = a^(mn). a^0 = 1. a^(−n) = 1/a^n. a^(1/n) = ⁿ√a.
- **Laws of logarithms.** log(xy) = log x + log y. log(x/y) = log x − log y. log(x^n) = n log x. Change of base: log_a(x) = log_b(x)/log_b(a).
- **Surds.** √a × √b = √(ab). √(a/b) = √a/√b. Simplify by extracting square factors.
- **Sequences.** Arithmetic a_n = a + (n−1)d. Geometric a_n = ar^(n−1).
- **Series sums.** Arithmetic: S_n = n/2 (2a + (n−1)d). Geometric: S_n = a(1 − r^n)/(1 − r) for r ≠ 1.
- **Sum to infinity.** S_∞ = a/(1 − r) for |r| < 1.

#### Examiner traps

- Mixing up log(xy) and log(x + y) — log(xy) = log x + log y; log(x + y) cannot be simplified.
- Forgetting |r| < 1 for sum to infinity — for |r| ≥ 1 the sum diverges.
- Treating surds as approximate — surds are exact; keep in surd form unless the question asks for a decimal.

### 🟡 Standard — Regular Study (2d–2mo)

#### Indices

For a > 0, m, n ∈ ℝ: a^m × a^n = a^(m+n); a^m / a^n = a^(m−n); (a^m)^n = a^(mn); a^(−n) = 1/a^n; a^0 = 1; a^(1/n) = ⁿ√a; a^(m/n) = (ⁿ√a)^m.

#### Surds

A surd is an irrational root that cannot be simplified to a rational. √a × √b = √(ab). √(a/b) = √a/√b. Simplify by extracting square factors: √12 = √(4 × 3) = 2√3.

Rationalise the denominator: 1/√3 = √3/3. (a + √b)/(c + √d): multiply top and bottom by the conjugate (c − √d).

#### Logarithms

Log_a(b) = c means a^c = b. Laws: log(xy) = log x + log y; log(x/y) = log x − log y; log(x^n) = n log x. Change of base: log_a(b) = log_c(b)/log_c(a).

ln is the natural logarithm (base e). ln x is the inverse of e^x. ln 1 = 0, ln e = 1, ln(1/e) = −1.

#### Sequences

Arithmetic: a_n = a + (n − 1)d. Sum S_n = n/2 × (a + a_n) = n/2 × (2a + (n − 1)d).

Geometric: a_n = a r^(n−1). Sum S_n = a(1 − r^n)/(1 − r) for r ≠ 1.

Sum to infinity S_∞ = a/(1 − r) for |r| < 1.

Recurrence relation: a_(n+1) = r a_n + b gives a geometric sequence if b = 0, or a sequence converging to b/(1 − r) otherwise.

### 🔴 Deep — Long-Term Mastery (1mo–6mo)

#### Why Algebra underpins calculus and modelling

- **Solving equations.** Quadratic ax² + bx + c = 0 → x = (−b ± √Δ)/2a where Δ = b² − 4ac. Index equations: a^x = b → x = log b / log a. Log equations: log x = k → x = 10^k.
- **Exact values.** √2, √3, √5 are exact. π is exact. sin(π/6) = 1/2 is exact. Keep exact values unless told otherwise.
- **Rearrangement.** Many calculus and financial problems require rearranging an equation. Practice isolating variables.

#### Exam technique

- For "show that" questions, work step-by-step and reverse the working from the conclusion to verify.
- For "find all solutions" questions, give ALL solutions in the given interval.
- For "exact value" questions, never round intermediate steps.

#### Common misconceptions (and the correction)

- "log(x + y) = log x + log y." No — log(xy) = log x + log y. log(x + y) cannot be simplified.
- "log(−x) = log x." No — log is defined only for positive arguments.
- "Sum to infinity is finite for any r." Only for |r| < 1.
