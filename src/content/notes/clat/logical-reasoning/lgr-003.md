# Analogies

### 🟢 Lite — Quick Review (1h–1d)
> Rapid summary for last-minute revision before your exam.

An analogy in CLAT Logical Reasoning is a question of the form **A is to B as C is to ?**, where you must identify the relationship linking the first pair and locate the option that reproduces that same relationship for the second pair. The section carries roughly **3% weight** and yields 1–3 quick-mark questions per paper.

- Three formats appear: **word analogy** (semantic/functional relations), **letter analogy** (alphabet-shift patterns), and **number analogy** (arithmetic or digit patterns).
- The fastest solving move is to **name the relation first** (cause-effect, part-whole, tool-user, degree, category-member, male-female) and then eliminate options that break its direction.
- Letter analogies reward scanning for **positional shifts, reversals, and skip codes**; number analogies reward spotting the **AP/GP/square/cube/digit-sum rule** governing the first pair.

### 🟡 Standard — Regular Study (2d–2mo)
> Standard content for students with a few days to months.

#### How the relation is extracted

Every analogy stem hides one of about a dozen logical links. Lock onto the link between A and B, then require the option word (D) to share *the same* link with C. The colon-colon notation **A : B :: C : D** is read as "A relates to B in the same way C relates to D," so the **direction** matters: if A causes B, then C must cause D, not the reverse.

#### Common relation types tested

| Relation type | Example pair | Parallel for CLAT |
| --- | --- | --- |
| Cause : Effect | Rain : Flood | Exercise : Stamina |
| Tool : User | Needle : Tailor | Brush : Painter |
| Part : Whole | Wheel : Bicycle | Page : Book |
| Male : Female | Bull : Cow | Lion : Lioness |
| Degree | Warm : Hot | Cool : Cold |
| Synonym / Antonym | Bold : Brave | Happy : Joyful |

#### Solving routine

1. Read the stem pair aloud and **name the relation in one phrase** ("X produces Y," "Y contains X").
2. Check that the relation is **directional and consistent** — not symmetric.
3. Scan the four options, eliminate any that flip the direction, share a surface feature with the wrong relation, or use a different link.
4. Confirm the chosen option by **restating the analogy**: "C relates to D in the same way A relates to B."

> Trap: when two options seem defensible, pick the *more precise* parallel — the one whose link matches the stem pair exactly, not merely plausibly.

### 🔴 Extended — Deep Study (3mo+)
> Comprehensive coverage for students on a longer study timeline.

#### Edge cases examiners exploit

- **Multiple-defensible relations.** A pair like *knife : fruit* could map via function (peels) or tool-user (chef). CLAT expects the **most specific, primary function** of the stem item, so reject looser parallels even when grammatical.
- **Direction reversal.** *Teacher : School :: Doctor : ?* tempts students toward *Patient*, but the relational slot is the **workplace** (Hospital/Clinic), not the client.
- **Hidden letter patterns.** Skip-coding (A→C, B→E means +2 then +3), reverse-alphabet (Z→A), and positional swaps (e.g., 1st and 3rd letters interchanged) appear in two-three-question clusters each paper.
- **Number analogies with nested operations.** Watch for digit-sum combined with multiplication, e.g., 14 : 25 → 1×4=4, then 4²+9 = 25, mirrored for the target pair.

#### Worked micro-example

**Stem:** *Author : Book :: Choreographer : ?*
Options: (a) Stage, (b) Dance, (c) Music, (d) Theatre.
Relation = **creator : created work**. An author creates a book; a choreographer creates a dance. Answer: **(b) Dance**.

**Number stem:** *3 : 27 :: 4 : ?*
Recognise 3³ = 27; therefore 4³ = **64**.

#### High-yield practice prompts

1. Identify the relation type in *Pupil : Eye :: Petal : ?* and pick the most precise option among Leaf, Flower, Stem, Root.
2. Decode the letter analogy *AZ : BY :: CX : ?* and list two plausible decoys examiners might use.

> Exam strategy: analogies are 30–45 second items. Cap time at one minute; if undecided, trust the option whose **single-word relation label** matches the stem pair exactly.
