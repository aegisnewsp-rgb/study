# Functions and Graphs — H2 Mathematics (9758) Notes

Functions and Graphs is the first content strand a JC1 student meets in the H2 Mathematics 9758 syllabus. It covers domain and range, composite and inverse functions, transformations of graphs, the modulus function, and the natural exponential and logarithm. While Functions and Graphs is not the largest strand by marks, it underpins every other topic in the syllabus — calculus, vectors, complex numbers and statistics all use function notation and graph-reading skills. A weak start in Functions and Graphs cascades into every later topic.

### 🟢 Lite — Quick Review (1h–1d)

#### The seven facts every JC1 student needs

1. **Function**: a rule that assigns to every input exactly one output. f: A → B means f is a function from set A to set B.
2. **Domain**: the set of all valid inputs.
3. **Range**: the set of all outputs that actually occur.
4. **Composite function**: (f ∘ g)(x) = f(g(x)). The output of g is the input to f.
5. **Inverse function**: f⁻¹ is the function that undoes f. f⁻¹(f(x)) = x and f(f⁻¹(x)) = x. The domain of f⁻¹ is the range of f; the range of f⁻¹ is the domain of f.
6. **Modulus function**: |x| = x if x ≥ 0, |x| = −x if x < 0. The graph of y = |f(x)| reflects the part of y = f(x) below the x-axis to above it.
7. **Exponential and logarithm**: y = e^x and y = ln x are inverse functions. ln(ab) = ln a + ln b; ln(a/b) = ln a − ln b; ln(a^n) = n ln a.

#### Key notations

- f: A → B — f is a function from A to B
- f ∘ g or fg — the composite function
- f⁻¹ — the inverse function
- |x| — the modulus of x
- e — the base of natural logarithms (≈ 2.71828)
- ln x — the natural logarithm of x

### 🟡 Standard — Regular Study (2d–2mo)

#### Domain and range

The **domain** of a function is the set of all inputs for which the function is defined. For polynomial functions, the domain is all real numbers. For rational functions p(x)/q(x), the domain excludes the roots of q(x) (where the denominator is 0). For √f(x), the domain is where f(x) ≥ 0. For ln f(x), the domain is where f(x) > 0.

The **range** of a function is the set of all outputs that actually occur. To find the range, find the minimum (or maximum) value of the function; the range is then [min, ∞) or (−∞, max] for unbounded functions, or a closed interval for bounded functions.

For a quadratic f(x) = ax² + bx + c with a > 0, the range is [f(vertex), ∞); with a < 0, the range is (−∞, f(vertex)]. The vertex is at x = −b/(2a).

#### Composite and inverse functions

**Composite function** (f ∘ g)(x) = f(g(x)). The composite is built by applying g first, then applying f to the result.

**Inverse function** f⁻¹ is the function that undoes f. f⁻¹(f(x)) = x for every x in the domain of f. f(f⁻¹(x)) = x for every x in the domain of f⁻¹.

To find f⁻¹ from the formula of f: replace f(x) with y, swap x and y, and solve for y. The resulting formula is f⁻¹.

The graph of f⁻¹ is the reflection of the graph of f in the line y = x.

A function has an inverse only if it is one-to-one (every output is produced by exactly one input). If a function is not one-to-one on its whole domain, restrict the domain to a region where it is one-to-one, then define the inverse on that region.

#### Transformations of graphs

Four basic transformations apply to any function y = f(x):

- **Vertical translation**: y = f(x) + a translates the graph up by a.
- **Horizontal translation**: y = f(x + a) translates the graph left by a.
- **Vertical stretch**: y = a f(x) stretches the graph vertically by a factor of a.
- **Horizontal stretch**: y = f(ax) compresses the graph horizontally by a factor of 1/a.

Reflections:

- y = −f(x) reflects in the x-axis.
- y = f(−x) reflects in the y-axis.

For multiple transformations, apply them in the order specified (or work from the inside out for composite transformations like y = a f(b(x + c)) + d).

#### Modulus function

The modulus function is |x| = x if x ≥ 0, |x| = −x if x < 0. The graph of y = |x| is the V-shape with vertex at the origin.

For a general function y = f(x), the graph of y = |f(x)| reflects the part of y = f(x) below the x-axis to above it. The graph of y = f(|x|) takes the right-hand side of y = f(x) and reflects it to the left.

Solving |f(x)| = a (for a > 0) gives the same solutions as f(x) = a and f(x) = −a.

#### Exponential and logarithmic functions

The **natural exponential** y = e^x is defined for all real x, with range (0, ∞). It passes through (0, 1) and grows without bound as x → ∞.

The **natural logarithm** y = ln x is defined for x > 0, with range all real numbers. It passes through (1, 0) and grows without bound (slowly) as x → ∞.

e^x and ln x are inverse functions: e^(ln x) = x and ln(e^x) = x.

Logarithm laws:

- ln(ab) = ln a + ln b
- ln(a/b) = ln a − ln b
- ln(a^n) = n ln a
- ln 1 = 0, ln e = 1

Equations involving exponentials and logarithms can be solved by taking the ln of both sides (or by using the change-of-base formula).

### 🔴 Deep — Long-Term Mastery (1mo–6mo)

#### Where Functions and Graphs appears across the H2 Mathematics papers

- **H2 Mathematics 9758 Paper 1**: functions and graphs items appear as short structured items on domain/range, inverse functions, and graph transformations. The functions-and-graphs content also feeds into calculus (chain rule with composite functions, related rates, optimisation) and into complex numbers (transformations of the Argand diagram).
- **H2 Mathematics 9758 Paper 3**: modulus-function and transformation items can appear as HL-extension content on Paper 3.
- **Across the papers**: drawing the original graph and then drawing each transformation step-by-step is the highest-leverage exam technique for graph-transformation items.

#### Common misconceptions (and the correction)

- "The domain is all real numbers." It depends on the function. For ln f(x), the domain is where f(x) > 0; for √f(x), the domain is where f(x) ≥ 0; for 1/f(x), the domain excludes where f(x) = 0.
- "f⁻¹(x) = 1/f(x)." The inverse function is NOT the reciprocal. f⁻¹ is the function that undoes f; 1/f(x) is the reciprocal function.
- "y = f(x + a) translates right by a." It translates LEFT by a. The sign of the shift is opposite to the sign of a.
- "y = a f(x) stretches by a when a is between 0 and 1." A factor a between 0 and 1 is a COMPRESSION, not a stretch. The graph becomes closer to the x-axis.
- "ln(x²) = 2 ln x." This is true only for x > 0; for x < 0, ln(x²) = 2 ln |x|.

#### Exam technique

- For domain / range questions, state the rule you are using (no-zero denominator, non-negative radicand, positive argument for log) before applying it.
- For inverse-function questions, show the swap (x ↔ y) step explicitly. The swap is the method mark.
- For graph-transformation questions, draw the original graph first, then apply each transformation in order. The original graph is the method mark.
- For exponential / logarithmic equations, take ln of both sides before algebraic manipulation. The ln step is the method mark.
