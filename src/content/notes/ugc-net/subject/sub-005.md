# Theories and Models

### 🟢 Lite — Quick Review (1h–1d)
> Rapid summary for last-minute revision before your exam.

A **theory** is a testable explanatory system linking concepts through verified propositions, while a **model** is a simplified representation (diagram, analogy, or schema) that makes a phenomenon easier to analyse without being fully tested. UGC NET Paper 1 tests four families: learning theories, models of teaching, motivation theories, communication models, and research paradigms.

| Concept | One-line distinction | Author / Year |
|---|---|---|
| Theory | Verified explanatory system | Varies by domain |
| Model | Simplified representation / analogy | Varies by domain |
| Hypothesis | Tentative, testable prediction | Research method term |
| Paradigm | Underlying worldview guiding research | Kuhn, 1962 |

- **Behaviourism** → stimulus-response (Skinner, Pavlov, Thorndike).
- **Cognitivism** → mental schemas, information processing (Piaget, Bruner).
- **Constructivism** → learners build knowledge via experience (Vygotsky, Piaget).
- **Connectivism** → learning occurs through networks (Siemens, Downes).

> 💡 **High-Yield Memory Hook:** "**B-C-C-H**" — **B**ehaviourist, **C**ognitivist, **C**onstructivist, **H**umanistic/Connectivist. Pair with the acronym "**M-B-H**" for motivation: **M**aslow, **B**runer-wrong-trap, **H**erzberg + McClelland.

### 🟡 Standard — Regular Study (2d–2mo)
> Standard content for students with a few days to months.

#### Core Distinction: Theory vs Model vs Hypothesis
A **theory** integrates multiple hypotheses that have survived empirical testing; a **model** can be a precursor or parallel representation that organises variables without requiring full verification (e.g., Shannon-Weaver is a model, not a theory of communication). A **hypothesis** is a single falsifiable statement; a **construct** is an abstract variable not directly measurable (e.g., "intelligence", "anxiety").

#### Models of Instruction

| Model | Originator | Core Mechanism | Order/Structure |
|---|---|---|---|
| Nine Events of Instruction | Robert Gagne | Instructional events activating internal processes | Attention → Objective → Recall → Present → Guide → Elicit → Feedback → Assess → Retain/Transfer |
| Three Modes of Representation | Jerome Bruner | Movement from action to abstraction | Enactive → Iconic → Symbolic |
| Revised Bloom's Taxonomy | Bloom (1956); Anderson & Krathwohl (2001) | Cognitive skill hierarchy | Remember → Understand → Apply → Analyse → Evaluate → Create |

- Bruner's **spiral curriculum** returns to the same concept at progressively deeper levels.
- Gagne's events are **prescriptive** for lesson design; Bloom's taxonomy is **descriptive** of cognitive outcomes.
- **Andragogy** (Knowles) addresses adult learners; **Heutagogy** focuses on self-determined learning.

#### Concept Comparison Matrix — Communication Models

| Model | Direction | Feedback Loop | Key Limitation |
|---|---|---|---|
| Shannon-Weaver (1949) | Linear (one-way) | Absent | No receiver feedback; noise distorts signal |
| Schramm / Osgood (1954) | Circular | Yes — each participant encodes and decodes | Field-of-experience overlap required |
| Berlo (1960) | Linear | Absent | Source-Message-Channel-Receiver with communication skills, attitudes, knowledge, social system |
| Newcomb (1953) | Triadic, balanced | A-B-X with symmetry pressure | Limited to small-group symmetry |

> 📌 **Formula Check:** A linear model transmits information **one way**; a circular model requires **mutual encoding-decoding**. If the diagram shows an arrow returning to the source, it is NOT Shannon-Weaver.

#### Motivation Theories

| Theorist | Theory | Need Categories |
|---|---|---|
| Maslow (1943) | Hierarchy of Needs | Physiological → Safety → Belonging → Esteem → Self-Actualisation (pyramid, self-actualisation at TOP) |
| Herzberg (1959) | Two-Factor | Motivators (achievement, recognition, work itself) vs Hygiene (salary, policy, supervision) |
| McClelland (1961) | Needs Theory | Achievement, Affiliation, Power — acquired through culture |
| Vroom (1964) | Expectancy Theory | Effort → Performance → Reward → Valence |

- Maslow's later writings added **cognitive and transcendence** needs above self-actualisation.
- Herzberg's hygiene factors **prevent dissatisfaction** but do not motivate; motivators **create satisfaction**.

#### Research Paradigms and Variables

- **Positivism** → quantitative, deductive, objective reality, hypothesis testing.
- **Post-positivism** → critical realism, modified hypothetico-deductive method.
- **Interpretivism** → qualitative, inductive, subjective meaning-making.
- **Pragmatism** → mixed methods, problem-centred.
- **Critical Theory** → emancipation, power analysis (Habermas, Freire).

| Variable Type | Role in Study | Example |
|---|---|---|
| Independent | Manipulated cause | Teaching method |
| Dependent | Measured effect | Test score |
| Moderating | Changes strength of IV→DV | Student prior knowledge |
| Mediating | Explains mechanism | Self-efficacy |
| Extraneous / Control | Confounding, held constant | Room temperature |

#### 🎯 Exam-Level Worked Problem
**Question:** A researcher finds that the Shannon-Weaver (1949) model fails to capture classroom interaction because there is no path for student responses back to the teacher. Which communication model should the researcher adopt to incorporate two-way feedback, and who originally proposed the circular encoder-decoder version?

(A) Berlo's SMCR model — David Berlo
(B) Schramm-Osgood model — Wilbur Schramm and Charles Osgood
(C) Newcomb's A-B-X model — Theodore Newcomb
(D) Lasswell's model — Harold Lasswell

#### Solution:
1. Identify the requirement: **two-way feedback** with **encoder-decoder role-switching** between participants.
2. Eliminate Berlo (linear, no feedback) and Lasswell (linear "who-says-what-to-whom").
3. Newcomb's A-B-X is triadic and balanced but oriented toward symmetry, not pure two-way encoding.
4. The Schramm-Osgood (1954) model explicitly states that **every participant is both encoder and decoder**, creating a circular feedback loop contingent on overlapping fields of experience.
5. **Correct answer: (B) Schramm-Osgood model — Wilbur Schramm and Charles Osgood.**

> ⚠️ **Examiner Trap:** Students frequently mark Shannon-Weaver as "two-way" because it lists "destination" at the end — but the model has **no return arrow**. Any communication diagram with a feedback loop pointing back to the source is **not** Shannon-Weaver.

### 🔴 Extended — Deep Study (3mo+)
> Comprehensive coverage for students on a longer study timeline.

#### Paradigmatic Edge Cases and Boundary Conditions

| Edge Case | Why It Trips Candidates | Correct Treatment |
|---|---|---|
| Bruner vs Piaget attribution | Bruner's modes are action-image-symbol; Piaget's stages are sensorimotor-preoperational-concrete-formal | Modes ≠ Stages; different authors |
| Self-Actualisation at base | Pyramid diagrams may be flipped in low-quality reproductions | Self-Actualisation is at the **top**, not the base |
| Bloom's author confusion | Anderson & Krathwohl revised it (2001) | Original 1956 taxonomy = Bloom; revision = Anderson-Krathwohl |
| Hypothesis as fact | Hypothesis is **tentative**, not proven | Use "testable proposition" wording |
| Connectivism's scope | Sometimes labelled a learning **theory**, sometimes a **model** | Treat as a learning **theory** for UGC NET purposes |
| Herzberg hygiene = motivator | Hygiene factors only neutralise dissatisfaction | Only motivators drive satisfaction |
| Bruner spiral = repetition | Spiral curriculum revisits topics at **greater depth** | Not mere repetition |
| Positivism = qualitative | Positivism is **quantitative**; Interpretivism is qualitative | Match paradigm to method |

#### Gagne's Events — Conditions and Limits
- Events 1–3 (attention, objective, recall) prepare learners.
- Events 4–6 (present, guide, elicit) constitute the **active instructional phase**.
- Events 7–9 (feedback, assess, retain/transfer) handle **consolidation**.
- Gagne's model assumes **hierarchical learning** — lower capabilities must be in place before higher-order skills are taught.
- Limitation: the model is **prescriptive**, not descriptive of how learners actually behave; it does not account for socio-cultural context the way Vygotsky's ZPD does.

#### Connections to Adjacent Topics

- **Zone of Proximal Development** (Vygotsky) → scaffolding → Gagne's "provide learning guidance."
- **Operant Conditioning** (Skinner) → reinforcement schedules → motivation theory overlap.
- **Cognitive Load Theory** (Sweller) → information-processing limits in Gagne's recall event.
- **Action Research** (Lewin) → links to interpretivism and critical theory in research methodology.
- **Kirkpatrick Model** (training evaluation) → reaction, learning, behaviour, results — tested alongside models of teaching.

#### Advanced Practice Prompts

1. **Application question:** A primary school teacher introduces fractions using physical strips, then drawings, then numerals. Map this sequence to Bruner's three modes and justify why the spiral return to fractions in Class 4 is not redundant revision but a deliberate cognitive upgrade.
2. **Paradigm-selection question:** A PhD scholar wants to study how tribal communities interpret seasonal festivals. Identify the appropriate paradigm, justify your choice against positivism, and state the type of reasoning (inductive / deductive) the study would employ.

> 📌 **Formula Check:** Deduction moves theory → data; induction moves data → theory. Positivism = deductive, Interpretivism = inductive, Pragmatism = either or both.
