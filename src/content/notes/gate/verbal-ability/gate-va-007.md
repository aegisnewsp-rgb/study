# Analogy

### 🟢 Lite — Quick Review (1h–1d)
> Rapid summary for last-minute revision before your exam.

Analogy items in GATE Verbal Ability use the format **A:B :: C:D**. The job is to find a pair (C:D) whose logical relation to each other exactly mirrors the relation between A and B. GATE's GA section carries roughly 7 marks total, of which analogy contributes 1–2 questions.

- **One-step relation**: synonym, antonym, tool–user, worker–workplace, animal–young one, part–whole, cause–effect, function, degree.
- **Direction matters**: *parent : offspring* is not the same as *offspring : parent*.
- **Substitution check**: replace A with C in the relation; if B and D come out parallel, the pair is correct.
- **Trap to avoid**: same thematic category (e.g., both about professions) ≠ same relation.

### 🟡 Standard — Regular Study (2d–2mo)
> Standard content for students with a few days to months.

#### What an analogy tests
An analogy item asks you to abstract the *relation* holding between two given words and locate that same relation in one of four options. GATE item stems look like **"Pen : Writer :: Scalpel : ?"** — the operative shape is *tool : user*, so the answer is *Surgeon* (or *Doctor*), not *Hospital*.

#### The solving method
1. Pin down the precise relation in the given pair (be specific — *animal : sound* is different from *animal : young one*).
2. Formulate the relation as a phrase: "A is the **tool** used by B".
3. Apply that phrase to C and check whether D in each option completes it the same way.
4. Eliminate distractors that share surface vocabulary or category with the stem.

#### Relation types GATE recycles

| Relation type | Example pair (A:B) | Cue phrase |
| --- | --- | --- |
| Synonym | Brave : Courageous | A means B |
| Antonym | Hot : Cold | A is opposite of B |
| Part : Whole | Wheel : Cart | A is a part of B |
| Tool : User | Pen : Writer | A is used by B |
| Worker : Workplace | Nurse : Hospital | B is where A works |
| Animal : Young one | Cow : Calf | B is the offspring of A |
| Cause : Effect | Rain : Flood | A causes B |
| Function | Knife : Cut | B is what A does |

> **Tip**: before reading the options, state the relation aloud in one sentence. Candidates that fit a *different* relation (e.g., function vs. tool–user) will then be obvious rejects.

### 🔴 Extended — Deep Study (3mo+)
> Comprehensive coverage for students on a longer study timeline.

#### Direction, multi-step, and degree
Relations in GATE are not always single-step. *Finger : Hand :: Atom : Molecule* is **part : whole** at two scales — finger is a part of hand, atom is a part of molecule. Missing the second scale is a classic source of wrong marks. Degree-based pairs (*Hot : Warm :: Tall : Medium*) require matching the *intensity gradient*, not the category.

#### Common traps examiners set
- **Surface-category bait**: "Doctor : Hospital :: Teacher : ?" — distractors like *Student* or *Book* share the school domain but break the *worker : workplace* relation; the correct answer must be a workplace (e.g., *School*).
- **Reversed direction**: *King : Queen :: Man : ?* is *sex : opposite sex*, so answer is *Woman*, not *Boy*.
- **Grammatical mismatch**: ignoring that the correct option must keep the same number, gender, and part of speech — *offspring* (singular) ≠ *children* (plural).

#### Mini practice
1. *Book : Library :: Painting : ?* — relation is *object : place where stored/displayed*; answer: *Gallery* (or *Museum*).
2. *Pupil : Eye :: Petal : ?* — relation is *part of a whole organ/structure*; answer: *Flower*.

#### Exam strategy for GA
Analogy sits in GATE's General Aptitude section (common to all streams), contributing about 2% of total marks. Items are typically 1-mark MCQs solvable in 30–45 seconds. Solve them in the first pass — they are the lowest time-cost questions on the paper, and freeing up minutes here pays off in Technical and Quantitative Aptitude.

> **Tip**: if two options seem equally defensible, re-state the relation more narrowly (e.g., from *associated with* to *used by*). The narrower reading usually leaves one survivor.
