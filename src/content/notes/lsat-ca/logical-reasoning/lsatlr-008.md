# Conditional Reasoning and Logical Patterns — LSAT Logical Reasoning

Conditional reasoning is the formal-logic backbone of many LSAT Logical Reasoning items. The LSAT tests translation of conditional statements ("if...then," "only if," "unless"), the contrapositive, and syllogistic patterns. Mastering conditional reasoning unlocks many otherwise-tricky items.

### Lite — Quick Review (1h-1d)

#### Translating conditionals

- **"If P, then Q":** P → Q. P is sufficient for Q; Q is necessary for P.
- **"P only if Q":** P → Q. Same as "if P, then Q."
- **"Q if P":** P → Q.
- **"All P are Q":** P → Q (universal affirmative).
- **"No P are Q":** P → not Q.
- **"Some P are Q":** some P are Q (existential; cannot be translated as P → Q).
- **"Unless":** "P unless Q" = if not Q, then P = Q → P. The "unless" introduces the negation.

#### The contrapositive

The contrapositive of "if P, then Q" is "if not Q, then not P." The contrapositive is logically equivalent to the original.

#### Common valid forms

- **Modus ponens:** P → Q. P. Therefore Q.
- **Modus tollens:** P → Q. Not Q. Therefore not P.

#### Common invalid forms

- **Affirming the consequent:** P → Q. Q. Therefore P. (Invalid.)
- **Denying the antecedent:** P → Q. Not P. Therefore not Q. (Invalid.)

#### One-pass drill

1. Translate each conditional in the passage to "if P, then Q" form.
2. Identify the contrapositive for each.
3. Apply modus ponens or modus tollens to derive new statements.

#### Examiner traps

- Confusing "P only if Q" with "P if Q." "P only if Q" = P → Q. "P if Q" = Q → P.
- Treating "unless" as "if not." "P unless Q" = if not Q, then P.
- Confusing the contrapositive with the inverse. The inverse (if not P, then not Q) is not equivalent.

### Standard — Regular Study (2d-2mo)

#### Strategy for conditional reasoning items

1. **Translate each conditional** to "if P, then Q" form.
2. **Identify the contrapositive** for each.
3. **Draw a chain of conditionals** if multiple statements are linked.
4. **Apply modus ponens or modus tollens** to derive new statements.
5. **Match the derivation to the answer choice.**

#### Conditional chains

If P → Q and Q → R, then P → R. Conditional chains allow chaining through intermediate steps.

#### Necessary and sufficient conditions

- **Sufficient condition:** P is sufficient for Q if P guarantees Q.
- **Necessary condition:** Q is necessary for P if Q must be true whenever P is true.

#### Practice routine

- Take 10 conditional reasoning items. For each, translate all conditionals to P → Q form.
- Draw the chain of conditionals. Apply modus ponens or modus tollens.
- Time yourself: under 1.5 minutes per item.

### Deep — Long-Term Mastery (1mo-6mo)

#### How conditional reasoning connects to the other LR skills

- **Assumption items** often require identifying the missing link in a conditional chain.
- **Strengthen/weaken items** may involve conditionals; translation is the first step.
- **Parallel reasoning items** often match conditional structures.

#### Common errors and the correction

- **"P only if Q means P → Q."** Correct. "P only if Q" = "if P, then Q" = P → Q.
- **"P if Q means P → Q."** Incorrect. "P if Q" = "if Q, then P" = Q → P.
- **"Unless is the same as if."** "P unless Q" = "if not Q, then P." The "unless" introduces the negation.

#### Exam technique

- For conditional reasoning items, translate all conditionals to "if P, then Q" form.
- Draw the chain. Apply modus ponens or modus tollens.
- Match the derivation to the answer choice.
- Use the platform's flag-for-review function for items you cannot answer.
