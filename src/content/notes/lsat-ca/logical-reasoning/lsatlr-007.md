# Parallel Reasoning and Analogous Arguments — LSAT Logical Reasoning

Parallel reasoning items ask the test-taker to identify an argument that has the same logical structure as the one in the passage, even if the topic is completely different. The skill is focusing on the form of the argument, not the content.

> Verify the live section count, item count, and any in-year changes on https://www.lsac.org/ before planning around the figures below.

---

### Lite — Quick Review (1h-1d)

#### What parallel reasoning items test

- The structure of the original argument.
- The relationship between premises and conclusion.
- The same structure in a new context.

#### One-pass drill

1. Identify the structure of the original argument (analogy, causation, generalisation, etc.).
2. Identify the premises and the conclusion in the original.
3. For each choice, identify its structure.
4. Pick the choice with the same structure.

#### Examiner traps

- Picking a choice with a similar topic but different structure. Structure matters more than topic.
- Picking a choice with a similar structure but a different flaw. The match must include the flaw (or lack of flaw).
- Missing a subtle difference in quantifiers (all, most, some).

---

### Standard — Regular Study (2d-2mo)

#### Strategy for parallel reasoning items

1. **Describe the original argument** in one sentence: "Premise 1 [type]. Premise 2 [type]. Therefore conclusion [type]."
2. **For each choice, do the same description.**
3. **Match the structure,** not the content.

#### Common structures to match

- **Deductive:** if all X are Y, and Z is X, then Z is Y. Match the categorical form.
- **Inductive:** if most X are Y, and Z is X, then Z is probably Y. Match the probabilistic form.
- **Analogical:** X has properties A, B, C. Y has properties A, B. Therefore Y has property C. Match the analogy.
- **Causal:** A preceded B. Therefore A caused B. Match the causal reasoning.
- **Conditional:** if P then Q. P. Therefore Q. Match the conditional form.

#### Practice routine

- Take 10 parallel reasoning items. For each, describe the original argument in one sentence.
- For each choice, describe it in one sentence. Compare.
- Time yourself: under 2 minutes per item (parallel reasoning items take longer).

### Deep — Long-Term Mastery (1mo-6mo)

#### How parallel reasoning items connect to the other LR skills

- **Method items** ask for the structure; parallel reasoning items match the structure.
- **Flaw items** ask what is wrong with the structure; parallel reasoning items match the same flawed structure.
- **Conditional reasoning items** require the same translation and application.

#### Common errors and the correction

- **"Topic match is enough."** Topic match is not enough; structure must match.
- **"Some means most."** Some, most, and all are different quantifiers. Match the exact quantifier.
- **"Affirming the consequent is the same as modus ponens."** Affirming the consequent (P → Q, Q, therefore P) is invalid; modus ponens (P → Q, P, therefore Q) is valid.

#### Exam technique

- For parallel reasoning items, describe the original argument's structure first.
- Match the structure in the choices, not the topic.
- Use the platform's flag-for-review function for items you cannot answer.
