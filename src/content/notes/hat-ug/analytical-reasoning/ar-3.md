# Coding-Decoding

### 🟢 Lite — Quick Review (1h–1d)
> Rapid summary for last-minute revision before your exam.

Coding-Decoding tests whether you can spot a fixed rule that turns a word, number, or symbol into a "code" and then either reverse it or apply it to a new item. HAT-UG usually asks 1–2 questions in Analytical Reasoning (≈4% weight), solvable in under a minute once the pattern clicks.

- **Positional arithmetic:** A=1, B=2 … Z=26. A forward shift of +3 turns CAT (3,1,20) into FDW (6,4,23).
- **Opposite-letter rule:** opposite of letter at position *n* is letter at position **27 − n** (so D ↔ W, M ↔ N).
- **Number coding:** look for +k, −k, ×k, square, or digit-reversal patterns applied identically across terms.

**High-yield tip:** before calculating, write both the original and coded values side-by-side and check whether the difference is constant, mirrored, or conditional on letter type.

### 🟡 Standard — Regular Study (2d–2mo)
> Standard content for students with a few days to months.

#### The Three Master Rules

Every coding question in HAT-UG reduces to one of three underlying rules. Detecting which one is in play takes roughly 30 seconds; the arithmetic afterwards is mechanical.

1. **Direct (forward) shift** — each letter moves a fixed number of steps forward or backward along A=1…Z=26.
2. **Mirror / opposite-letter** — each letter is replaced by its mirror across the alphabet midpoint, position becomes **27 − n**.
3. **Conditional** — the rule changes depending on whether the letter is a vowel, a consonant, or a particular position (first/middle/last).

#### Worked Relation: Mirror Table

| Original position (n) | Opposite position (27 − n) | Letter pair |
| --- | --- | --- |
| 1 | 26 | A ↔ Z |
| 2 | 25 | B ↔ Y |
| 5 | 22 | E ↔ V |
| 13 | 14 | M ↔ N |
| 14 | 13 | N ↔ M |

Decoding the codeword VHF means each letter maps back: V → E, H → S, F → U → **ESU**.

#### Numeric Coding Patterns

- **Constant offset:** 4, 9, 16 → 7, 12, 19 (each +3).
- **Square pattern:** 2, 3, 4 → 4, 9, 16.
- **Digit reversal:** 23, 47, 81 → 32, 74, 18.
- **Sum of digits:** 142 → 1+4+2 = 7 → next 7×3 = 21.

Always check all four patterns before committing — HAT-UG frequently mixes one numeric and one letter pattern in the same question.

### 🔴 Extended — Deep Study (3mo+)
> Comprehensive coverage for students on a longer study timeline.

#### Edge Cases and Traps

Conditional coding is where marks are lost. A typical HAT-UG item encodes "vowels shifted +2, consonants shifted −2", so KITE becomes (I+2, J−2, G+2, E−2) = **IGHW**. Students who apply a uniform shift will get a wrong option that looks plausible.

For reverse coding — where the coded word is given and the original must be recovered — the inverse of every operation must be applied: +3 becomes −3, ×4 becomes ÷4, reversal becomes reversal again. A frequent trap is treating mirror coding as ordinary shift coding; remember the formula is **27 − n**, not 26 − n, because the alphabet has 26 letters but positions run 1 to 26.

| Mistake | Why it fails | Correct move |
| --- | --- | --- |
| Apply uniform shift to a conditional code | Vowels and consonants use different offsets | Split letters into two groups first |
| Use 26 − n for mirror pairs | Off-by-one for M and N | Use **27 − n** |
| Stop after first arithmetic step in number code | Multi-step rules exist | Verify each coded value, not just the first |

#### Connection to Adjacent Topics

Coding-Decoding shares its alphabet-index engine with **Number Series** and **Analogy** problems. Fluency with A=1…Z=26 arithmetic accelerates all three. Symbol coding (★, ◆, ▲ standing in for letters) uses the same detection logic but removes the alphabet anchor — pattern detection must come purely from positional correspondence.

#### Practice Prompts

1. If HOUSE is coded as IPVTF, decode LOGIC using the same rule.
2. In a number series 3, 6, 11, 18, 27 → 6, 9, 14, 21, 30, identify the rule and code 45.
