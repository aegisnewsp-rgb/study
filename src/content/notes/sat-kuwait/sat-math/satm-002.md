# Heart of Algebra — Functions and Function Notation — SAT Math Notes

Functions and function notation are part of the SAT Math Heart of Algebra content domain. The SAT tests interpreting and using function notation, evaluating functions, the language of functions (input, output, domain, range), linear and piecewise functions, and composing functions.

> Verify the live SAT specifications on https://satsuite.collegeboard.org/ before planning revision.

---

### 🟢 Lite — Quick Review (1h–1d)

#### Core facts in one pass

- **Function:** a rule that assigns each input x in the domain to exactly one output f(x).
- **Function notation:** f(x) means "the value of f at x."
- **Domain:** the set of all allowed x values.
- **Range:** the set of all possible f(x) values.
- **Linear function:** f(x) = mx + b; graph is a straight line.
- **Piecewise function:** different formulas for different parts of the domain.
- **Composition:** f(g(x)) = (f ∘ g)(x) means apply g first, then f.

#### Examiner traps

- Confusing f(g(x)) with f(x)g(x).
- Treating piecewise functions as ordinary functions.

### 🟡 Standard — Regular Study (2d–2mo)

#### Evaluating functions

To evaluate f(x) at a specific value:

1. Substitute the value for x in the formula.
2. Simplify.

Example: f(x) = 2x + 3. f(4) = 2(4) + 3 = 11.

#### Domain and range

Domain is the set of all allowed x values. For most functions, the domain is all real numbers. For functions with a denominator, exclude values that make the denominator zero. For functions with a square root, exclude values that make the radicand negative.

Range is the set of all possible f(x) values. For linear functions, the range is all real numbers. For quadratic functions, the range depends on the vertex and direction.

#### Function composition

f(g(x)) = (f ∘ g)(x) means apply g first, then apply f to the result.

Example: f(x) = 2x + 1, g(x) = x². f(g(3)) = f(9) = 2(9) + 1 = 19.

### 🔴 Deep — Long-Term Mastery (1mo–6mo)

#### Where Functions and Function Notation appears across the SAT Math section

Functions and function notation items appear throughout the SAT Math section. They test the candidate's ability to work with functions algebraically and graphically.

#### Common misconceptions (and the correction)

- "f(g(x)) = g(f(x))." No — composition is not commutative in general.
- "All functions are continuous." No — piecewise functions can have jumps.

#### Exam technique

- For evaluation, substitute carefully.
- For domain, exclude values that make denominators zero or radicands negative.
- For composition, apply the inner function first.
