# Functions and Graphs — Kuwait Secondary Certificate Mathematics Notes

Functions and Graphs is the sixth terminal-level domain at the Kuwait Secondary Certificate. The Kuwait MOE Mathematics curriculum covers domain and range, linear, quadratic, exponential, logarithmic and trigonometric functions, transformations, inverse functions, and graph interpretation in applied problems.

> Verify the live terminal paper pattern and the 2026/2027 tracks regulation on https://www.moe.edu.kw/ before planning revision.

---

### 🟢 Lite — Quick Review (1h–1d)

#### Core facts in one pass

- **Function:** a rule that assigns each input x in the domain to exactly one output f(x).
- **Domain:** the set of all allowed x values. **Range:** the set of all possible f(x) values.
- **Linear function:** f(x) = mx + b; graph is a straight line with slope m and y-intercept b.
- **Quadratic function:** f(x) = ax² + bx + c; graph is a parabola opening up (a > 0) or down (a < 0).
- **Exponential function:** f(x) = aˣ where a > 0 and a ≠ 1; passes through (0, 1); grows without bound if a > 1, decays to 0 if 0 < a < 1.
- **Logarithmic function:** f(x) = log_a x is the inverse of aˣ; defined for x > 0.
- **Inverse functions:** f and f⁻¹ satisfy f(f⁻¹(x)) = x and (f⁻¹ ∘ f)(x) = x. The graph of f⁻¹ is the reflection of f across y = x.

#### Examiner traps

- Forgetting that log x is only defined for x > 0 — any item with log(x + 5) needs x > −5 in the domain.
- Confusing f(g(x)) (composition) with f(x)g(x) (multiplication).
- Treating all transformations as vertical shifts — horizontal shifts act in the opposite direction to what the sign suggests.

### 🟡 Standard — Regular Study (2d–2mo)

#### Linear functions

The graph of f(x) = mx + b is a straight line with slope m and y-intercept b. To find where the line crosses the x-axis, set f(x) = 0 and solve: x = −b/m (when m ≠ 0). The slope between two points (x₁, y₁) and (x₂, y₂) is (y₂ − y₁) / (x₂ − x₁).

#### Quadratic functions

The graph of f(x) = ax² + bx + c is a parabola with vertex at x = −b/2a, y = f(−b/2a). The parabola opens up if a > 0 (minimum at the vertex) and opens down if a < 0 (maximum at the vertex). The y-intercept is c. The x-intercepts (if any) are at x = (−b ± √(b² − 4ac)) / 2a.

#### Exponential functions

The function f(x) = aˣ satisfies f(x + y) = aˣ × aʸ, f(x − y) = aˣ / aʸ, and f(0) = 1. The natural exponential f(x) = eˣ is the exponential where the rate of change equals the function value (df/dx = f).

The compound interest formula A = P(1 + r/n)^(nt) is exponential growth with P the principal, r the annual rate, n the number of compounding periods per year, t the years.

#### Logarithmic functions

The function f(x) = log_a x satisfies log_a(xy) = log_a x + log_a y, log_a(x/y) = log_a x − log_a y, and log_a(xⁿ) = n log_a x. The natural logarithm log_e x = ln x is the inverse of eˣ. The change-of-base formula: log_a x = ln x / ln a.

#### Trigonometric functions

f(x) = sin x is periodic with period 2π, oscillates between −1 and 1, and is zero at integer multiples of π. f(x) = cos x is the same shape, shifted left by π/2. f(x) = tan x is periodic with period π, undefined at π/2 + kπ, and asymptotes there.

#### Function composition and inverse

The composition f(g(x)) = (f ∘ g)(x) is computed by applying g first, then f. The composition is defined only when the range of g is contained in the domain of f.

A function f has an inverse f⁻¹ iff it is one-to-one (every output has exactly one input). The inverse is found by swapping x and y and solving for y. The graph of f⁻¹ is the reflection of the graph of f across the line y = x.

#### Transformations

The graph of y = f(x − h) is the graph of y = f(x) shifted h units to the right. The graph of y = f(x) + k is shifted k units up. The graph of y = a f(x) is scaled vertically by a. The graph of y = f(bx) is scaled horizontally by 1/b.

### 🔴 Deep — Long-Term Mastery (1mo–6mo)

#### Where Functions and Graphs appears across the terminal exam

- **Paper 1:** domain and range of a basic function, inverse of a simple function, transformation of a known graph.
- **Paper 2:** composition of two functions, modelling with exponential or logarithmic functions (compound interest, population growth), piecewise functions.

#### Common misconceptions (and the correction)

- "f(x + h) shifts the graph to the right by h." No — f(x − h) shifts to the right; f(x + h) shifts to the left. The sign inside is opposite to the visual shift.
- "All functions have inverses." No — only one-to-one functions do. f(x) = x² does not have an inverse over the reals because both +2 and −2 map to 4.
- "log(2 + 3) = log 2 + log 3." No — log(ab) = log a + log b, not log(a + b).

#### Exam technique

- For domain questions, write the conditions (e.g. x + 5 > 0 for log(x + 5)) explicitly — the domain condition is the method mark.
- For composition questions, state the range of g before composing with f — the range check is the method mark.
- For graph transformations, state the transformation rule explicitly before drawing — the rule is the method mark.
