# Functions — IB Mathematics: Analysis and Approaches (AA) Notes

Functions is the second topic of the IB Mathematics: Analysis and Approaches syllabus (after Number and Algebra) and the most heavily weighted topic at SL by teaching hours. The topic covers domain and range, composite and inverse functions, transformations of graphs, the modulus function, and a wide range of standard functions: polynomial, exponential, logarithmic, rational, and (at HL) trigonometric, parametric and piecewise functions. Functions underpins every other topic in the syllabus — calculus, geometry, statistics and probability all use function notation and graph-reading skills.

### 🟢 Lite — Quick Review (1h–1d)

#### The seven facts every IB student needs

1. **Function**: a rule that assigns to every input exactly one output.
2. **Domain**: the set of all valid inputs.
3. **Range**: the set of all outputs that actually occur.
4. **Composite function**: (f ∘ g)(x) = f(g(x)).
5. **Inverse function**: f⁻¹ is the function that undoes f.
6. **Modulus function**: |x| = x if x ≥ 0, |x| = −x if x < 0.
7. **Exponential and logarithm**: y = e^x and y = ln x are inverse functions. The graphs of y = a^x (for a > 1) and y = log_a(x) pass through (0, 1) and (1, 0) respectively.

#### Key notations

- f: A → B — f is a function from A to B
- f ∘ g — the composite function
- f⁻¹ — the inverse function
- |x| — the modulus of x
- e — the base of natural logarithms (≈ 2.71828)
- ln x — the natural logarithm of x
- log_a x — the logarithm of x to the base a

### 🟡 Standard — Regular Study (2d–2mo)

#### Domain and range

The **domain** of a function is the set of all inputs for which the function is defined. For polynomial functions, the domain is all real numbers. For rational functions p(x)/q(x), the domain excludes the roots of q(x). For √f(x), the domain is where f(x) ≥ 0. For ln f(x) or log f(x), the domain is where f(x) > 0.

The **range** of a function is the set of all outputs that actually occur. For a quadratic f(x) = ax² + bx + c with a > 0, the range is [f(vertex), ∞); with a < 0, the range is (−∞, f(vertex)].

#### Composite and inverse functions

**Composite function**: (f ∘ g)(x) = f(g(x)). The composite is built by applying g first, then applying f to the result.

**Inverse function**: f⁻¹ is the function that undoes f. f⁻¹(f(x)) = x for every x in the domain of f; f(f⁻¹(x)) = x for every x in the domain of f⁻¹. The graph of f⁻¹ is the reflection of the graph of f in the line y = x.

A function has an inverse only if it is one-to-one. If a function is not one-to-one on its whole domain, restrict the domain to a region where it is one-to-one, then define the inverse on that region.

#### Transformations of graphs

Four basic transformations apply to any function y = f(x):

- Vertical translation: y = f(x) + a moves the graph up by a.
- Horizontal translation: y = f(x + a) moves the graph left by a.
- Vertical stretch: y = a f(x) stretches the graph vertically by a factor of a.
- Horizontal stretch: y = f(ax) compresses the graph horizontally by a factor of 1/a.

Reflections:

- y = −f(x) reflects in the x-axis.
- y = f(−x) reflects in the y-axis.

For multiple transformations, apply them in the order specified. The IB often tests transformations applied to y = sin x, y = cos x, y = e^x and y = ln x.

#### Modulus function

The modulus function is |x| = x if x ≥ 0, |x| = −x if x < 0. The graph of y = |f(x)| reflects the part of y = f(x) below the x-axis to above it.

Solving |f(x)| = a (for a > 0) gives the same solutions as f(x) = a and f(x) = −a.

#### Exponential and logarithmic functions

The **natural exponential** y = e^x is defined for all real x, with range (0, ∞). The **natural logarithm** y = ln x is defined for x > 0, with range all real numbers. e^x and ln x are inverse functions.

Logarithm laws:

- ln(ab) = ln a + ln b
- ln(a/b) = ln a − ln b
- ln(a^n) = n ln a
- ln 1 = 0, ln e = 1
- log_a x = ln x / ln a (change of base)

For any base a > 0, a ≠ 1: y = a^x and y = log_a(x) are inverse functions.

#### Polynomial, rational and other standard functions

**Polynomial functions** of degree n: f(x) = aₙ xⁿ + … + a₁ x + a₀. The graph is a smooth curve; the behaviour as x → ±∞ depends on the leading coefficient.

**Rational functions** p(x)/q(x): asymptotes occur where q(x) = 0 (vertical asymptotes) and where p(x)/q(x) approaches a finite value as x → ±∞ (horizontal or oblique asymptotes).

**Piecewise functions**: defined by different formulas on different parts of the domain. The IB often combines a piecewise function with modulus or with transformations.

**Trigonometric functions (HL)**: sin x, cos x, tan x have well-known graphs with period 2π (or π for tan). Transformations apply to these graphs just as to any other function.

**Parametric functions (HL)**: x = x(t), y = y(t). The graph is the set of (x(t), y(t)) as t varies.

### 🔴 Deep — Long-Term Mastery (1mo–6mo)

#### Where Functions appears across the IB Mathematics: AA papers

- **IB Math AA SL Paper 1**: short to medium structured items on domain / range, composite / inverse functions, and graph transformations. Functions underpins calculus items throughout the paper.
- **IB Math AA SL Paper 2**: functions items appear alongside other topics, especially in modelling contexts.
- **IB Math AA HL Paper 1**: more advanced functions items (e.g. piecewise, parametric) appear alongside calculus items.
- **IB Math AA HL Paper 3**: functions and transformations often appear in the modelling and investigation problems.
- **Across the papers**: drawing the original graph and then drawing each transformation step-by-step is the highest-leverage exam technique for graph-transformation items.

#### Common misconceptions (and the correction)

- "The domain is all real numbers." It depends on the function. For ln f(x), the domain is where f(x) > 0; for √f(x), the domain is where f(x) ≥ 0; for 1/f(x), the domain excludes where f(x) = 0.
- "f⁻¹(x) = 1/f(x)." The inverse function is NOT the reciprocal. f⁻¹ is the function that undoes f; 1/f(x) is the reciprocal function.
- "y = f(x + a) translates right by a." It translates LEFT by a.
- "y = a f(x) stretches by a when a is between 0 and 1." A factor a between 0 and 1 is a compression.
- "log_a(x × y) = log_a(x) × log_a(y)." The logarithm of a product is the sum of the logarithms: log_a(xy) = log_a(x) + log_a(y).

#### Exam technique

- For domain / range questions, state the rule you are using (no-zero denominator, non-negative radicand, positive argument for log) before applying it.
- For inverse-function questions, show the swap (x ↔ y) step explicitly. The swap is the method mark.
- For graph-transformation questions, draw the original graph first, then apply each transformation in order. The original graph is the method mark.
- For exponential / logarithmic equations, take ln of both sides before algebraic manipulation. The ln step is the method mark.
