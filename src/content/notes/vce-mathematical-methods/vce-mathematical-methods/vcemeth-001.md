# Functions, Relations and Graphs — VCE Mathematical Methods (VCAA 2023) Notes

Functions, relations and graphs is the largest single content strand in the VCE Mathematical Methods Units 3 and 4 syllabus. The 2023 Study Design covers linear, quadratic, polynomial, exponential, logarithmic and circular (sine and cosine) functions; combinations and composite functions; inverse functions; transformations and the graphical relationship between a function and its inverse. The strand is assessed in both Examination 1 and Examination 2.

### 🟢 Lite — Quick Review (1h–1d)

#### Core facts in one pass

- **Linear function.** f(x) = mx + c. Graph is a straight line with slope m and y-intercept c. Domain and range both all reals.
- **Quadratic function.** f(x) = a(x − h)² + k. Vertex (h, k), axis of symmetry x = h, y-intercept a·h² + c. Discriminant Δ = b² − 4ac determines number of real roots.
- **Exponential function.** f(x) = a·b^x with b > 0, b ≠ 1. Domain all reals, range (0, ∞).
- **Logarithmic function.** f(x) = log_b(x). Domain (0, ∞), range all reals. Inverse of the exponential.
- **Circular functions.** f(x) = sin x, f(x) = cos x. Period 2π. Range [−1, 1].
- **Composite function.** (f ∘ g)(x) = f(g(x)).
- **Inverse function.** f⁻¹(x); exists if f is one-to-one.

#### Examiner traps

- Confusing horizontal and vertical translations: y = f(x − 3) shifts right; y = f(x) − 3 shifts down.
- Forgetting the domain restriction on √x: x ≥ 0; on ln x: x > 0.
- Confusing f⁻¹(x) with 1/f(x). The inverse function is the reflection in y = x; the reciprocal is the reflection in y = x AND y = 0 for the y values.

### 🟡 Standard — Regular Study (2d–2mo)

#### Linear, quadratic and polynomial functions

A linear function f(x) = mx + c has constant rate of change m. A quadratic f(x) = ax² + bx + c has a parabolic graph opening up (a > 0) or down (a < 0). The roots solve ax² + bx + c = 0; discriminant Δ = b² − 4ac; if Δ > 0 two real roots, Δ = 0 one real root, Δ < 0 no real roots.

Cubic functions have one or two stationary points. Factor theorem: x − a is a factor if f(a) = 0.

#### Exponential and logarithmic functions

The exponential function y = a·b^x (b > 0, b ≠ 1) is increasing for b > 1, decreasing for 0 < b < 1. The graph passes through (0, a) and has the x-axis as a horizontal asymptote.

The natural exponential y = e^x has base e ≈ 2.71828. y = e^x is its own derivative.

The logarithm y = log_b(x) is the inverse of y = b^x. Laws: log(xy) = log x + log y; log(x/y) = log x − log y; log(x^n) = n log x. Change of base: log_b(x) = log(x)/log(b).

#### Circular functions

sin x and cos x have period 2π and range [−1, 1]. Exact values: sin 0 = 0, sin π/6 = 1/2, sin π/4 = √2/2, sin π/3 = √3/2, sin π/2 = 1. Cosine values are the sines shifted: cos x = sin(x + π/2).

Identities: sin² x + cos² x = 1. sin(A + B) = sin A cos B + cos A sin B. cos(A + B) = cos A cos B − sin A sin B. tan x = sin x / cos x.

#### Composite and inverse functions

Composite (f ∘ g)(x) = f(g(x)). Domain restriction: x must be in the domain of g AND g(x) must be in the domain of f.

Inverse function: exists iff f is one-to-one (passes the horizontal line test). To find f⁻¹: replace f(x) with y, swap x and y, solve for y. The graph of f⁻¹ is the reflection of f in y = x.

#### Transformations

For parent function y = f(x): y = f(x − a) shifts right a; y = f(x) − a shifts down a; y = a·f(x) stretches vertically by factor a; y = f(x/a) stretches horizontally by factor a; y = −f(x) reflects in x-axis; y = f(−x) reflects in y-axis.

### 🔴 Deep — Long-Term Mastery (1mo–6mo)

#### Why Functions underpins every other Area of Study

- **Calculus** uses function notation throughout. Derivatives, chain rule, integration, and applications all assume fluency with function notation.
- **Algebra** uses function properties (one-to-one, onto) to determine invertibility and composition.
- **Data analysis** uses linear regression to fit a function of the form y = a + bx to bivariate observations.

#### Exam technique

- For sketching questions, identify the parent function, list the transformations in order, and label key features (intercepts, asymptotes, vertex).
- For inverse questions, ALWAYS check one-to-one first.
- For composite function domain questions, list the restrictions from the inner function and from the outer function's domain.

#### Common misconceptions (and the correction)

- "Domain and range are the same." No — domain is the set of allowed x; range is the set of actual outputs.
- "f⁻¹(x) = 1/f(x)." No — f⁻¹ is the inverse function, not the reciprocal.
- "Reflection in y = x and reciprocal are the same." They coincide only when f(x) = x or f(x) = 1/x.
