# Polymers

### 🟢 Lite — Quick Review (1h–1d)
> Memory Hook target: recall PVC's monomer as **Vinyl Chloride** and Teflon's as **Tetrafluoroethylene** — the "T" connects to "Tetra-fluoro".

A polymer is a macromolecule (10³–10⁷ u) built by linking many monomer units through covalent bonds. The **degree of polymerisation** tells you how many repeat segments sit in one chain:

- **Formula:** n = M̄ₙ / M₀, where n is dimensionless, M̄ₙ is the number-average molar mass in g·mol⁻¹, and M₀ is the molar mass of one repeat unit in g·mol⁻¹.
- Addition polymerisation joins monomers with **no small-molecule byproduct** (e.g., polyethylene from CH₂=CH₂).
- Condensation polymerisation **releases H₂O, HCl, or NH₃** (e.g., nylon-6,6 from a diacid + diamine).

| Polymer | Monomer | Type |
|---|---|---|
| Polythene | CH₂=CH₂ | Addition |
| PVC | CH₂=CHCl | Addition |
| Teflon | CF₂=CF₂ | Addition |
| Bakelite | Phenol + HCHO | Condensation |

> 💡 **High-Yield Memory Hook:** "**PVC = Poly-Vinyl-Chloride**" — read the name backward to recover CH₂=CHCl; "**Teflon = TetraFluoro**" — CF₂=CF₂ carries four fluorines per carbon pair.

### 🟡 Standard — Regular Study (2d–2mo)
> Track the difference between *no byproduct* (addition) and *small molecule lost* (condensation) — this single distinction clears most MDCAT MCQs on polymerisation mode.

#### How polymers form and how they are classified

Polymerisation is either **chain-growth (addition)** or **step-growth (condensation)**. In addition, an initiator radical opens a C=C double bond and the chain extends one monomer at a time without losing mass. In condensation, two different bifunctional monomers react at each step and eject a small molecule — nylon-6,6 releases water when its adipic acid and hexamethylenediamine ends meet.

Polymers split into four behaviour classes based on intermolecular forces and chain architecture:

| Class | Chain structure | Behaviour on heating | Example |
|---|---|---|---|
| Thermoplastic | Linear or branched, no cross-links | Softens, remouldable | Polythene, PVC |
| Thermosetting | Heavily cross-linked network | Infusible, irreversible set | Bakelite, vulcanised rubber |
| Elastomer | Sparse cross-links, coiled chains | Elastic recoil, stretches then recovers | Natural rubber |
| Fibre | Linear, strong H-bonds/dipoles | High tensile strength, low stretch | Nylon-6,6, Terylene |

A **homopolymer** repeats one monomer (PVC = –(CH₂–CHCl)ₙ–); a **copolymer** alternates or randomises two or more (SBR rubber = styrene + butadiene). Natural rubber is **cis-1,4-polyisoprene**, a polyisoprene whose cis configuration lets chains uncoil on stretching; vulcanisation with ~1–3 % sulphur inserts –S–S– bridges that limit slippage and raise the elastic limit.

#### Molar-mass averages and polydispersity

Real polymer samples contain chains of many lengths, so two averages are used:

- **Number-average:** M̄ₙ = Σ(Nᵢ·Mᵢ) / Σ(Nᵢ)
- **Mass-average:** M̄w = Σ(Nᵢ·Mᵢ²) / Σ(Nᵢ·Mᵢ)
- **Polydispersity index:** PDI = M̄w / M̄ₙ

PDI = 1 only for a perfectly uniform (theoretical) sample; values from 1.5 to 3 are typical for commercial polyethylene and PVC. The difference matters because M̄w weights long chains heavily (squared mass term), while M̄n treats every chain equally.

#### Worked problem from a past-paper pattern

**Question.** A polymer sample has M̄ₙ = 84 000 g·mol⁻¹. If the repeat unit is –CH₂–CHCl– (M₀ = 62.5 g·mol⁻¹), find the degree of polymerisation and state the class of polymer this represents.

**Step 1.** Apply n = M̄ₙ / M₀ with both quantities in g·mol⁻¹:
n = 84 000 / 62.5 = 1344.

**Step 2.** A chain containing –CH₂–CHCl– repeat units is PVC. PVC is addition-polymerised from vinyl chloride (CH₂=CHCl) and behaves as a **thermoplastic** — it softens above ~80 °C and can be remoulded.

**Answer:** n ≈ 1344, polymer is PVC (thermoplastic).

> ⚠️ **Examiner Trap:** Students often divide by the atomic mass of Cl (35.5) alone or by 27.5 (the empirical-formula mass CH₂Cl) instead of the repeat-unit mass 62.5. The repeat unit for PVC is **–CH₂–CHCl–**, not a single C–C or a single CHCl. Always count one full monomer residue that repeats along the chain.

### 🔴 Extended — Deep Study (3mo+)
> Where the Standard tier separates addition from condensation, here the traps live in monomer identity, repeat-unit drawing, and the link between structure and physical class.

#### Edge cases and the traps examiners actually use

- **Teflon confusion.** Teflon is the polymer of **tetrafluoroethylene (CF₂=CF₂)**, not of ethylene. Repeating the monomer name as "fluorinated ethene" instead of using its IUPAC name loses a mark on descriptive questions.
- **Bakelite's class.** Phenol-formaldehyde resin is **thermosetting**, not thermoplastic, because the methylene and ether bridges form a 3-D network that does not flow on reheating. Many students assume "plastic = thermoplastic".
- **Natural rubber's class.** Unvulcanised cis-1,4-polyisoprene is **sticky and plastic**; once vulcanised, it becomes an **elastomer** because –S–S– cross-links stop chains from sliding past each other.
- **Repeat-unit subscript.** The "n" in –(CH₂–CHCl)ₙ– is **not optional** in MDCAT answers. Writing –(CH₂–CHCl)– without the subscript is treated as an incomplete specification.
- **Condensation byproduct count.** Nylon-6,6 loses **(2n – 1)** H₂O molecules for n monomers of each reactant, not n. One water forms per amide bond, and there are (2n – 1) bonds linking 2n monomers.

#### Comparison matrix of commonly confused pairs

| Feature | Polythene | PVC |
|---|---|---|
| Monomer | CH₂=CH₂ | CH₂=CHCl |
| Repeat unit | –CH₂–CH₂– | –CH₂–CHCl– |
| Mass of repeat unit (g·mol⁻¹) | 28.0 | 62.5 |
| Polymerisation mode | Addition | Addition |
| Behaviour class | Thermoplastic | Thermoplastic |

| Feature | Thermoplastic | Thermosetting |
|---|---|---|
| Cross-linking | None | Extensive network |
| Remouldable on heating | Yes | No (chars instead) |
| Example | Polythene, PVC | Bakelite |
| Recycling | Possible by remelting | Grind-only |

#### Connection to adjacent MDCAT chapters

- **Biomolecules.** Starch, glycogen, cellulose, proteins and nucleic acids are all natural polymers; classifying them as condensation polymers (proteins release water during peptide-bond formation) reinforces the same mechanism.
- **Chemical bonding.** The strength of polymer chains traces to C–C σ bonds; secondary bonding (van der Waals, dipole, H-bond) explains why fibres (nylon) outperform elastomers (weak uncross-linked rubber).
- **Organic nomenclature.** Reading "vinyl chloride" as CH₂=CHCl and "tetrafluoroethylene" as CF₂=CF₂ draws directly on IUPAC rules.

#### Advanced practice prompts

1. A copolymer of styrene (C₈H₈) and butadiene (C₄H₆) is mass-balanced with 25 % styrene by mass. Estimate the **mole ratio** of styrene to butadiene units in the polymer and comment on how this ratio shifts the glass-transition temperature.
2. A condensation polymer is formed from HOOC–(CH₂)₄–COOH and H₂N–(CH₂)₆–NH₂. Write the repeat unit, state the number of water molecules released per 100 repeat units formed, and justify why the resulting material is classed as a **fibre** rather than a thermoplastic.
