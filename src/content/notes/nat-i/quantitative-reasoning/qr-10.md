# Quadratic Equations

### 🟢 Lite — Quick Review (1h–1d)
> Rapid summary for last-minute revision before your exam.

A **quadratic equation** in one variable has the standard form **ax² + bx + c = 0**, where *a*, *b*, *c* are real constants and *a* ≠ 0. The two roots are found with the **quadratic formula**: **x = (−b ± √(b² − 4ac)) / (2a)**. The expression inside the root, **Δ = b² − 4ac**, is called the **discriminant**, and it alone tells you the nature of the roots.

- Δ > 0 → two distinct real roots
- Δ = 0 → two equal real roots (repeated root)
- Δ < 0 → no real roots (complex conjugates)

For NAT-I, expect MCQs that ask for the roots, the value of the discriminant, or the **sum** (−b/a) and **product** (c/a) of the roots using **Vieta's formulas**. Remember to rearrange any equation into ax² + bx + c = 0 *before* reading off the coefficients.

### 🟡 Standard — Regular Study (2d–2mo)
> Standard content for students with a few days to months.

#### Standard form and coefficients

Every quadratic must be rewritten as **ax² + bx + c = 0** with *a* ≠ 0. Watch for hidden coefficients: an equation like 3x² = 12 becomes 3x² − 12 = 0, giving a = 3, b = 0, c = −12. Mixing up *a*, *b*, *c* is the single most common reason candidates miss NAT-I items involving the discriminant or Vieta's formulas.

#### Solving methods

Three equivalent routes reach the same roots:

- **Factoring**: split the middle term so ax² + bx + c factors into (px + q)(rx + s) = 0; each factor gives one root.
- **Completing the square**: rewrite as a(x + b/2a)² = (b² − 4ac)/4a, then take square roots.
- **Quadratic formula**: x = (−b ± √Δ) / 2a, valid for every quadratic.

#### Discriminant and root nature

| Discriminant Δ = b² − 4ac | Nature of roots |
| --- | --- |
| Δ > 0 | Two distinct real roots |
| Δ = 0 | Two equal real roots (a perfect square trinomial) |
| Δ < 0 | No real roots; pair of complex conjugates |

#### Vieta's formulas

If α and β are the roots of ax² + bx + c = 0, then **α + β = −b/a** and **αβ = c/a**. To form a quadratic with roots p and q, use **x² − (p + q)x + pq = 0**.

- If both roots must be positive: demand α + β > 0 *and* αβ > 0.
- If both roots must be negative: demand α + β < 0 *and* αβ > 0.
- If roots have opposite signs: αβ < 0.

#### Common NAT-I traps

- Forgetting to move all terms to one side before factoring.
- Treating x² = k as having one root; it has ±√k unless k ≤ 0.
- Sign errors inside the ± of the quadratic formula.

### 🔴 Extended — Deep Study (3mo+)
> Comprehensive coverage for students on a longer study timeline.

#### Graphical meaning

The graph of y = ax² + bx + c is a **parabola**. When a > 0 it opens upward; when a < 0 it opens downward. The x-intercepts are exactly the roots of ax² + bx + c = 0, and the **axis of symmetry** is the vertical line **x = −b/(2a)**. The **vertex** sits at **(−b/(2a), (4ac − b²)/(4a))** and represents the minimum (a > 0) or maximum (a < 0) value of the quadratic expression — useful for optimization word problems on NAT-I.

#### Worked micro-example

Solve 2x² − 5x − 3 = 0 and verify with Vieta's formulas.
Here a = 2, b = −5, c = −3, so Δ = (−5)² − 4(2)(−3) = 25 + 24 = 49.
Roots: x = (5 ± 7) / 4 → x = 3 or x = −1/2.
Check: α + β = 3 + (−1/2) = 5/2 = −b/a = 5/2 ✓; αβ = 3 · (−1/2) = −3/2 = c/a ✓.

#### Connection to adjacent topics

Quadratic behaviour underpins the **completing-the-square** technique used to derive the vertex form, the standard form of a circle (x − h)² + (y − k)² = r², and integration of polynomial areas. Discriminant logic also appears in cubic and quartic root analysis.

#### Practice prompts

1. If α and β are roots of x² − 7x + 5 = 0, find α² + β² without solving for α, β individually.
2. For what value of k does 3x² − 6x + k = 0 have equal roots?
