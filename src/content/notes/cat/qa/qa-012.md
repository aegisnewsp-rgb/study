# Logarithms

### 🟢 Lite — Quick Review (1h–1d)
> Rapid summary for last-minute revision before your CAT slot.

A **logarithm** answers the question *"to what power must I raise the base to get N?"*. Formally, if $a^x = N$ with $a>0$, $a\neq 1$, and $N>0$, then $x = \log_a N$. The value $N$ is the **argument** (or antilogarithm), and the only legal inputs are positive numbers.

Three identities carry most of the marks:

- $\log_a(MN) = \log_a M + \log_a N$
- $\log_a(M/N) = \log_a M - \log_a N$
- $\log_a(M^k) = k \log_a M$

#### CAT-scoring pointers:

- Always check the **domain**: $\log_a N$ is defined only for $N>0$.
- $\log_a a = 1$ and $\log_a 1 = 0$ — free marks when spotted.
- $\log_{10}$ uses base 10; $\ln$ uses base $e \approx 2.71828$.

### 🟡 Standard — Regular Study (2d–2mo)
> Standard content for students with a few days to months.

#### Definition and inverse link with exponentials

Logarithms are the **inverse operation** of exponentiation. The pair $a^x = N \iff x = \log_a N$ lets you convert exponential statements into linear ones, which is the entire reason the topic appears in CAT QA. The base must be positive and not equal to 1; the argument must be strictly positive.

#### The three working laws

For any valid $M,N>0$ and real $k$:

$$\log_a(MN) = \log_a M + \log_a N, \quad \log_a(M/N) = \log_a M - \log_a N, \quad \log_a(M^k) = k \log_a M.$$

These turn multiplication into addition, division into subtraction, and powers into coefficients — useful whenever a CAT problem hides a product inside an exponential equation.

#### Change of base and special values

When two bases appear in one expression, use $\log_a b = \dfrac{\ln b}{\ln a} = \dfrac{\log_c b}{\log_c a}$. This is the cleanest way to compare magnitudes or evaluate numerically. The table below lists the values CAT rewards for instant recall.

| Identity | Value | When to use it |
| --- | --- | --- |
| $\log_a a$ | $1$ | Argument equals base |
| $\log_a 1$ | $0$ | Argument equals 1 |
| $a^{\log_a N}$ | $N$ | Exponent is a logarithm |
| $\log 2, \log 3, \log 5, \log 7$ | $\approx 0.301, 0.477, 0.699, 0.845$ | Quick magnitude checks |

#### Solving exponential equations

Take $\log$ on both sides: $2^{3x} = 32 \Rightarrow 3x\log 2 = \log 32 \Rightarrow x = \dfrac{5}{3}$. The same trick simplifies compound-interest formulas $A = P(1+r)^n$ into a linear form in $n$, which is why logarithms surface inside Arithmetic.

#### Common traps examiners set

- Mixing bases without converting: $\log_2 8 + \log_3 27 = 3 + 3 = 6$, but $\log_2 8 \cdot \log_3 27 = 9$ — only one form is a true log identity.
- Forgetting that $\log(x+y) \neq \log x + \log y$.

### 🔴 Extended — Deep Study (3mo+)
> Comprehensive coverage for students on a longer study timeline.

#### Domain, monotonicity, and inequality comparison

The behaviour of $\log_a x$ depends entirely on the base $a$. For $a>1$ the function is **strictly increasing**; for $0<a<1$ it is **strictly decreasing**. This sign-flip is the single highest-value observation for CAT inequality questions: if you take $\log$ of both sides of an inequality, you must reverse the sign whenever the base lies in $(0,1)$.

The domain restriction $x>0$ is equally load-bearing. Expressions such as $\log(x^2)$ have domain $x\neq 0$, but $\log(x-3)$ collapses to $x>3$. Squaring inside a log — e.g. replacing $\log(x-1)^2$ with $2\log(x-1)$ — silently adds the forbidden region $x<1$, and CAT problem-setters exploit this routinely.

#### Connections to other CAT QA topics

- **Arithmetic / Compound Interest:** $n = \dfrac{\log(A/P)}{\log(1+r)}$ converts the time variable in $A=P(1+r)^n$ into a linear equation.
- **AP/GP linkages:** the $n$-th term $a r^{n-1}$ of a GP yields $\log a_n = \log a + (n-1)\log r$, an arithmetic progression in log-space.
- **Number Systems:** counting digits of $N!$ uses $\lfloor \log_{10} N! \rfloor + 1$, and trailing zeros depend on $\sum \lfloor N/5^k \rfloor$.
- **Algebraic inequalities:** AM-GM comparisons are sometimes easier after taking logs when the variables are exponential.

#### Worked micro-example

Solve $3^{2x+1} = 7^{x-1}$. Take natural log on both sides:

$$(2x+1)\ln 3 = (x-1)\ln 7 \implies 2x\ln 3 - x\ln 7 = -\ln 3 - \ln 7$$
$$x = \frac{-\ln 21}{2\ln 3 - \ln 7} \approx \frac{-3.045}{1.098 - 1.946} \approx 3.59.$$

#### Practice prompts

1. If $\log_2(\log_3 x) = 2$, find $x$ without using a calculator.
2. Find the largest integer $n$ such that $2^n < 10^6$, using only $\log_{10} 2 \approx 0.3010$.
