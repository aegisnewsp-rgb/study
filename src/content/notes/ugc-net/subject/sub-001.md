# Research Methodology

### 🟢 Lite — Quick Review (1h–1d)
> Rapid summary for last-minute revision before your exam.

Research Methodology is the systematic plan that governs how a problem is defined, data is gathered, and findings are reported. UGC NET Paper-1 tests it under "Research Aptitude" with 4–5 questions (≈5% weightage) drawn mostly from definitions, concept pairs, and basic statistical reasoning.

| Term | One-line meaning |
|---|---|
| **Research Design** | Overall blueprint/strategy of the study |
| **Research Method** | Specific tools/techniques used (survey, interview) |
| **Hypothesis (H₁)** | Testable, falsifiable prediction by the researcher |
| **Null Hypothesis (H₀)** | Statement of "no effect/no difference" |
| **Independent Variable** | Cause that is manipulated |
| **Dependent Variable** | Effect that is measured |
| **α (Level of Significance)** | P(Type I error), usually 0.05 |

- Mean: $\bar{x} = \dfrac{\sum x_i}{n}$
- Standard Error: $SE = \dfrac{\sigma}{\sqrt{n}}$
- Degrees of Freedom: $df = n - k$
- χ² (Chi-square): $\chi^2 = \sum \dfrac{(O_i - E_i)^2}{E_i}$

### 🟡 Standard — Regular Study (2d–2mo)
> Standard content for students with a few days to months.

#### Core Definitions and the Method–Design Split
A **research method** is the instrument of data collection (questionnaire, interview, observation). A **research design** is the strategic architecture linking the research problem to data and conclusion. Examiners frequently swap these two; remembering the hierarchy "Design > Method > Tool" prevents that slip.

#### Types of Research at a Glance

| Type | Purpose | Example |
|---|---|---|
| **Fundamental / Basic** | Expand theoretical knowledge | Studying cell division |
| **Applied** | Solve a practical problem | Drug trial for a new compound |
| **Descriptive** | Portray characteristics | Survey of student habits |
| **Analytical** | Test a causal hypothesis | Effect of tuition on grades |
| **Action Research** | Improve practitioner's own practice | Teacher revising lesson plan |
| **Empirical** | Based on observable evidence | Lab experiment |
| **Qualitative / Quantitative / Mixed** | Nature of data | Interviews vs scores vs both |

#### Variables and Hypothesis Logic
The **independent variable (IV)** is the cause manipulated; the **dependent variable (DV)** is the outcome measured; **extraneous variables** must be controlled to avoid confounding. A hypothesis is a *declarative* statement — never a question. H₀ states "no effect"; H₁/Hₐ states the expected effect. Statistical decision rules:

- Reject H₀ when p ≤ α → evidence supports H₁.
- Fail to reject H₀ → does **not** prove H₀ true, only that evidence is insufficient.

#### Concept Comparison Matrix

| Pair | Key Distinction |
|---|---|
| **Type I vs Type II error** | Type I = false positive (reject true H₀); Type II = false negative (accept false H₀) |
| **Reliability vs Validity** | Reliability = consistency on repetition; Validity = measures what it claims |
| **Stratified vs Cluster sampling** | Stratified samples each subgroup proportionally; Cluster samples whole intact groups |
| **Parametric vs Non-parametric tests** | Parametric needs interval/ratio + normality (t, ANOVA, Pearson); Non-parametric uses ranks (χ², Mann-Whitney, Wilcoxon) |
| **Applied vs Action research** | Applied solves external problems; Action is cyclical, practitioner-led, classroom-based |
| **Cross-sectional vs Longitudinal** | Cross = one-time snapshot; Long = repeated over time |
| **Interpretation vs Inference** | Interpretation explains meaning *within* data; Inference generalises to population |

#### Sampling and Sample-Size Logic
Probability sampling (Simple Random, Stratified, Systematic, Cluster, Multistage) lets every element have a known chance of selection. Non-probability (Convenience, Purposive, Snowball, Quota, Judgmental) is faster but limits generalisability. The working formula for estimating sample size when population proportion is unknown uses $n = \dfrac{z^2 \cdot p(1-p)}{e^2}$, where $z$ = confidence-level value (1.96 for 95%), $p$ = expected proportion (0.5 if unsure), $e$ = margin of error (decimal). All terms dimensionless except $z$, which is a pure number.

#### 🎯 Exam-Level Worked Problem
**Question:** A researcher sets α = 0.05. After running a two-tailed z-test, the calculated p-value is 0.03. State the decision regarding H₀, identify which error becomes relevant if the decision is wrong, and compute the power of the test if β = 0.10. ([UGC NET Paper-1, Research Aptitude pattern])

#### Solution:
1. Compare p-value with α: 0.03 < 0.05, so **reject H₀**.
2. A wrong rejection of a true H₀ is a **Type I error** (α error).
3. Power = 1 − β = 1 − 0.10 = **0.90** (90%).

> ⚠️ **Examiner Trap:** Students often pick "Type II error" here because they confuse *failure to reject* with *rejection*. Rule: an error triggered by **rejecting** a true null is always Type I. Also, "Power = 1 − β" applies *only* to Type II — don't invert it.

### 🔴 Extended — Deep Study (3mo+)
> Comprehensive coverage for students on a longer study timeline.

#### Validity and Reliability — The Nested Sets Model
Validity and reliability obey a **subset rule**: every valid measure must be reliable, but a perfectly reliable measure can still be invalid (e.g., a ruler consistently off by 2 cm is reliable but not valid). Internal validity (causal truth inside the study) and external validity (generalisation beyond the study) often trade off — tight controls boost internal but may hurt external. Construct validity checks whether the operational definition matches the theoretical concept; content validity checks whether the items cover the full domain. For questionnaires, **Cronbach's α ≥ 0.70** is the conventional reliability threshold; the formula is $\alpha = \dfrac{k}{k-1}\left(1 - \dfrac{\sum \sigma^2_{item}}{\sigma^2_{total}}\right)$, where $k$ = number of items, $\sigma^2_{item}$ = variance of each item, $\sigma^2_{total}$ = variance of total score (dimensionless).

#### Measurement Scales and Test Selection
Nominal (categories) and Ordinal (rank) data need non-parametric tests. Interval (equal units, no true zero, e.g., °C) and Ratio (true zero, e.g., kg, marks) data support parametric tests. Misusing a t-test on Likert-scale ordinal data inflates Type I error — a classic UGC NET trap.

#### Research Design Hierarchy of Evidence
For quantitative questions, the evidence ladder rises: **Case Study < Correlational < Quasi-experimental < True Experimental (RCT)**. Random assignment to treatment/control and pre-test/post-test structure are what mark a true experiment. Qualitative designs (ethnography, phenomenology, grounded theory, narrative inquiry) answer "how/why" questions through prolonged engagement.

#### Common Traps and Boundary Cases

| Trap | Why it costs marks | Correct position |
|---|---|---|
| Treating a question as a hypothesis | Hypothesis is declarative | Re-phrase as a statement |
| "Failing to reject H₀ proves H₀" | Decision ≠ proof | Insufficient evidence, not proof |
| Quota ≠ Stratified sampling | Quota is non-probability | Stratified is probability |
| APA in-text only or reference list only | Both mandatory | Cite + list |
| Parametric test on ordinal Likert data | Violates assumptions | Use Mann-Whitney / χ² |
| Treating applied and action research as identical | Different scope | Applied = general problem; Action = own practice |
| Reporting SE instead of σ | SE = σ/√n | Use SE for the *mean*, σ for individuals |

#### Ethical and Reporting Layers
Informed consent, confidentiality, anonymity, and citation discipline are non-negotiable under UGC and APA ethics codes. The **IMRaD** structure (Introduction, Methods, Results, and Discussion) is the default report skeleton. Plagiarism includes self-plagiarism and paraphrased unattributed text — both are flagged by Turnitin-style software.

#### Advanced Practice Prompts
1. A study reports reliability = 0.92 but construct validity = 0.45. Diagnose the design flaw and propose two corrective steps (use the reliability–validity subset rule).
2. A researcher uses stratified random sampling with proportional allocation, then applies ANOVA. If α = 0.01 and obtained F = 1.85 with df = (3, 76), what is the logical decision, and which error type carries the greater risk in under-powered studies?

#### Exam Strategy for UGC NET Paper-1
UGC NET Paper-1 has **no negative marking since the December 2024 UGC notification**, so attempt all Research Aptitude MCQs. Read "difference between" questions by isolating one word at a time — most wrong options differ only on scope (e.g., "applied" vs "action") or direction (Type I vs Type II). For numerical items (SE, df, χ²), write the formula first, then substitute — examiners reward the working even when the final value is approximate.
