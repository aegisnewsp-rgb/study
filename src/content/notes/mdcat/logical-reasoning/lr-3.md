# Classification

### 🟢 Lite — Quick Review (1h–1d)
> Rapid summary for last-minute revision before your MDCAT Logical Reasoning section.

**Classification** is a grouping task: from a set of 4–5 items, identify the *essential common property* shared by four of them so the fifth emerges as the **odd one out**. MDCAT tests classification through short odd-one-out MCQs where the correct grouping must use the **strongest** shared attribute — not the first one you spot.

#### Must-know quick rules
- **Step 1:** Scan all options before grouping.
- **Step 2:** Find a property common to exactly four.
- **Step 3:** Confirm by rejecting alternative groupings.
- **Step 4:** Watch for **negative attributes** (e.g., 4 mammals vs 1 reptile).

| Attribute type | Example grouping | Odd item |
|---|---|---|
| Biological class | Tiger, Lion, Deer, Cow | Bat (only flying mammal listed) |
| Function | Knife, Saw, Scissors, Axe | Spoon (only one without a cutting edge) |
| Profession | Doctor, Engineer, Teacher, Lawyer | Farmer (only one tied to agriculture directly) |
| Living/Non-living | Rose, Mango, Lotus, Tulip | Plastic flower |

Aim for **under 60 seconds per question** — the 3% weight usually means about 3 quick MCQs in the MDCAT paper.

### 🟡 Standard — Regular Study (2d–2mo)
> Standard content for students with a few days to months of preparation.

#### What classification really tests
Classification items are placed in the same class because they share **at least one essential characteristic** — function, structure, habitat, composition, or category. MDCAT questions present 4–5 words and ask either *"which one is odd?"* or *"which two go together?"*. The trap is that almost any set can be grouped in more than one weak way. The correct answer is the grouping whose shared property is the **most defining** for the four items, leaving a clean fifth.

#### The classification algorithm
1. **Read all options first** — avoid locking onto a pattern after seeing two items.
2. **Hunt for a common property** across the options: biological class (mammal, bird, reptile), physical state (solid, liquid, gas), use (cutting, writing, measuring), habitat (aquatic, terrestrial), or word structure (letter count, vowel pattern).
3. **Identify the odd one** as the option that fails this property.
4. **Verify uniqueness** — try to find a *stronger* grouping; if none exists, your answer is solid.

#### Attributes PMC tests most often

| Attribute axis | Sample items in a question | Why it works |
|---|---|---|
| Mammal vs bird | Cat, Dog, Cow, Sparrow | Three share warm-blooded mammal traits |
| Edible part | Apple, Mango, Carrot, Spinach | Three are fruits, one is a leaf-vegetable |
| Musical instrument | Guitar, Violin, Piano, Flute | Three are string, one is wind |
| Mode of transport | Car, Bus, Train, Boat | Three are land-based, one is water |
| Word length | "Cat, Dog, Bat, Rat" vs "Tiger" | Four are 3-letter animals, one is 5-letter |

> **Trap to avoid:** don't pick a grouping that uses a *weak* or *incidental* property when a **category-based essential property** ties the other four together more tightly.

### 🔴 Extended — Deep Study (3mo+)
> Comprehensive coverage for students on a longer study timeline.

#### Edge cases and pattern shifts
MDCAT occasionally uses **verbal/letter classification** instead of semantic categories. Examples: *"P, Q, R, S, T"* — the odd one out is the vowel *U* (or whichever letter breaks a stated pattern such as rotational symmetry, alphabetical position, or shape). Letter-classification questions test **pattern recognition**, not world knowledge, so switch your mental mode.

Two harder variants appear in PMC past papers:
- **"Which two go together?"** — find the *pair* sharing a unique property, not the odd one.
- **Multiple-step classification** — first classify 4 items, then re-classify the *remaining set* with a new option added.

#### Mechanism: why a "wrong" answer feels right
Distractors exploit three biases:

| Bias | How it misleads | Counter |
|---|---|---|
| Surface similarity | Grouping Cat–Dog–Horse by "pet" | Farm animals aren't pets; use biological class instead |
| Function overlap | Grouping Knife–Spoon–Fork by "kitchen tool" | Three are utensils, one is a tool — narrower axis |
| Ignoring negatives | Missing that 4 are mammals, 1 is a reptile | Always check the *whole* set's negatives |

#### Common mistakes
- **First-pattern lock-in:** settling on the first grouping without testing alternatives.
- **Confusing Classification with Analogy:** analogies need A:B :: C:?; classification needs grouping/odd-one-out logic.
- **Forgetting negative attributes:** four items can be classed by *what they are not* relative to the fifth.
- **Misreading the question stem** — choosing an odd-one-out answer for a "which two are alike" question.

#### Practice prompts
1. From *Tiger, Lion, Elephant, Deer, Dolphin* — which is the odd one out, and what is the **strongest** defining property of the other four?
2. In the set *Chair, Table, Stool, Bench, Cupboard* — identify the odd one using *function* as the axis, then re-classify using *mobility* as the axis and note the difference.
