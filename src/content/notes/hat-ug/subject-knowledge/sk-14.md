# Computer Fundamentals

### 🟢 Lite — Quick Review (1h–1d)
> Rapid summary for last-minute revision before your exam.

Computer Fundamentals for HAT-UG tests your recognition of **basic computer architecture**, **memory units**, **generations of computers**, and **number system conversions**. The HAT-UG Subject Knowledge section carries about **3% weightage**, usually yielding **1–2 MCQs** per attempt.

- **CPU** = ALU + CU + Registers; executes instructions fetched from memory.
- **Memory ladder**: 1 Byte = 8 Bits → 1 KB = 1024 B → 1 MB = 1024 KB → 1 GB = 1024 MB → 1 TB = 1024 GB.
- **Generations**: 1st (vacuum tubes), 2nd (transistors), 3rd (IC), 4th (microprocessor/VLSI), 5th (AI).
- **RAM is volatile** (data lost on power-off); **ROM is non-volatile** (stores BIOS/boot instructions).

### 🟡 Standard — Regular Study (2d–2mo)
> Standard content for students with a few days to months.

#### Computer Architecture (Von Neumann Model)
A computer follows the **Von Neumann architecture** where *program instructions* and *data share the same memory and bus*. The **CPU** contains the **ALU** (arithmetic-logic operations), the **CU** (control unit, decodes instructions), and **registers** (smallest, fastest storage). The **motherboard** connects CPU, RAM, and peripherals through buses (data, address, control).

#### Memory Hierarchy
Primary memory sits close to the CPU: **Registers** (fastest) → **Cache** (L1/L2/L3, SRAM-based) → **RAM** (volatile, DRAM) → **ROM** (non-volatile, holds BIOS). Secondary memory (HDD, SSD, optical disc, USB) is non-volatile but slower.

| Memory type | Volatile? | Typical use |
| --- | --- | --- |
| RAM | Yes | Running programs and temporary data |
| ROM | No | Boot instructions, firmware |
| Cache | Yes | Speed bridge between CPU and RAM |
| HDD/SSD | No | Permanent file storage |

#### Number System Conversions
The four bases tested are **Binary (2)**, **Octal (8)**, **Decimal (10)**, and **Hexadecimal (16)**. Conversion methods:

- Decimal → Binary: divide by 2, record remainders, read **bottom-up**.
- Binary → Decimal: $\text{value} = \sum d_i \cdot 2^i$, where $d_i \in \{0,1\}$ and $i$ starts at 0 from the right.
- Decimal → Hex: divide by 16; remainders ≥10 become **A–F** (10→A, 11→B, 12→C, 13→D, 14→E, 15→F).

For example, decimal **45** → divide 45÷2 = 22 r**1**, 22÷2 = 11 r**0**, 11÷2 = 5 r**1**, 5÷2 = 2 r**1**, 2÷2 = 1 r**0**, 1÷2 = 0 r**1** → reading bottom-up gives **101101**.

#### Software Categories
- **System software**: Operating System, device drivers, compilers, interpreters.
- **Application software**: MS Word, browsers, Photoshop — user-facing tools.

#### Exam Patterns for HAT-UG
Expect one **definition MCQ** (e.g., "Which memory is volatile?") and one **conversion MCQ** (binary ↔ hex). Statements about HTTP vs HTTPS, LAN/WAN, and IP/DNS also appear. HAT-UG uses a single-correct MCQ format with no negative marking announced for Subject Knowledge.

### 🔴 Extended — Deep Study (3mo+)
> Comprehensive coverage for students on a longer study timeline.

#### Generations of Computers in Detail
| Generation | Component | Approx. period | Key trait |
| --- | --- | --- | --- |
| First | Vacuum tubes | 1940–1956 | Large, heat, ENIAC/IAC |
| Second | Transistors | 1956–1963 | Smaller, reliable |
| Third | Integrated circuits | 1964–1971 | Miniaturisation |
| Fourth | Microprocessors / VLSI | 1971–present | PCs, laptops |
| Fifth | AI / parallel processing | Future | NLP, neural hardware |

#### Common Mistakes in HAT-UG MCQs
1. Confusing **RAM (volatile)** with **ROM (non-volatile)** — HAT options frequently swap the two.
2. Using **1 KB = 1000 Bytes** (SI) instead of **1024 Bytes** (binary) — wrong by ~2.4%.
3. Calling the **Internet** and the **WWW** the same thing. The internet is the physical network; WWW is a service layered over HTTP.
4. Tagging **microprocessors** to the Third Generation — they belong to the Fourth.
5. Treating **HTTP** and **HTTPS** as identical. HTTPS adds **SSL/TLS encryption** and is mandatory for login/payment pages.

#### Networking & Internet Basics
**LAN** (Local Area Network) covers a building; **MAN** covers a city; **WAN** spans countries; **PAN** is personal (Bluetooth). An **IP address** identifies a device; **DNS** resolves domain names to IPs. **URL** = protocol + domain + path; **HTTP/HTTPS** are request protocols; **Email** uses SMTP/POP3/IMAP.

#### Operating System Functions
1. **Process management** — scheduling and multitasking.
2. **Memory management** — allocating RAM to processes.
3. **File management** — read/write, NTFS/FAT/ext4.
4. **Device management** — drivers for I/O.
5. **Security** — authentication and access control.

#### ASCII & Data Encoding
**ASCII** uses 7 bits = **128 characters**; Extended ASCII uses 8 bits = **256 characters**. Unicode (UTF-8/16) supersedes ASCII for global scripts. ASCII value of 'A' = 65, '0' = 48, 'a' = 97 — useful for character-arithmetic MCQs.

#### Practice Prompts
1. Convert decimal **255** to binary and hexadecimal, then verify by expanding $(11111111)_2$.
2. A 16 GB RAM stick contains how many bytes? (Answer: $16 \times 1024 \times 1024 \times 1024 = 17{,}179{,}869{,}184$ bytes.)
