# Question Types — Multiple Choice, Matching, Labelling, Short Answer — IELTS Listening (Hong Kong) Notes

Multiple choice (with three options A/B/C, or five options A-E), matching (matching items to lists, speakers to opinions), plan/map/diagram labelling, and short-answer questions. Common in Parts 2 and 3 of the IELTS Listening test.

> Verify the live Listening question types on https://ielts.org/ before planning revision.

---

### 🟢 Lite — Quick Review (1h–1d)

#### Core facts in one pass

- **Multiple choice:** choose one of three or five options. The question stem may ask about a detail, the main idea, an opinion, or a function.
- **Matching:** match items from a list to a set of categories (e.g. speakers to opinions, features to locations, dates to events).
- **Plan/map/diagram labelling:** label a plan, map, or diagram with words from the recording.
- **Short-answer questions:** answer open-ended questions about the recording in 1-3 words.

#### Examiner traps

- Selecting a distractor that is mentioned in the recording but does not match the question.
- Matching to the wrong item (e.g. confusing speaker A with speaker B).
- Exceeding the word limit on short-answer questions.

### 🟡 Standard — Regular Study (2d–2mo)

#### Multiple choice

**3-option MCQ**: choose A, B, or C. Common in Parts 1 and 2.

**5-option MCQ**: choose A, B, C, D, or E. Common in Parts 3 and 4.

**Approach**:

1. Read the question stem and the options before listening.
2. Identify the keywords in the question.
3. Listen for the keywords; eliminate options that are mentioned but do not match the question.
4. Select the option that exactly matches the question.

**Common traps**:

- The recording mentions all options; the question asks for the correct one.
- A speaker corrects themselves; the original (wrong) information is the distractor.
- Hedging language ("I sort of think..." vs "I definitely think...").

#### Matching

**Common types**:

- **Speakers to opinions:** match each speaker's opinion to a list.
- **Features to categories:** match each feature to a category.
- **Dates to events:** match each date to an event.

**Approach**:

1. Read the list of items to match and the categories.
2. Identify the keywords for each item.
3. Listen for the keywords; match each item as you hear it.
4. Be careful with speakers — track who says what.

#### Plan/map/diagram labelling

**Approach**:

1. Study the visual carefully before listening.
2. Identify the items to label.
3. Listen for the location/feature descriptions; label the items in the order you hear them.
4. Use the exact word from the recording.

**Tip**: the order of items in the recording typically matches the order of items in the visual.

#### Short-answer questions

**Word limit**: typically 1-3 words.

**Approach**:

1. Read the question; identify the type of information needed (name, date, number, place).
2. Listen for the keyword in the question.
3. Write the answer using words from the recording, within the word limit.

**Common answer types**: name, date, time, number, place, percentage, colour, material.

### 🔴 Deep — Long-Term Mastery (1mo–6mo)

#### Cross-paper links

- **Part 2**: plan/map/diagram labelling is common.
- **Part 3**: multiple choice and matching are common.
- **Reading**: similar multiple choice and matching techniques.

#### Exam technique

- For multiple choice, eliminate distractors; select the option that exactly matches the question.
- For matching, track each speaker's opinion carefully.
- For plan/map/diagram labelling, label in the order you hear.
- For short-answer questions, follow the word limit strictly.

#### Common misconceptions (and the correction)

- "All options are correct." No — only one option is correct; the others are distractors.
- "I can use my own words." No — use words from the recording for completion and short-answer items.
