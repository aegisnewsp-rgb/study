# Random Number Allocation

### 🟢 Lite — Quick Review (1h–1d)
> Rapid summary for last-minute revision before your CAO application.

**Random Number Allocation** — Quick Facts for Irish Leaving Certificate students

**What is random number allocation?**
Random number allocation is the **tie-breaker mechanism** that CAO uses when two or more candidates are tied on points for the last available place in a course. Each candidate is assigned a unique random number when they submit their CAO application; the candidate with the LOWEST random number receives the offer.

**Key facts:**
- Random number is generated when the application is submitted (not when the offer round runs)
- The number is unique to each application — no two candidates share the same random number
- The lowest random number wins ties
- Random number is INDEPENDENT of grades and INDEPENDENT of order of course choices
- Used only at the cut-off boundary; candidates who are not tied are not affected
- Random number allocation runs at every round (Round 1, Round 2, Round 3, etc.)

**Why it matters:**
Random number allocation is the only mechanism that decides between tied candidates. Two candidates with identical 550 points will not always both get offers if only one place is available — the random number breaks the tie.

**Practical implications:
- Apply early is NOT a strategic advantage (the random number is independent of timing relative to other applicants; the order of receipt is irrelevant)
- Order of course choices is NOT a strategic tie-breaker (the random number beats preference order — see cao-008)
- Tied candidates with lower random numbers receive offers; tied candidates with higher random numbers are placed on waiting lists

⚡ **Quick rule:** Two candidates with identical points at the cut-off are NOT guaranteed both offers — random number breaks it, lowest wins. Order of choices does NOT affect random-number tie-breaking.

**Random Number Allocation** — CAO Points Study Guide

**When does random number allocation apply?**
Random number allocation applies **only when two or more candidates are tied on points** for the last available place in a course. Specifically:

- Two or more candidates have **identical CAO points** (six-best + HL Maths bonus if applicable)
- The course's published cut-off is that exact points value
- There are fewer remaining places than the number of tied candidates

If a candidate's points exceed the cut-off by even 1 point, they receive the offer regardless of any tied candidates. Random number allocation only kicks in at the boundary.

**How is the random number generated?**
The random number is generated **at the time the candidate submits their CAO application**. The exact algorithm is published by CAO; the number is unique to each application. Some properties:

- The number is in the range 1 to N where N is identified by CAO's random-number system
- Lower numbers win ties (candidate with the lowest random number gets the offer)
- The number is independent of the order in which the application was submitted (i.e., two candidates who submit seconds apart have the same chance of a low random number)
- The number is independent of the order of course choices the candidate lists

**What random number is NOT:**
- It is NOT a function of grades (two candidates with identical grades get different random numbers)
- It is NOT a function of the order in which the application was received (early submission does NOT give a lower random number)
- It is NOT a function of the order of course choices (preference order is irrelevant to random-number tie-breaking)
- It is NOT a function of the candidate's school or county
- It is NOT a function of the year of application (a 2024 random number does not influence a 2025 random number)

**The order of evaluation in CAO offers:**
For each round (Round 1, Round 2, Round 3, etc.), CAO evaluates candidates course by course in the order of their listed preferences:

1. **Matriculation check:** Does the candidate meet all subject-and-grade minimums for the course? (see cao-005)
2. **Aggregate check:** Does the candidate's aggregate (six-best + 25 bonus) meet or exceed the course's published cut-off? (see cao-001, cao-002, cao-003)
3. **Random number allocation:** If candidates are tied at the cut-off, the random number breaks the tie — lowest random number wins.

Random number allocation is the **final tie-breaker** in the offer decision. It runs only at the boundary of two candidates with identical points.

**How random number ties are reported:**
After each offer round, CAO publishes the cut-off points for every Level 7/8 course. If random number allocation affected the cut-off, CAO notes that the cut-off was determined by random number rather than by aggregate alone. Candidates who received offers via random number can verify this by examining the published cut-off notes.

**Worked example 1:** Three candidates tied at 500 points for the last place in a course.

- Candidate A: 500 points, random number 1,234
- Candidate B: 500 points, random number 5,678
- Candidate C: 500 points, random number 9,012

Candidate A has the lowest random number, so Candidate A receives the offer. Candidates B and C are placed on the waiting list (or considered in subsequent rounds).

**Worked example 2:** One candidate exceeds the cut-off; random number is not invoked.

- Course cut-off: 500 points
- Candidate D: 501 points — exceeds by 1 point, receives the offer
- Candidate B: 500 points, random number 5,678 — does NOT receive the offer because Candidate D took the last place
- Candidate C: 500 points, random number 9,012 — does NOT receive the offer

In this scenario, random number is not invoked because Candidate D's points exceeded the cut-off. The tie-breaker only applies at the exact cut-off boundary.

**Worked example 3:** Two candidates tied at the cut-off after Round 1, both not offered; one receives offer in Round 2.

- Round 1 cut-off: 500 points, 1 place available
- Candidates B and C both have 500 points. Candidate B has random number 5,678; Candidate C has random number 9,012. Candidate B receives the offer. Candidate C is placed on the waiting list.
- In Round 2, the cut-off for the course might be lower (e.g., 480 points) if no candidates at 490 points have applied, or if places remain unfilled. Candidate C with 500 points would receive a Round 2 offer at any cut-off ≤ 500.

**The random number across rounds:**
A candidate's random number is **constant across rounds**. The same random number is used in Round 1, Round 2, Round 3, etc. Candidates do not get a fresh random number for each round.

**What "random" means here:**
The random number is generated by a deterministic algorithm (the same inputs produce the same output), but the inputs include a per-application seed that is unpredictable in advance. From a candidate's perspective, the number is random — no candidate can predict or influence their random number before application submission.

**Why random number is independent of submission order:**
The random number is generated **at the moment of application submission** and is unique to that application. The order in which candidates submit their applications (e.g., 14:00:01 vs 14:00:02) does not affect the distribution of random numbers. Each candidate's number is independently drawn from the same uniform distribution, regardless of timing.

**Why random number is independent of order of choices:**
The random number is a property of the application, not of any individual course choice. When two candidates are tied on a particular course's cut-off, the random number decides regardless of whether the candidate listed the course as their first or tenth preference. The order of choices (see cao-008) is evaluated separately, after the random-number tie-breaker.

**Why random number allocation is fair:**
Random number allocation is the standard fair-tie-breaker mechanism used by CAO for the last-place allocation problem. It is:

- **Independent of grades:** Two candidates with identical grades get different random numbers
- **Independent of timing:** Submission order does not affect the distribution
- **Independent of preferences:** Order of choices does not affect tie-breaking
- **Verifiable:** Candidates can verify their random number through the CAO applicant portal

**What to do if you are affected by random number allocation:**
- If you are tied at the cut-off and lose the random number, you may receive an offer in a later round if places remain unfilled
- You may be placed on a waiting list (course-specific)
- Your random number is the same across rounds, so a lower random number does NOT give you an advantage in later rounds compared to other tied candidates
- Consider re-applying in subsequent years (you receive a fresh random number each year)

**Frequently asked questions:**
- "Does early submission give me a better random number?" — No. The random number is generated at submission time and is independent of the order in which applications are received. Two candidates submitting seconds apart have the same chance of a low random number.
- "Does my random number change between rounds?" — No. The random number is constant across rounds for a given application. The same number is used in Round 1, Round 2, etc.
- "Can I see my random number?" — Yes, your random number is visible in your CAO applicant portal after you submit your application.
- "Does preference order affect random number allocation?" — No. Random number is a property of the application, not of any individual course. The tie-breaker is invoked regardless of where the candidate listed the course.
- "Can two candidates have the same random number?" — No. Each application receives a unique random number. The system guarantees no duplicates.
- "What happens if I am tied with 100 other candidates?" — The lowest random number among the 101 tied candidates receives the offer; the other 100 are considered for waiting lists or later rounds.
