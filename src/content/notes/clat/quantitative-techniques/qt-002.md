# Algebra

### 🟢 Lite — Quick Review (1h–1d)
> Rapid summary for last-minute revision before your exam.

**Algebra** in CLAT Quantitative Techniques covers algebraic identities, linear and quadratic equations, inequalities, and progressions (AP, GP). Questions are short MCQs requiring fast manipulation, in most keys solvable in under a minute.

- **Quadratic formula:** x = (−b ± √(b² − 4ac)) / 2a; the **discriminant** Δ = b² − 4ac decides whether roots are real and distinct (Δ > 0), real and equal (Δ = 0), or complex (Δ < 0).
- **AP nth term:** aₙ = a + (n−1)d; **AP sum:** Sₙ = (n/2)[2a + (n−1)d].
- **GP nth term:** aₙ = a·rⁿ⁻¹; **GP sum:** Sₙ = a(1−rⁿ)/(1−r); **infinite GP sum** S∞ = a/(1−r) applies only when |r| < 1.

| Identity | Expanded form |
| --- | --- |
| (a + b)² | a² + 2ab + b² |
| (a − b)² | a² − 2ab + b² |
| a² − b² | (a + b)(a − b) |
| a³ − b³ | (a − b)(a² + ab + b²) |

### 🟡 Standard — Regular Study (2d–2mo)
> Standard content for students with a few days to months.

#### Linear and Quadratic Equations
A **linear equation** in one variable has the form ax + b = 0, solved as x = −b/a. Two-variable systems use substitution or elimination: express one variable from the first equation and substitute into the second.

A **quadratic equation** ax² + bx + c = 0 (with a ≠ 0) is solved by factorization when roots are rational, by completing the square, or by the quadratic formula. The **discriminant** Δ = b² − 4ac tells you the **nature of roots** without solving: Δ > 0 gives two distinct real roots, Δ = 0 gives equal roots, Δ < 0 gives complex conjugate roots.

#### Algebraic Identities
Master the standard identities because CLAT questions in many papers test direct expansion or reverse factorisation.

- (a + b)² = a² + 2ab + b²
- (a − b)² = a² − 2ab + b²
- (a + b)(a − b) = a² − b²
- (a + b + c)² = a² + b² + c² + 2ab + 2bc + 2ca
- a³ ± b³ = (a ± b)(a² ∓ ab + b²)

#### Progressions
In an **Arithmetic Progression**, the common difference d = aₙ₊₁ − aₙ. Use aₙ = a + (n−1)d and Sₙ = (n/2)(2a + (n−1)d). In a **Geometric Progression**, the common ratio r = aₙ₊₁ / aₙ. Use aₙ = a·rⁿ⁻¹ and Sₙ = a(1−rⁿ)/(1−r) for r ≠ 1.

#### Inequalities
Solve linear inequalities on the number line. **Critical rule:** multiplying or dividing both sides by a negative number **flips** the inequality sign.

| Equation type | Standard form | Solution method |
| --- | --- | --- |
| Linear (one variable) | ax + b = 0 | x = −b/a |
| Linear (two variables) | a₁x + b₁y = c₁, a₂x + b₂y = c₂ | Substitution / elimination |
| Quadratic | ax² + bx + c = 0 | Factorisation, completing the square, or quadratic formula |
| Linear inequality | ax + b > 0 | Isolate x; flip sign if dividing by negative a |

### 🔴 Extended — Deep Study (3mo+)
> Comprehensive coverage for students on a longer study timeline.

#### Edge Cases and Common Traps
CLAT setters exploit specific slips. Track these deliberately:

- **Sign flip on division by negative:** solving −3x > 9 gives x < −3, not x > −3.
- **Discriminant as a sign-test only:** Δ tells you the *nature* of roots, not their value. A common wrong step is solving b² − 4ac = 0 to "find" the root.
- **AP vs GP confusion:** AP uses additive difference d; GP uses multiplicative ratio r. Mixing them produces nonsense answers.
- **Expansion sign errors:** (a − b)² = a² − 2ab + b², not a² + b². (a − b)³ = a³ − 3a²b + 3ab² − b³, with alternating signs.
- **Infinite GP sum:** S∞ = a/(1−r) is valid **only** when |r| < 1. For |r| ≥ 1 the series diverges.
- **Word-problem translation:** assign the variable to the *unknown quantity* (e.g., let x be the age of the younger sibling), then translate each sentence into an equation.

#### Worked Example
Find two consecutive positive integers whose product is 156.

Let the integers be n and n + 1. Then n(n + 1) = 156 → n² + n − 156 = 0. The discriminant Δ = 1 + 624 = 625 = 25². So n = (−1 + 25)/2 = 12. The integers are **12 and 13**.

#### Connections to Adjacent Topics
Algebra links tightly with **percentages**, **ratios**, and **simple interest** in CLAT word problems, and with **number system** problems on divisibility. Discriminant analysis feeds directly into coordinate geometry questions on parabola intersections.

#### Practice Prompts
1. If α and β are roots of x² − 7x + 12 = 0, find α² + β² without solving for α and β (use α + β = 7, αβ = 12).
2. The 4th term of a GP is 8 and the 7th term is 64; find the common ratio and the first term.

#### Exam Strategy for CLAT
Algebra contributes roughly 4% of the CLAT paper, in standard papers appearing as 4–6 MCQs in the Quantitative Techniques section. Target 45–60 seconds per question: identify the identity or formula, substitute, compute. Skip and return if a question demands lengthy computation — the section is not scored negatively for unattempted items in CLAT's current marking scheme, so accuracy beats coverage.
