# Logical Sequences

### 🟢 Lite — Quick Review (1h–1d)

A logical sequence is an ordered progression of numbers, letters, symbols, or alphanumeric clusters governed by an invariant underlying transformation rule.

Core Progression Rules:
- Arithmetic Progression (AP): Constant common difference $d = a_{n} - a_{n-1}$. General term:
$$a_n = a_1 + (n - 1)d$$
- Geometric Progression (GP): Constant common ratio $r = \frac{a_n}{a_{n-1}}$. General term:
$$a_n = a_1 \cdot r^{n-1}$$
- Difference Series: When consecutive differences $\Delta_1 = a_{n+1} - a_n$ form an AP, the underlying sequence is quadratic ($a_n = A n^2 + B n + C$). When second differences $\Delta_2$ are constant, third differences are zero.
- Fibonacci and Recursive Series: Each term is the sum of preceding terms:
$$F_n = F_{n-1} + F_{n-2}$$

Alphabetical Mapping Rules:
- Forward Position: $A = 1, B = 2, C = 3, \dots, Z = 26$.
- Reverse Position: $Z = 1, Y = 2, X = 3, \dots, A = 26$.
- Complementary (Opposite) Pairs: The sum of forward positions of opposite letter pairs equals exactly $27$:
$$\text{Opposite Position} = 27 - p$$
Examples: $A(1) \leftrightarrow Z(26)$, $B(2) \leftrightarrow Y(25)$, $C(3) \leftrightarrow X(24)$, $D(4) \leftrightarrow W(23)$, $M(13) \leftrightarrow N(14)$.

⚡ **CLAT Exam Strategy:** Always confirm the identified transformation rule across at least three consecutive terms before extrapolating the answer. Test for interleaved alternating patterns if first differences show non-monotonic fluctuation.

### 🟡 Standard — Regular Study (2d–2mo)

CLAT Logical Reasoning evaluates sequence identification under time pressure. Systematic classification isolates the governing operation rapidly.

#### 1. Comparison of Common Sequence Architectures

| Pattern Architecture | Diagnostic Test | Governing Mathematical Relation | Representative Example |
| :--- | :--- | :--- | :--- |
| **Arithmetic Progression** | First differences are equal | $a_n = a_1 + (n - 1)d$ | $8, 15, 22, 29, 36 \implies d = +7$ |
| **Geometric Progression** | Ratios of consecutive terms are equal | $a_n = a_1 \cdot r^{n-1}$ | $5, 15, 45, 135 \implies r = 3$ |
| **Quadratic Difference** | Second differences are constant | $a_n = A n^2 + B n + C$ | $2, 5, 10, 17, 26 \implies \Delta_1 = 3, 5, 7, 9; \Delta_2 = 2$ |
| **Cubic Difference** | Third differences are constant | $a_n = A n^3 + B n^2 + C n + D$ | $2, 9, 28, 65, 126 \implies n^3 + 1$ |
| **Interleaved / Alternating** | Alternating rise and fall in magnitudes | Two distinct sub-series in odd/even slots | $3, 20, 6, 17, 9, 14 \implies (3, 6, 9 \dots)$ and $(20, 17, 14 \dots)$ |
| **Recursive / Fibonacci** | Term equals sum of prior terms | $a_n = a_{n-1} + a_{n-2}$ | $4, 7, 11, 18, 29, 47 \implies 18 + 29 = 47$ |
| **Digit Operation** | Non-algebraic term shifts | Operations on individual digits | $19, 28, 37, 46 \implies \text{digit sum } = 10$ |

#### 2. Letter and Alphanumeric Shift Logic

When letters appear in series, convert each letter to its numerical equivalent using the five-letter benchmark word **EJOTY** ($E = 5, J = 10, O = 15, T = 20, Y = 25$):
- Shift by constant stride: $B(2) \xrightarrow{+3} E(5) \xrightarrow{+3} H(8) \xrightarrow{+3} K(11)$.
- Shift by increasing stride: $A(1) \xrightarrow{+2} C(3) \xrightarrow{+3} F(6) \xrightarrow{+4} J(10) \xrightarrow{+5} O(15)$.
- Reverse cycle (wraparound): $B(2) \xrightarrow{-4} X(24)$ because $2 - 4 = -2 \equiv 26 - 2 = 24$.

#### 3. Step-by-Step Worked Example: Combined Operation Series

**Problem:** Find the missing number in the following sequence:
$$7, 16, 41, 90, 171, ?$$

**Solution Steps:**
1. Compute the first-order differences ($\Delta_1$) between consecutive terms:
$$16 - 7 = 9$$
$$41 - 16 = 25$$
$$90 - 41 = 49$$
$$171 - 90 = 81$$
2. Inspect the sequence of differences:
$$\Delta_1 = 9, 25, 49, 81$$
3. Recognize that these are squares of consecutive odd integers:
$$9 = 3^2, \quad 25 = 5^2, \quad 49 = 7^2, \quad 81 = 9^2$$
4. The next difference in this progression must be $11^2$:
$$\Delta_{next} = 11^2 = 121$$
5. Add this difference to the last known term:
$$\text{Next Term} = 171 + 121 = 292$$

#### 2. Step-by-Step Worked Example: Odd-Term Identification

**Problem:** One term in the following series does not conform to the governing rule. Identify the incorrect term and determine the replacement value:
$$3, 7, 15, 39, 63, 127$$

**Solution Steps:**
1. Examine the relationship between consecutive terms:
$$3 \times 2 + 1 = 7$$
$$7 \times 2 + 1 = 15$$
$$15 \times 2 + 1 = 31 \ne 39$$
2. Test whether the subsequent terms conform if $31$ replaces $39$:
$$31 \times 2 + 1 = 63$$
$$63 \times 2 + 1 = 127$$
3. All terms ($3, 7, 15, 63, 127$) satisfy the recursive function $a_n = 2a_{n-1} + 1$.
4. The erroneous term is $39$, and the correct replacement is $31$.
