# Statistics and Probability — Kuwait Secondary Certificate Mathematics Notes

Statistics and Probability is the fourth terminal-level domain at the Kuwait Secondary Certificate, with the Kuwait MOE Mathematics curriculum allocating substantial marks to descriptive statistics (mean, median, mode, variance, standard deviation), frequency distributions, regression and correlation, and probability rules including conditional probability. This domain integrates with the Sciences track curriculum at terminal level.

### 🟢 Lite — Quick Review (1h–1d)

#### Core facts in one pass

- **Mean of n numbers:** x̄ = (x₁ + x₂ + ... + xₙ) / n.
- **Median:** the middle value when the data are ordered (or the mean of the two middle values for even n).
- **Mode:** the most frequent value (a dataset may be unimodal, bimodal or have no mode).
- **Variance:** σ² = Σ(xᵢ − x̄)² / n for a population, s² = Σ(xᵢ − x̄)² / (n − 1) for a sample.
- **Standard deviation:** σ = √σ² (or s for a sample).
- **Probability of an event:** P(A) = (number of favourable outcomes) / (total number of outcomes), assuming equally likely outcomes.
- **Complement:** P(not A) = 1 − P(A).
- **Conditional probability:** P(A | B) = P(A and B) / P(B).
- **Independent events:** P(A and B) = P(A) × P(B).

#### Examiner traps

- Using the population variance formula on a sample (or vice versa) — terminal items specify which.
- Forgetting to subtract 1 from n when computing the sample variance.
- Confusing "at least one" with "exactly one" on probability items — read the question carefully.

### 🟡 Standard — Regular Study (2d–2mo)

#### Frequency distributions

For grouped data, compute the mean using the midpoints of the class intervals weighted by their frequencies. The mode of grouped data is the modal class interval. The median is found by locating the (n/2)th value in the cumulative frequency curve.

For continuous frequency distributions, plot the cumulative frequency curve (ogive) and read off the median, the lower quartile (Q1, at n/4) and the upper quartile (Q3, at 3n/4). The interquartile range is Q3 − Q1, which is a robust measure of spread that is not affected by outliers.

#### Regression and correlation

The least-squares regression line of y on x is y = a + bx, where b = (Σ(xᵢ − x̄)(yᵢ − ȳ)) / Σ(xᵢ − x̄)², and a = ȳ − b x̄. This line minimises the sum of squared vertical distances from the points to the line.

The Pearson correlation coefficient r = Σ(xᵢ − x̄)(yᵢ − ȳ) / √(Σ(xᵢ − x̄)² Σ(yᵢ − ȳ)²) lies in [−1, 1]. r = 1 indicates a perfect positive linear relationship, r = −1 a perfect negative one, r = 0 no linear relationship. Note that r measures linear correlation only — a quadratic relationship can have r = 0.

#### Probability rules

For events A and B:

- **Addition rule:** P(A or B) = P(A) + P(B) − P(A and B).
- **Multiplication rule:** P(A and B) = P(A) × P(B | A) = P(B) × P(A | B).
- **Independent events:** P(A and B) = P(A) × P(B) when the events are independent, so P(A | B) = P(A).
- **Bayes' theorem:** P(A | B) = P(B | A) × P(A) / P(B).

#### Counting and combinatorics

- **Permutation** (order matters): P(n, r) = n! / (n − r)!.
- **Combination** (order doesn't): C(n, r) = n! / [r! (n − r)!].
- **Permutation with repetition:** n! / (n₁! n₂! ... nₖ!) for arrangements of n items with multiplicities.

#### Expectation

The expected value of a discrete random variable X is E(X) = Σ xᵢ P(X = xᵢ). It is the long-run mean of X. For a binomial random variable X ~ B(n, p), E(X) = np. For a Poisson random variable X ~ Po(λ), E(X) = λ.

### 🔴 Deep — Long-Term Mastery (1mo–6mo)

#### Where Statistics and Probability appears across the terminal exam

- **Paper 1:** mean/median/mode from a small dataset, a probability tree diagram, basic conditional probability.
- **Paper 2:** grouped-data calculations (mean from midpoints, median from cumulative frequency), regression line by least squares, Bayes' theorem with three events, binomial distribution problems.

#### Common misconceptions (and the correction)

- "A correlation of 0.8 implies causation." No — correlation measures association, not cause. Two variables can be correlated because of a confounder.
- "P(A | B) means A given B has happened." Yes, but P(A | B) ≠ P(B | A) in general. The prosecutor's fallacy is the classic confusion of the two.
- "Variance is in the same units as the data." No — variance is in squared units. Standard deviation is in the original units and is the typical summary statistic.
- "A binomial distribution requires the events to be ordered." No — it requires a fixed number of independent trials, each with the same success probability.

#### Exam technique

- For grouped-data mean calculations, write the midpoints and the frequency × midpoint products in a table — the table is the method mark.
- For probability tree problems, label every branch with a probability and every outcome — the labelled tree is the method mark.
- For Bayes' theorem, write the unconditional probabilities before the conditional — the prior P(A) is the method mark.
