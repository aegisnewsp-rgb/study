# Introduction to LSAT Analytical Reasoning

### 🟢 Lite — Quick Review (1h–1d)
> Rapid summary for last-minute revision before your exam.

LSAT Analytical Reasoning, commonly called **Logic Games**, tests whether you can derive conclusions from a finite set of stated relationships. The passage gives the only permitted facts; outside knowledge cannot supply an answer.

| Feature | What to identify |
| --- | --- |
| Entities | The people, objects, positions, or time slots being arranged |
| Rules | Fixed, conditional, grouping, matching, or spatial constraints |
| Diagram | A compact record of permitted and excluded relationships |
| Question target | What must, can, or cannot be true |

- **Fixed rule:** Directly limits a position, group, or pairing, such as “A is second.”
- **Conditional rule:** Uses a condition, such as “If A is selected, B must also be selected.”
- Contrapositive logic applies: “If A then B” also means **“if not B, then not A.”**
- For **Can Be True** questions, exactly one option must work; the other four must fail.
- Plan roughly **8–9 minutes per game**, including reading, diagramming, and answering.

### 🟡 Standard — Regular Study (2d–2mo)
> Standard content for students with a few days to months.

#### Game Structure and Canonical Types

A Logic Game defines **entities** and a finite system of constraints. Entities can be people, projects, seats, days, or boxes. The rules determine which arrangements are legally possible, and every answer must follow the entire setup.

| Game type | Governing relationship |
| --- | --- |
| Ordering | Entities occupy ranked positions, such as first through sixth |
| Grouping | Entities enter groups with membership or distribution rules |
| Matching | Entities connect across categories, such as people to assignments |
| Spatial or path | Entities occupy locations or follow connected routes |

LSAT India normally presents **one game with about 5–6 questions**, so precision matters more than breadth. A master diagram should capture fixed positions, memberships, pairings, blocks, and exclusions. Add a second sketch only when a branching possibility creates two or more materially different cases.

#### Rules and Deductions

A fixed rule applies without a stated condition. In “M is third,” M occupies that position in every valid arrangement. A conditional rule triggers a consequence only after its condition is met.

If a rule says, “If R is selected, S is selected,” then:

- Selecting R requires selecting S.
- Omitting S requires omitting R.
- Selecting S does **not** require selecting R unless reciprocity is separately stated.

Combine these implications into inference chains. A rule such as “If P then Q; if Q then R” permits P → R, but not R → P. Negative deductions in many papers control the answer set.

#### Question Stems and Common Errors

| Stem | Correct test |
| --- | --- |
| Must Be True | The statement holds in every legal arrangement |
| Must Be False | Its opposite holds in every legal arrangement |
| Can Be True | At least one legal arrangement supports it |
| Cannot Be True | No legal arrangement supports it |

1. Circle the modal phrase before examining choices.
2. Test each option against the complete rule set, not merely the drawn base case.
3. For a can-be-true option, build one valid example; for a must-be-true option, seek a counterexample.
4. If two options seem identical, compare whether a rule affects both entities identically.
5. Abandon a question that consumes disproportionate time and protect the remaining questions.

### 🔴 Extended — Deep Study (3mo+)
> Comprehensive coverage for students on a longer study timeline.

#### Diagramming and Case Management

A useful diagram separates **given information** from **derived information**. Use placeholders for every entity before reading the rules, then mark fixed relationships immediately. Record a conditional arrow and its contrapositive, but add reverse implications only when the rules support them.

A split diagram becomes necessary when no single position or grouping pattern satisfies every condition. Keep each branch structurally complete; an incomplete branch can turn a must-be statement into a false positive. A combine sketch can later merge branches when new deductions eliminate their differences.

| Strategy | Best use | Main warning |
| --- | --- | --- |
| Master diagram | Preserve the full rule set | Crowding can hide contradictions |
| Sketch | Explore a limited number of cases | Do not infer global necessity from one branch |
| Split | Represent mutually exclusive possibilities | Complete every branch |
| Combine | Merge branches after shared deductions | Preserve facts that differ between cases |

#### Worked Reasoning

Suppose five speakers, P, Q, R, S, and T, speak in order. Rule 1 places P immediately before Q. Rule 2 says that if R speaks fourth, then S speaks fifth. Rule 3 excludes T from the fifth position.

We can deduce P–Q occupy adjacent spots, with P immediately before Q. From Rule 2, if S is not fifth, R cannot be fourth. Also, T cannot occupy the slot needed by S when S is fifth.

For a Can Be True question, one valid order is Q, P, R, S, T. It satisfies adjacency, the conditional because R is fourth and S is fifth, and the exclusion of T from fifth. If four options fail, that remaining legal order identifies the answer.

#### Practice Prompts

1. A project has six slots, X immediately precedes Y, and Z cannot occupy the last two positions. Determine whether X must occupy the fourth position.
2. A committee has three members, “A joins only if B joins,” and C is selected if neither joins. Test whether both “A and B join” and “only C joins” can be true in different scenarios.

Avoid assuming symmetry, treating a sufficient condition as necessary, or reading a conditional rule outside its scope. During timed practice, use approximately **8–9 minutes per game**; LSAT India places limited weight here, so consistency protects scores in the larger sections.
