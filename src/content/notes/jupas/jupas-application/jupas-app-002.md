# Programme Choices — Band A, Band B, Band C — JUPAS Notes

This topic covers the JUPAS programme-choice system. Each applicant may list up to 20 programme choices, with each institution/programme listed once, grouped into three bands: Band A (free choice), Band B (free choice), and Band C (free choice). Within a band, programme choices are treated as equally ranked; only between-band ordering matters. Choice ordering is critical because Main Round offers are determined by the highest band in which a programme admits the applicant.

> Verify the live JUPAS choice-ordering rules on https://www.jupas.edu.hk/ before planning revision.

### 🟢 Lite — Quick Review (1h–1d)

#### Core facts in one pass

- **Maximum 20 choices**: each applicant may list up to 20 programme choices in total.
- **Three bands**: Band A (free choice), Band B (free choice), Band C (free choice). Each institution/programme can be listed once.
- **Within a band**: choices are equally ranked. Band A is not "first choice" — only the band ordering matters.
- **Between bands**: ordering matters. Band A choices are considered before Band B choices.
- **Main Round offer rule**: each applicant receives at most ONE Main Round offer — the offer is determined by the highest band in which a programme admits the applicant.

#### Examiner traps

- Listing the same institution/programme twice in different bands — JUPAS rejects duplicate entries.
- Treating Band A as "first choice" — within a band, choices are equally ranked.

### 🟡 Standard — Regular Study (2d–2mo)

#### How the band system works

The JUPAS system uses a band-based choice system:

- **Band A** (free choice): the applicant lists their most preferred programmes here.
- **Band B** (free choice): programmes the applicant would be happy to attend if no Band A programme admits them.
- **Band C** (free choice): safety programmes — programmes the applicant would accept as a last resort.

Within each band, the order of choices does not matter. Between bands, Band A is processed first; if the applicant is not admitted to any Band A programme, JUPAS moves to Band B, and so on.

Each institution/programme can be listed once. Listing the same programme in two different bands is rejected.

#### Strategy for programme choices

**Band A strategy**: include the most ambitious programmes — those the applicant hopes to be admitted to based on their expected grades. Examples: top-tier programmes at HKU, HKUST, CUHK.

**Band B strategy**: include realistic programmes — programmes the applicant is likely to be admitted to based on their predicted grades. Examples: mid-tier programmes at the UGC-funded institutions.

**Band C strategy**: include safety programmes — programmes with admission scores clearly below the applicant's predicted grades. These should be programmes the applicant would actually accept if offered.

Common mistakes:

- Listing too many ambitious programmes in Band A (low admission probability for all).
- Listing safety programmes in Band A (no upside if admitted).
- Listing programmes the applicant would not actually accept in any band.

#### How the Main Round offer is determined

JUPAS processes applicants in order of the highest-scoring programme for which the applicant is eligible. For each applicant:

1. Check Band A choices in any order (within band, no order). If any Band A programme admits the applicant → offer that programme.
2. If no Band A admission, check Band B in any order. If any Band B programme admits the applicant → offer that programme.
3. If no Band A or Band B admission, check Band C in any order. If any Band C programme admits the applicant → offer that programme.
4. If no Band C admission → no Main Round offer. The applicant may participate in Clearing Round.

Each applicant receives at most ONE Main Round offer, regardless of how many programmes admit them.

#### Choice modification

Choices can be modified:

- **Freely before HKDSE release**: any number of modifications, no restrictions.
- **During the 48-hour modification slot** (mid-July 2026 for the 2026 cycle): within the allocated time slot only.
- **Clearing Round**: choices may be modified before Clearing Round (subject to published rules).

Strategy for modification after HKDSE release:

- **Re-rank based on actual results**: if actual results are weaker than predicted, move some Band A programmes to Band B.
- **Consider band boundaries**: move safety programmes to a higher band if results are strong, or vice versa.
- **Check programme-specific prerequisites**: if results fall below a minimum entrance requirement, the programme becomes ineligible.

#### Exam technique

- **For "explain the band system" questions**: describe the within-band and between-band ranking; state the offer rule.
- **For "strategy" questions**: describe the Band A/B/C approach; cite common mistakes.

#### Common misconceptions (and the correction)

- "Band A is the first choice list." Within a band, choices are equally ranked; band ordering matters, not within-band ordering.
- "Listing 20 programmes guarantees a place." No — the applicant is admitted only if at least one programme's admission score is met.
- "JUPAS sorts choices by predicted grades." JUPAS does not sort choices; the applicant chooses the order.
