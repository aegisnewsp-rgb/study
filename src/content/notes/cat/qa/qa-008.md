# Functions

### 🟢 Lite — Quick Review (1h–1d)

A mathematical function $f: A \to B$ is a well-defined rule assigning each element in domain set $A$ to exactly one element in codomain set $B$.

Core Definitions:
- Domain ($A$): The complete set of permissible real input values $x$ for which $f(x)$ is defined and real.
- Codomain ($B$): The target set containing all potential outputs.
- Range ($R_f$): The actual set of outputs achieved by the mapping: $R_f = \{f(x) \mid x \in A\} \subseteq B$.
- Vertical Line Test: A curve in the Cartesian plane represents a function if and only if every vertical line intersects the curve at most once.

Fundamental Structural Properties:
- Injective (One-to-One): Different domain elements produce different outputs:
$$f(x_1) = f(x_2) \implies x_1 = x_2$$
A strictly monotonic function (always increasing or always decreasing) is always injective.
- Surjective (Onto): Every element in codomain $B$ is an output: $\text{Range} = \text{Codomain}$.
- Bijective (One-to-One and Onto): Both injective and surjective. A function admits an inverse $f^{-1}(x)$ if and only if it is bijective.
- Symmetries:
  - Even Function: $f(-x) = f(x)$ $\implies$ symmetric about the $y$-axis.
  - Odd Function: $f(-x) = -f(x)$ $\implies$ symmetric about the origin $(0, 0)$.

⚡ **CAT Exam Strategy:** The graph of the inverse function $y = f^{-1}(x)$ is the exact geometric reflection of $y = f(x)$ across the line of symmetry $y = x$. If point $(a, b)$ lies on the curve of $f$, then point $(b, a)$ must lie on the curve of $f^{-1}$.

### 🟡 Standard — Regular Study (2d–2mo)

CAT Quantitative Aptitude questions emphasize domain-range constraints, composite evaluations, and algebraic inversions.

#### 1. Comparison of Function Classifications

| Mapping Type | Formal Definition | Graphical Characteristic | Invertibility Status |
| :--- | :--- | :--- | :--- |
| **Injective (One-to-One)** | $f(a) = f(b) \implies a = b$ | Passes Horizontal Line Test (at most 1 intersection) | Invertible only onto its range |
| **Many-to-One** | Multiple inputs yield identical output | Horizontal line intersects at multiple points | Not invertible |
| **Surjective (Onto)** | $\text{Range} = \text{Codomain}$ | Projected range covers codomain entirely | Invertible only if also injective |
| **Bijective** | Injective and Surjective simultaneously | Monotonic and covers codomain without gaps | Strictly invertible everywhere |

#### 2. Domain and Range Evaluation Rules

To determine domain, apply real-variable constraints simultaneously:
1. Denominators cannot equal zero: In $\frac{P(x)}{Q(x)}$, require $Q(x) \ne 0$.
2. Even radical radicands must be non-negative: In $\sqrt[2k]{g(x)}$, require $g(x) \ge 0$.
3. Logarithm arguments must be strictly positive with positive base not equal to $1$: In $\log_b(h(x))$, require $h(x) > 0, b > 0, b \ne 1$.

#### 3. Step-by-Step Worked Example: Domain and Range Determination

**Problem:** Determine the domain and range of the real-valued function:
$$f(x) = \sqrt{\frac{x - 2}{x + 3}}$$

**Solution Steps:**
1. Formulate domain inequality: Radicand must be non-negative, and denominator cannot equal zero:
$$\frac{x - 2}{x + 3} \ge 0 \quad \text{and} \quad x + 3 \ne 0$$
2. Identify critical transition points on the real number line: $x = -3$ and $x = 2$.
3. Use the wavy-curve (sign) analysis:
   - For $x > 2$: $(+)/(+) > 0$ (valid).
   - For $-3 < x < 2$: $( - )/(+) < 0$ (invalid).
   - For $x < -3$: $( - )/( - ) > 0$ (valid).
   - At $x = 2$: numerator is $0 \implies 0 \ge 0$ (valid).
   - At $x = -3$: denominator is $0$ (strictly excluded).
4. Domain:
$$\text{Domain} = (-\infty, -3) \cup [2, \infty)$$
5. Determine Range: Let $y = \sqrt{\frac{x - 2}{x + 3}} \ge 0$.
Square both sides:
$$y^2 = \frac{x - 2}{x + 3} \implies y^2(x + 3) = x - 2 \implies x y^2 + 3y^2 = x - 2$$
$$x(y^2 - 1) = -2 - 3y^2 \implies x = \frac{3y^2 + 2}{1 - y^2}$$
6. For real $x$, denominator cannot equal zero: $1 - y^2 \ne 0 \implies y \ne 1$.
Because $y$ represents a principal non-negative square root, $y \ge 0$.
7. Range:
$$\text{Range} = [0, 1) \cup (1, \infty)$$

### 🔴 Extended — Deep Study (3mo+)

Extended study targets functional equations, recurrent iteration cycles, and composite graph shifts.

#### 1. Canonical Functional Equations

| Functional Relation | Invariant Analytical Solution | Physical / Mathematical Parallel |
| :--- | :--- | :--- |
| **$f(x + y) = f(x) + f(y)$** | $f(x) = c x$ ($c = f(1)$) | Cauchy additive equation (linear scaling) |
| **$f(x + y) = f(x) \cdot f(y)$** | $f(x) = a^x = [f(1)]^x$ | Exponential growth laws |
| **$f(x \cdot y) = f(x) + f(y)$** | $f(x) = c \ln x$ | Logarithmic transformation |
| **$f(x \cdot y) = f(x) \cdot f(y)$** | $f(x) = x^k$ | Power law |
| **$f(x) + f\left(\frac{1}{x}\right) = f(x) \cdot f\left(\frac{1}{x}\right)$** | $f(x) = 1 \pm x^n$ | High-frequency CAT polynomial equation |

#### 2. Graphical Transformation Algebra

| Transformation | Geometric Operation on Curve $y = f(x)$ |
| :--- | :--- |
| **$y = f(x) + k$** | Vertical translation upward by $k$ units |
| **$y = f(x - h)$** | Horizontal translation rightward by $h$ units |
| **$y = f(-x)$** | Reflection across the vertical $y$-axis |
| **$y = -f(x)$** | Reflection across the horizontal $x$-axis |
| **$y = |f(x)|$** | Retain portion where $y \ge 0$; reflect portion where $y < 0$ upward across $x$-axis |
| **$y = f(|x|)$** | Erase portion where $x < 0$; replicate portion where $x \ge 0$ symmetrically across $y$-axis |

#### 3. Step-by-Step Worked Example: Exponential Functional Equation

**Problem:** A function $f(x)$ defined for all positive integers satisfies $f(x + y) = f(x) \cdot f(y)$. If $f(1) = 3$ and $\sum_{k=1}^n f(k) = 3279$, calculate the integer value of $n$.

**Solution Steps:**
1. Identify the functional form: $f(x + y) = f(x) \cdot f(y)$ with $f(1) = 3$.
2. Compute consecutive values:
   - $f(2) = f(1 + 1) = f(1) \cdot f(1) = 3^2 = 9$.
   - $f(3) = f(2 + 1) = f(2) \cdot f(1) = 3^3 = 27$.
   - In general: $f(k) = 3^k$.
3. The sum forms a geometric progression:
$$S_n = \sum_{k=1}^n 3^k = 3 + 3^2 + 3^3 + \dots + 3^n$$
4. Apply the finite sum formula for a GP with first term $a = 3$ and common ratio $r = 3$:
$$S_n = \frac{a(r^n - 1)}{r - 1} = \frac{3(3^n - 1)}{3 - 1} = \frac{3(3^n - 1)}{2}$$
5. Set the expression equal to $3279$:
$$\frac{3(3^n - 1)}{2} = 3279$$
$$3(3^n - 1) = 6558 \implies 3^n - 1 = \frac{6558}{3} = 2186$$
$$3^n = 2187$$
6. Express $2187$ as a power of $3$:
$$3^1 = 3, \quad 3^2 = 9, \quad 3^3 = 27, \quad 3^4 = 81, \quad 3^5 = 243, \quad 3^6 = 729, \quad 3^7 = 2187$$
7. Therefore:
$$n = 7$$
