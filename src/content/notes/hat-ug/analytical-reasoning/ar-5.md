# Classification and Odd One Out

### 🟢 Lite — Quick Review (1h–1d)
> Rapid summary for last-minute revision before your exam.

**Classification** groups items by a shared defining property; **Odd One Out** locates the single item that breaks the rule shared by the rest. In HAT-UG, these appear as 3–5 questions in the Analytical Reasoning section, in most keys with four options (A–D) where three obey one rule and one violates it. Always identify the rule of the largest homogeneous subset first, then test each candidate against it.

- The "odd" item in standard papers shares **one superficial feature** with the group but fails the **dominant conceptual rule** (e.g., living/non-living, kingdom, function).
- Multiple classifications can apply; the **strongest answer** is the rule that excludes exactly one item.
- Quick scoring: most items take 30–60 seconds if the underlying property is recognised.

### 🟡 Standard — Regular Study (2d–2mo)
> Standard content for students with a few days to months.

#### The Two Operations

Classification is **inclusive grouping**: items enter a category because they share a defining attribute (origin, function, structure, class). Odd One Out is the **inverse**: build the group, then locate the exception. In HAT-UG, both operations are tested with four-item sets, in many papers drawn from biology, chemistry, everyday objects, or word relationships.

#### Bases for Classification

Examiners draw sets from a limited pool of rules. Recognising the rule is half the answer.

| Basis | Example grouping |
| --- | --- |
| Living vs non-living | Dog, rose, mushroom / chair, water |
| Kingdom | Lion, eagle, shark (Animalia) / oak, fern (Plantae) |
| Function | Knife, scissors, saw (cutting tools) |
| Origin / source | Cotton, jute, wool (natural fibres) |
| Intrinsic property | Gold, silver, copper (metals) |

#### Solving Procedure

1. **Read all four items**; note any obvious pair or triplet that share a label.
2. **State the rule** in words (e.g., "three are metals").
3. **Test each remaining candidate** against that exact rule.
4. **Confirm** that the chosen odd item fails the rule that the other three satisfy, not a different one.

#### Common Mistakes

- Choosing by **superficial feature** (colour, size) when a conceptual rule applies.
- Stopping at the first plausible rule without checking whether **multiple rules** can single out different items; the correct rule excludes exactly one.

> Tip: if two items seem odd, the rule you picked is wrong — restart with a deeper property.

### 🔴 Extended — Deep Study (3mo+)
> Comprehensive coverage for students on a longer study timeline.

#### Distinguishing Necessary from Accidental Properties

A **necessary property** is essential to the category (a mammal must be warm-blooded, have hair, nurse young). An **accidental property** is incidental (a mammal can be white, large, or carnivorous — but these are not defining). Examiners exploit this by giving three items that share a *necessary* property plus the target, and one that shares only an *accidental* feature. Example: lion, tiger, wolf / cow. The cow is a mammal too, but the dominant rule is *carnivore*, which the cow violates; if the rule were *mammal*, no item would be odd, so the question would be flawed.

#### Multi-Rule Conflict Resolution

When more than one rule seems to isolate an item, apply the **maximal-homogeneity test**: pick the rule under which three items cluster most tightly, leaving one clearly distinct. HAT-UG items are designed so only one rule produces a clean 3-vs-1 split; weaker rules produce 2-vs-2 ambiguity.

| Scenario | Correct move |
| --- | --- |
| Two items differ on feature X | X is the wrong rule; try feature Y |
| Three items share rule, one shares a weaker feature | Weak feature is a distractor; rule still holds |
| All four items seem classifiable together | Re-read — one item in most keys belongs to a sub-class that excludes it |

#### Adjacent Topics and Connections

Classification links directly to **analogy** (shared relation type), **series completion** (pattern rule), and **coding-decoding** (consistent mapping). Mastering the rule-isolation step here transfers to those sections.

#### Practice Prompts

1. Identify the odd item and the rule: *rose, lotus, sunflower / mushroom*. (Answer: mushroom — fungi, not plant.)
2. In *hammer, saw, drill / microscope*, state the rule and verify the outlier. (Answer: microscope — not a carpentry tool.)

> Exam strategy: spend no more than 60 seconds per item; flag and return if two candidates seem valid.
