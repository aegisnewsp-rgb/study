# Computer Fundamentals

### 🟢 Lite — Quick Review (1h–1d)
> Rapid summary for last-minute revision before your exam.

A **computer** is an electronic device that accepts **input**, processes data through the **CPU (Central Processing Unit)**, produces **output**, and stores results in **memory**. The CPU contains the **ALU (Arithmetic Logic Unit)** for calculations and the **CU (Control Unit)** for instruction sequencing. Memory divides into **RAM (Random Access Memory)**, which is volatile and temporary, and **ROM (Read Only Memory)**, which is non-volatile and permanent. **Software** splits into **system software** (operating systems, device drivers) and **application software** (MS Word, browsers). Data is represented using **bits (0/1)** and **bytes (8 bits)**, with **ASCII (7-bit)** and **Unicode (16-bit)** encoding characters. Number systems — **binary (base-2)**, **octal (base-8)**, **decimal (base-10)**, **hexadecimal (base-16)** — are tested through conversions. Key conversions: **1 KB = 1024 Bytes**, **1 MB = 1024 KB**. **High-yield pointers:** remember RAM vs ROM volatility, compiler vs interpreter difference, and binary-to-decimal using positional weights (e.g., 1011₂ = 8+0+2+1 = 11).

### 🟡 Standard — Regular Study (2d–2mo)
> Standard content for students with a few days to months.

#### Computer Architecture and the IPO Cycle

Every computer follows the **Input–Process–Output (IPO) cycle**. Input devices (keyboard, mouse, scanner) feed data to the **CPU**, which executes instructions via the **ALU** and coordinates them through the **CU**. Output devices (monitor, printer) display results, while **storage** retains data across sessions. The **motherboard** is the printed circuit board that interconnects the CPU, memory slots, expansion slots, and peripheral ports through buses (data, address, control).

#### Memory Hierarchy

Memory is organised by the **speed-versus-capacity tradeoff**: **Registers** (fastest, smallest, inside the CPU) → **Cache memory** (L1/L2/L3, bridges CPU and RAM) → **Primary memory / RAM** (volatile working memory) → **Secondary storage** (HDD, SSD — non-volatile, large capacity). **ROM** retains firmware like BIOS; **EEPROM** allows electrical erasure. Conversion uses the binary multiplier: **1 KB = 1024 Bytes**, **1 MB = 1024 KB**, **1 GB = 1024 MB**, **1 TB = 1024 GB**.

#### Software Types

**System software** manages hardware and provides a platform for applications — examples are **Windows, Linux, macOS** (operating systems), **device drivers**, and **utility programs** (disk cleanup, antivirus). **Application software** performs user-specific tasks: **MS Excel** (spreadsheets), **Photoshop** (image editing), **Chrome** (browser). **Language translators** convert code: an **assembler** converts assembly to machine code, a **compiler** translates the entire high-level program before execution (producing object code, e.g., GCC for C), and an **interpreter** translates line-by-line at runtime (e.g., Python interpreter).

#### Number Systems and Data Representation

**Binary (base-2)** uses digits 0,1; **Octal (base-8)** uses 0–7; **Decimal (base-10)** uses 0–9; **Hexadecimal (base-16)** uses 0–9 and A–F. To convert binary to decimal, apply **Σ (digit × 2^position)** counting from the right at position 0. Example: (1 1 0 1)₂ = 8 + 4 + 0 + 1 = **13**₁₀. **ASCII** is a 7-bit code representing 128 English characters; **Unicode** (UTF-16/UTF-8) extends to over a million code points for global scripts.

#### Networks and the OS

**LAN** covers a small area (a building), **MAN** a city, **WAN** a country or globe (the Internet is the largest WAN). Common **topologies**: Star (central hub), Bus (single backbone cable), Ring (token passing), Mesh (every node interconnected). **OS functions** include **process scheduling**, **memory management**, **file system management**, and **access control**.

#### Exam Question Patterns

HAT-UG typically asks: (1) identify the volatile memory, (2) convert (1010)₂ to decimal — answer **10**, (3) match the translator to its function, (4) classify a given program as system or application software, (5) identify the topology from a diagram. These are direct-recall MCQs worth 1 mark each in the Subject Knowledge section.

### 🔴 Extended — Deep Study (3mo+)
> Comprehensive coverage for students on a longer study timeline.

#### Generations of Computers

The five generations track the underlying hardware: **1st (1940–1956)** — vacuum tubes (ENIAC, UNIVAC), huge and heat-intensive; **2nd (1956–1963)** — transistors, smaller and reliable; **3rd (1964–1971)** — Integrated Circuits (ICs), enabling minicomputers; **4th (1971–present)** — microprocessors (VLSI chips), leading to PCs; **5th (present/future)** — Artificial Intelligence and parallel processing. Expect HAT-UG to ask "Which generation used ICs?" — answer **Third Generation**.

#### Computer Networks and Protocols

**TCP/IP** is the foundational suite of the Internet; **HTTP/HTTPS** governs web traffic (HTTPS adds SSL/TLS encryption); **FTP** transfers files; **SMTP** sends emails. An **IP address** (IPv4: 32-bit, e.g., 192.168.1.1) identifies a device on a network; **DNS** translates domain names to IP addresses. A **firewall** filters traffic based on rules; **encryption** (symmetric AES, asymmetric RSA) secures data.

#### Cybersecurity Threats

**Malware** is malicious software: **viruses** attach to files and need a host, **worms** self-replicate across networks, **Trojans** disguise as legitimate software, **ransomware** encrypts files for payment. **Phishing** is social engineering — fraudulent emails or sites tricking users into revealing credentials. A **DoS (Denial of Service)** attack floods a server to disrupt service. Defences include antivirus software, multi-factor authentication, and regular patching.

#### Cloud Computing Models

**IaaS (Infrastructure as a Service)** provides virtualised hardware (AWS EC2); **PaaS (Platform as a Service)** offers a development platform (Google App Engine); **SaaS (Software as a Service)** delivers ready applications over the Internet (Gmail, Microsoft 365). **Public cloud** is shared, **private cloud** is single-organisation, **hybrid** combines both.

#### Common Mistakes

- Treating **1 KB as 1000 Bytes** — HAT-UG follows binary convention, so **1 KB = 1024 Bytes**.
- Confusing **compiler** (whole-program translation, faster execution) with **interpreter** (line-by-line, easier debugging).
- Saying RAM is permanent — RAM is **volatile**, only ROM is permanent.
- Confusing **phishing** (deception-based, no code execution needed) with **malware** (malicious code injection).

#### Worked Example

Convert (2F)₁₆ to decimal and then to binary.
- Hex → Decimal: 2 × 16¹ + 15 × 16⁰ = 32 + 15 = **47**.
- Decimal → Binary (divide by 2 repeatedly): 47 → 23 r1 → 11 r1 → 5 r1 → 2 r1 → 1 r0 → 0 r1. Read bottom-up: **(101111)₂**.
