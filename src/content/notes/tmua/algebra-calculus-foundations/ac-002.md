# MM5 Exponentials and Logarithms

MM5 is the shortest family in Section 1 Part 1 and it is entirely made of inverse operations. The specification lists three strands: the graph of $y = a^x$ for simple positive values of $a$, the laws of logarithms, and solving equations of the form $a^x = b$ including ones that need algebraic manipulation first.

Two facts about the paper shape everything here. There is no calculator, so you are never asked to evaluate $\log 7$ — you are asked to rearrange it. And the specification states explicitly that questions requiring the change of base formula will not be set. That single sentence tells you the entire exam convention: write everything in terms of the base you are given.

### 🟢 Lite — Quick Review (1h–1d)

> Logarithms are just exponents you have been handed sideways. Anything you can do to an index you can undo by logging it.

| You are given | You are really being told | Write it as |
|---|---|---|
| $a^b = c$ | $b$ is the power that turns $a$ into $c$ | $b = \log_a c$ |
| $\log_a x + \log_a y$ | Multiplication, in disguise | $\log_a(xy)$ |
| $\log_a x - \log_a y$ | Division, in disguise | $\log_a\!\left(\tfrac{x}{y}\right)$ |
| $k\log_a x$ | A power, in disguise | $\log_a(x^k)$ |
| $\log_a\!\left(\tfrac1x\right)$ | A negative power, in disguise | $-\log_a x$ |
| $\log_a a$ | The answer to $a^{?}=a$ | $1$ |

**The one question that decides the rest.** Given $a^x = b$, what do you write? $x = \log_a b$. Every method below is a route to getting an equation into that shape.

### 🟡 Standard — Regular Study (2d–2mo)

#### The graph of $y = a^x$

For every positive $a$, four features hold regardless of the base. The graph passes through $(0,1)$, because $a^0 = 1$. It is defined for all real $x$, so there is no domain to worry about. It never touches $y = 0$ — the range is strictly positive, and $y=0$ is a horizontal asymptote. And the only fixed point is $(1,a)$, since $a^1 = a$.

The base decides the direction. If $a > 1$ the graph rises; if $0 < a < 1$ it falls. Since the paper bans calculators, the bases you actually need are small: $2$, $3$, $\tfrac12$, $\tfrac13$. With $a = \tfrac12$ the graph passes through $(0,1)$, $(1,\tfrac12)$, $(2,\tfrac14)$, $(3,\tfrac18)$ and falls towards the axis — the mirror image of $y=2^x$ in the line $y = x$.

#### Solving $a^x = b$ when the bases do not match

Take $8^x = 4$. You cannot log this to a tidy number in the base you are given, but you can rewrite both sides in base $2$: $8^x = (2^3)^x = 2^{3x}$ and $4 = 2^2$. Since the exponential function is one-to-one, equal outputs mean equal exponents, so $3x = 2$ and $x = \tfrac23$.

A second specification example, $2^{x/3} = 4 = 2^2$, gives $\tfrac{x}{3} = 2$ and $x = 6$. Notice how different these two are: one needed a base change on both sides, the other only on one. Check $x=6$ by hand — $2^2 = 4$ ✓.

#### The substitution the specification asks for

The second worked example in MM5.3 is $5^{2x} - 3\cdot 5^x + 2 = 0$. This is a quadratic in disguise. Put $u = 5^x$, so $5^{2x} = u^2$ and $5^x = u$:

$$u^2 - 3u + 2 = 0 \implies (u-1)(u-2) = 0$$

So $u = 1$ or $u = 2$, giving $5^x = 1 \Rightarrow x = 0$, or $5^x = 2 \Rightarrow x = \log_5 2$. Two solutions, and the substitution is the entire trick — once $u = 5^x$ is in place you are back in MM1.

#### Which law, which way

The laws are reversible and that is worth internalising. "Multiplication becomes addition" means $\log_a x + \log_a y = \log_a(xy)$ in one direction and $\log_a(xy) = \log_a x + \log_a y$ in the other. If a question hands you $\log_a 6 + \log_a 7$, collapse it to $\log_a 42$ rather than reaching for decimals. If it hands you $\log_a 8$ and asks for a single logarithm, split it as $3\log_a 2$.

### 🔴 Deep — Mastery (3mo+)

#### Where the law list is not enough

Logarithms convert multiplication into addition, which makes them extraordinarily good at turning growth into something you can compare. If a population satisfies $P = P_0 a^t$ and the specification's Part 2 covers compound interest and growth-and-decay problems (M3.11), then an equation like "in what time does the quantity double?" is $2P_0 = P_0 a^t$, i.e. $a^t = 2$, i.e. $t = \log_a 2$. Every growth question reduces to that one line.

The same machinery explains halving. A sample decaying by a factor of $\tfrac12$ each period satisfies $\log_{1/2}\left(\tfrac14\right) = 2$, because $(1/2)^2 = 1/4$. Knowing that $\log_{1/2}$ flips direction is the same fact as knowing $0 < a < 1$ gives a falling graph.

#### The false rules that cost marks

Four non-rules are worth naming because each is a natural guess:

- $\log_a(x+y) \neq \log_a x + \log_a y$. Logs distribute over products, not sums.
- $a^x = a^y$ implies $x = y$ **only when $a > 0$ and $a \ne 1$**. At $a = 1$ the equation $1^x = 1$ holds for every $x$, so there is no solution to find and no $x$ to deduce.
- Taking the base-$a$ logarithm of both sides of an equation is only legitimate when both sides are strictly positive. $\log_a(-4)$ is not a real number, and an equation can carry you outside the domain without warning — $2^x + 1 = 0$ has no solution precisely because it never equals zero.
- Halving and doubling are not symmetric in the exponent for bases below 1. For $a = \tfrac12$, $\log_{1/2} 8 = -3$, and the negative sign is the falling graph showing up in the answer.

#### Solving backwards into $a^x = b$

Some items do not hand you the right form, and MM5.3 explicitly includes "equations which can be reduced to this form, including those that need prior algebraic manipulation". The workflow is: isolate the exponential term, then substitute. For $3\cdot 2^x - 5 = 19$, add 5 to get $3\cdot 2^x = 24$, divide by 3 to get $2^x = 8 = 2^3$, so $x = 3$. For $2^{x+1} = 32$, write $32 = 2^5$ on the right and $2^{x+1} = 2^5$ on the left, giving $x + 1 = 5$ and $x = 4$. The exponent never has to be evaluated; it only has to be matched.

### Common mistakes

Assuming change of base is available. The specification excludes it, so an answer containing $\log_7 3$ in a context where only base 2 or base 5 was given is a sign you missed a step.

Writing $x = \log_b a$ instead of $x = \log_a b$ for $a^x = b$.

Dropping the coefficient when substituting — turning $5^{2x}$ into $u$ instead of $u^2$.

Assuming $a^x = a^y \Rightarrow x = y$ without checking that $a \ne 1$.

Reading a falling exponential as increasing because the exponent is increasing.

Taking a logarithm of a term you have not shown to be positive.

Forgetting that $\log_a 1 = 0$ and $\log_a a = 1$, so $\log_5 1 = 0$ is a perfectly good answer.
