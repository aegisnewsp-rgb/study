# HKDSE Score Conversion Table — JUPAS Notes

This topic covers the HKDSE score conversion table used by JUPAS for ranking candidates. The 2025 entry onwards conversion applies to all JUPAS applicants. Category A Core and Elective subjects are converted to numeric scores: 5** = 8.5, 5* = 7, 5 = 5.5, 4 = 4, 3 = 3, 2 = 2, 1 = 1. Category B (Applied Learning) and Category C (Other Languages) subjects use a separate published conversion table.

> Verify the live conversion table on https://www.jupas.edu.hk/ before planning revision.

---

### 🟢 Lite — Quick Review (1h–1d)

#### Core facts in one pass

- **2025 entry conversion (Category A Core/Elective)**:
 - 5** = 8.5
 - 5* = 7
 - 5 = 5.5
 - 4 = 4
 - 3 = 3
 - 2 = 2
 - 1 = 1
- **Category B (Applied Learning)**: separate conversion (the simplest level "Attained" / N is converted to specific values, higher levels to higher numbers).
- **Category C (Other Languages)**: separate conversion (e.g. French, Japanese, Spanish — use the published Category C table).
- **Use**: the conversion is used for ranking only; HKDSE grades still appear on the certificate.
- **Source**: JUPAS score conversion is published in the 2025 JUPAS Admissions Scores report and on the JUPAS website.

#### Examiner traps

- Confusing the JUPAS conversion with the HKDSE grade — they are different.
- Treating "5**" as 9.0 in the JUPAS conversion — it is 8.5.

### 🟡 Standard — Regular Study (2d–2mo)

#### Category A conversion table

The 2025 entry JUPAS conversion for Category A Core and Elective subjects is:

| HKDSE Grade | JUPAS Score |
|--------------|--------------|
| 5** | 8.5 |
| 5* | 7 |
| 5 | 5.5 |
| 4 | 4 |
| 3 | 3 |
| 2 | 2 |
| 1 | 1 |

The conversion is applied to each Category A subject separately. The admission score for a programme is calculated using the programme-specific scoring formula, applied to the converted scores.

#### Category B (Applied Learning) conversion

Category B subjects are Applied Learning (ApL) subjects. The conversion is different:

- "Attained with distinction" / A+: higher value
- "Attained" / A: lower value

Re-check the live conversion on jupas.edu.hk for the current cycle.

#### Category C (Other Languages) conversion

Category C subjects are Other Languages (e.g. French, German, Hindi, Japanese, Spanish, Urdu, etc.). The conversion is different from Category A and may include alternative grade scales (e.g. A1, B, C for French).

Re-check the live conversion on jupas.edu.hk for the current cycle.

#### Use of the conversion

The conversion is used by JUPAS for ranking candidates. The HKDSE grades still appear on the candidate's HKDSE certificate, but JUPAS uses the converted scores for admission decisions.

Candidates do not need to convert scores themselves; JUPAS does the conversion automatically when calculating admission scores.

#### Comparison with previous conversion

The 2025 entry conversion (5** = 8.5, 5* = 7, 5 = 5.5) is different from the pre-2025 conversion. Candidates should always use the current cycle's conversion table.

#### Common misconceptions (and the correction)

- "The JUPAS conversion is the same as the HKDSE grade." No — the JUPAS conversion is numeric; the HKDSE grade is alphanumeric (5**, 5*, 5, 4, 3, 2, 1).
- "5** = 9.0 in JUPAS." No — 5** = 8.5 in JUPAS (with effect from 2025 entry).
