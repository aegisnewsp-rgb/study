# Straight Lines

### 🟢 Lite — Quick Review (1h–1d)
> Rapid summary for last-minute revision before your exam.

A **straight line** is the locus of points (x, y) satisfying a first-degree equation in two variables, drawn on the Cartesian plane with a fixed **slope** between any two of its points. The **slope** m = (y₂ − y₁)/(x₂ − x₁) measures steepness and direction. The most-used forms are **slope-intercept** (y = mx + c), **point-slope** (y − y₁ = m(x − x₁)), **two-point** ((y − y₁)/(y₂ − y₁) = (x − x₁)/(x₂ − x₁)), and **general** (ax + by + c = 0, where slope = −a/b). The **distance** from (x₁, y₁) to ax + by + c = 0 is |ax₁ + by₁ + c|/√(a² + b²). **Parallel** lines share equal slopes; **perpendicular** lines satisfy m₁·m₂ = −1. Expect 3–5 MCQs in CUET UG testing these conversions and the angle formula tan θ = |(m₁ − m₂)/(1 + m₁m₂)|.

### 🟡 Standard — Regular Study (2d–2mo)
> Standard content for students with a few days to months.

#### Slope and Inclination
The **slope** m of a line joining (x₁, y₁) and (x₂, y₂) is the ratio of vertical change to horizontal change: m = (y₂ − y₁)/(x₂ − x₁), undefined for vertical lines (x = constant). The **angle of inclination** θ (0 ≤ θ < π) satisfies tan θ = m. A positive slope indicates an upward trend left-to-right; a negative slope indicates a downward trend.

#### Forms of a Line
- **Slope-intercept form:** y = mx + c, where c is the **y-intercept**.
- **Point-slope form:** y − y₁ = m(x − x₁) — fastest when one point and the slope are known.
- **Two-point form:** (y − y₁)/(y₂ − y₁) = (x − x₁)/(x₂ − x₁) — used when no slope is given.
- **Intercept form:** x/a + y/b = 1, where a, b are the x- and y-intercepts (both nonzero).
- **General form:** ax + by + c = 0, with slope = −a/b and y-intercept = −c/b.

#### Parallel and Perpendicular Lines
Two non-vertical lines with slopes m₁ and m₂ are **parallel** iff m₁ = m₂. A line parallel to ax + by + c = 0 can be written as ax + by + k = 0 (same coefficients for x and y, different constant). They are **perpendicular** iff m₁·m₂ = −1. A line perpendicular to ax + by + c = 0 has the form bx − ay + k = 0.

#### Angle Between Two Lines
tan θ = |(m₁ − m₂)/(1 + m₁m₂)|, provided 1 + m₁m₂ ≠ 0. When 1 + m₁m₂ = 0, the lines are perpendicular (θ = 90°). When m₁ = m₂, θ = 0° (parallel or coincident).

#### Distance of a Point from a Line
For point (x₁, y₁) and line ax + by + c = 0: d = |ax₁ + by₁ + c|/√(a² + b²). The sign of ax₁ + by₁ + c tells which side of the line the point lies on.

#### Collinearity Test
Three points (x₁, y₁), (x₂, y₂), (x₃, y₃) are **collinear** iff the area of the triangle they form is zero:
|x₁(y₂ − y₃) + x₂(y₃ − y₁) + x₃(y₁ − y₂)| = 0.

### 🔴 Extended — Deep Study (3mo+)
> Comprehensive coverage for students on a longer study timeline.

#### Deriving the General-Form Slope
Starting from y = mx + c, move everything to one side: mx − y + c = 0. Comparing with ax + by + c = 0 gives a = m, b = −1, so slope m = −a/b. Watch the sign carefully — a common trap is reading m = a/b from ax + by + c = 0.

#### Edge Cases in the Angle Formula
When 1 + m₁m₂ = 0, the tangent is undefined, signalling perpendicularity (θ = 90°). When m₁ = m₂, tan θ = 0, but this only means parallel — to rule out coincidence, check that the constants differ (i.e., the lines are not the same line scaled). CUET occasionally frames this as a trick: "parallel or coincident?" — solve both simultaneously to decide.

#### Worked Example
Find the equation of the line through (2, −3) perpendicular to 3x − 4y + 5 = 0.
The given line has slope 3/4, so the perpendicular slope is −4/3. Using point-slope form: y − (−3) = (−4/3)(x − 2) → y + 3 = (−4/3)(x − 2) → 3y + 9 = −4x + 8 → 4x + 3y + 1 = 0.

Verify using the perpendicular-form shortcut: a = 3, b = −4, so perpendicular is bx − ay + k = 0 → −4x − 3y + k = 0 → 4x + 3y − k = 0. Substituting (2, −3): 8 − 9 − k = 0 → k = −1, giving 4x + 3y + 1 = 0. ✓

#### Common Mistakes
- Forgetting the absolute value in the distance formula (distance is always nonnegative).
- Dividing by zero in slope = (y₂ − y₁)/(x₂ − x₁) when x₁ = x₂ (vertical line).
- Mixing up the intercept form x/a + y/b = 1 with x/a + y/b = −1.
- In CUET, sign errors when c is negative are the single largest source of dropped marks on this unit.

#### Practice Prompts
1. Find the distance between the parallel lines 3x + 4y − 7 = 0 and 3x + 4y + 3 = 0.
2. Show that the points A(1, 2), B(3, 4), C(7, 8) are collinear, and find the equation of the line through them.
