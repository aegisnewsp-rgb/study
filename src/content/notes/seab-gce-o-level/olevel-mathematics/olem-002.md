# Algebraic Expressions, Equations and Inequalities — O-Level Mathematics (4052) Notes

Algebraic Expressions, Equations and Inequalities is the largest single sub-strand in the O-Level Mathematics 4052 syllabus by marks. The sub-strand covers algebraic expressions, equations (linear and quadratic), simultaneous equations, and inequalities. Every O-Level Mathematics paper carries algebra items, and the highest-mark structured questions on Paper 2 are often built around algebraic manipulation. Mastery of this sub-strand is the single highest-return investment for a Sec 4 student.

### 🟢 Lite — Quick Review (1h–1d)

#### The seven facts every Sec 4 student needs

1. **Algebraic expressions** are combinations of numbers, letters and operators.
2. **Like terms** are terms with the same letters raised to the same powers; they can be added.
3. **The four operations with algebraic expressions** follow the same rules as for numbers.
4. **Factorisation** is the reverse of expansion: rewrite a polynomial as a product of factors.
5. **Quadratic equations** have the form ax² + bx + c = 0 with a ≠ 0; solved by factorisation, completing the square, or the quadratic formula.
6. **Simultaneous equations** are two equations in two unknowns; solved by substitution or elimination.
7. **Inequalities** use <, ≤, >, ≥; the rules of solving are similar to equations, but the inequality reverses when both sides are multiplied or divided by a negative number.

#### Key notations

- a² = a × a
- a² − b² = (a − b)(a + b) (difference of two squares)
- a³ − b³ = (a − b)(a² + ab + b²) (difference of two cubes)
- x = (−b ± √(b² − 4ac)) / 2a (quadratic formula)

### 🟡 Standard — Regular Study (2d–2mo)

#### Algebraic expressions

An algebraic expression is a combination of numbers, letters and operators. Letters stand for numbers; the value of the expression depends on the values of the letters.

**Collecting like terms**: 3x + 5x = 8x; 4x² − x² = 3x²; 2xy + 3yx = 5xy (the order of letters does not matter).

**Expanding a single bracket**: multiply every term inside by the term outside. 3(x + 4) = 3x + 12. −2(5y − 6) = −10y + 12. x(x − 7) = x² − 7x.

**Expanding two brackets**: multiply every term in the first bracket by every term in the second. (x + 3)(x + 5) = x² + 5x + 3x + 15 = x² + 8x + 15. (2x − 1)(3x + 4) = 6x² + 8x − 3x − 4 = 6x² + 5x − 4.

**Factorisation** is the reverse of expansion.

- Common factor first: 6x² + 9x = 3x(2x + 3).
- Difference of two squares: x² − 9 = (x − 3)(x + 3).
- Quadratic factorisation: x² + 5x + 6 = (x + 2)(x + 3).
- Quadratic with leading coefficient not 1: 2x² + 7x + 3 = (2x + 1)(x + 3).
- Grouping: ax + ay + bx + by = a(x + y) + b(x + y) = (x + y)(a + b).

#### Linear and quadratic equations

**Linear equations** are solved by inverse operations applied equally to both sides. 3x + 7 = 22 → 3x = 15 → x = 5. The general form is ax + b = 0 (or any equivalent).

**Equations with the variable on both sides**: collect the variable on one side. 5x + 3 = 2x + 18 → 3x = 15 → x = 5.

**Equations with brackets**: expand first, then collect. 3(x + 2) = 5x − 4 → 3x + 6 = 5x − 4 → 10 = 2x → x = 5.

**Quadratic equations** (form ax² + bx + c = 0) are solved by three methods:

1. **Factorisation** (when the discriminant b² − 4ac is a perfect square): x² − 5x + 6 = 0 → (x − 2)(x − 3) = 0 → x = 2 or x = 3.
2. **Completing the square**: x² + 6x + 5 = (x + 3)² − 9 + 5 = (x + 3)² − 4 → (x + 3)² = 4 → x + 3 = ±2 → x = −1 or x = −5.
3. **Quadratic formula**: x = (−b ± √(b² − 4ac)) / 2a. Works for every quadratic.

**The discriminant** b² − 4ac tells how many real roots the quadratic has:

- b² − 4ac > 0: two distinct real roots.
- b² − 4ac = 0: one repeated root (the parabola touches the x-axis at the vertex).
- b² − 4ac < 0: no real roots (the parabola does not cross the x-axis).

#### Simultaneous equations

Two equations in two unknowns are solved by substitution or elimination.

**Substitution**: solve one equation for one variable, then substitute into the other.

- y = 2x + 1 and y + x = 10.
- Substitute: (2x + 1) + x = 10 → 3x = 9 → x = 3.
- Back-substitute: y = 2(3) + 1 = 7.

**Elimination**: add or subtract the equations to cancel one variable.

- 2x + y = 10 and x − y = 2.
- Add: 3x = 12 → x = 4. Back-substitute: y = 2.

**Graphical solution**: plot both lines and read off the intersection point. The graph approach is useful when the equations are not linear (e.g. a line and a circle).

#### Inequalities

Inequalities use <, ≤, >, ≥. The rules of solving are similar to equations, with one critical difference: the inequality reverses when both sides are multiplied or divided by a negative number.

**Linear inequalities**: 3x − 5 < 7 → 3x < 12 → x < 4. (No reversal needed; dividing by 3.)

**Inequalities requiring reversal**: −2x > 6 → x < −3. (Reversal because of division by −2.)

**Quadratic inequalities**: solve the corresponding quadratic equation first, then test intervals.

- x² − 5x + 6 < 0 → (x − 2)(x − 3) < 0 → 2 < x < 3 (the inequality holds between the roots because the parabola opens upward and is below the x-axis there).

#### Algebraic fractions

Algebraic fractions are simplified, added, subtracted, multiplied and divided using the same rules as numerical fractions. The key step is factoring the numerator and denominator before simplifying.

- Simplify: (x² − 9) / (x + 3) = (x − 3)(x + 3) / (x + 3) = x − 3 (provided x ≠ −3).
- Add: 1 / (x + 1) + 1 / (x + 2) = [(x + 2) + (x + 1)] / [(x + 1)(x + 2)] = (2x + 3) / [(x + 1)(x + 2)].
- Multiply: (x / (x + 1)) × ((x + 1) / (x + 2)) = x / (x + 2).
- Divide: (x / (x + 1)) ÷ (x / (x + 2)) = (x / (x + 1)) × ((x + 2) / x) = (x + 2) / (x + 1) (provided x ≠ 0).

### 🔴 Deep — Long-Term Mastery (1mo–6mo)

#### Where Algebra appears across the papers

- **O-Level Mathematics 4052 Paper 1**: short structured items on algebraic manipulation, factorisation, and solution of linear and quadratic equations.
- **O-Level Mathematics 4052 Paper 2**: long structured items (5 to 10 marks) that combine algebraic manipulation with a real-world context — money, motion, area, etc.
- **Across both papers**: showing every algebraic step on a new line is the single biggest differentiator between a B-grade and an A-grade answer.

#### Common misconceptions (and the correction)

- "Move the 5 across the equals sign." The formal operation is "subtract 5 from both sides". Moving a term is shorthand; the underlying operation is the same inverse on both sides.
- "Expand (x + 3)² as x² + 9." It is x² + 6x + 9. Squaring a sum is not the same as summing the squares.
- "A quadratic equation always has two solutions." It can have 0, 1 or 2 real solutions, decided by the discriminant.
- "Multiplying or dividing by a negative number is the same as multiplying or dividing by a positive number." The inequality reverses when you multiply or divide by a negative number.
- "Factorising 2x² + 4x gives 2x(x + 2)." Correct. But factorising 2x² + 4x as x(2x + 4) is incomplete — the factor 2 should be removed from the bracket too.

#### Exam technique

- For algebra questions, show every algebraic step. Partial marks on 4- and 5-mark questions depend on visible working.
- For rearranging formulae, write the inverse operations in reverse order on a separate line each time.
- For simultaneous equations, state the substitution or elimination step explicitly.
- For inequality questions, mark the critical points on a number line and test intervals, rather than relying on algebraic intuition alone.
