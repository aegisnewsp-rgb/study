# Matching Features and Sentence Endings — IELTS Reading Notes

Matching Features and Matching Sentence Endings are two related IELTS Academic Reading question types. Matching Features asks you to match items (e.g. researchers, dates, theories) to a list of features. Matching Sentence Endings asks you to complete the second half of each sentence from a list of options. Both test careful reading and line-reference skills.

---

### 🟢 Lite — Quick Review (1h–1d)

#### Core facts in one pass

- **Matching Features:** match items to a list of features (e.g. researchers to theories, dates to events).
- **Matching Sentence Endings:** match the second half of each sentence from a list of options.
- **Format:** each option may be used once, more than once, or not at all.
- **Order of answers:** not strictly in order.
- **Common distractor:** some options may be plausible for more than one sentence.

#### Examiner traps

- Choosing an option that fits grammatically but not semantically.
- Missing the line reference and matching to the wrong part of the passage.

---

### 🟡 Standard — Regular Study (2d–2mo)

#### Matching Features strategy

1. Read the list of items and features — identify the keywords.
2. Skim the passage for the relevant section.
3. Match each item to the feature that best describes it.
4. Some features may not be used.

#### Matching Sentence Endings strategy

1. Read the first half of each sentence carefully — identify the subject and verb.
2. Read each option — identify the grammatical structure (does it start with a verb, noun, or clause).
3. Match each first-half to the option that completes the sentence grammatically and semantically.
4. Each option may be used once, more than once, or not at all.

---

### 🔴 Deep — Long-Term Mastery (1mo–6mo)

#### Where matching appears across IELTS Reading

Matching Features and Matching Sentence Endings appear in IELTS Academic Reading, often in one of the three passages. They test careful reading and are a strong band discriminator.

#### Common misconceptions (and the correction)

- "Each option is used once." Not necessarily — some options may be used more than once.
- "Match by grammar only." No — both grammar and meaning must align.
- "Skim the passage." No — matching requires careful reading, not just skimming.

#### Exam technique

- For Matching Features, scan the passage for the keywords in the items first.
- For Matching Sentence Endings, identify the verb tense and subject agreement in the first half.
- If an option fits grammatically but not semantically, it is wrong.
