# Passport to Advanced Math — Quadratics and Polynomials — SAT Math Notes

Quadratics and polynomials are part of the SAT Math Passport to Advanced Math content domain. The SAT tests solving quadratic equations by factoring, completing the square and the quadratic formula; the discriminant; polynomial arithmetic; the remainder theorem; and graphs of quadratic and polynomial functions.

> Verify the live SAT specifications on https://satsuite.collegeboard.org/ before planning revision.

---

### 🟢 Lite — Quick Review (1h–1d)

#### Core facts in one pass

- **Quadratic equation:** ax² + bx + c = 0.
- **Solving by factoring:** write as a(x - r)(x - s) = 0; solutions are x = r and x = s.
- **Quadratic formula:** x = (-b ± √(b² - 4ac)) / 2a.
- **Discriminant:** Δ = b² - 4ac; Δ > 0 (two distinct roots), Δ = 0 (one repeated), Δ < 0 (no real roots).
- **Vertex:** x = -b/2a, y = f(-b/2a).
- **Polynomial:** an expression of the form aₙxⁿ + aₙ₋₁xⁿ⁻¹ + ... + a₁x + a₀.
- **Remainder theorem:** when a polynomial P(x) is divided by (x - r), the remainder is P(r).

#### Examiner traps

- Treating the discriminant as the solution (it tells you the number of solutions, not the solutions themselves).
- Confusing vertex form with standard form.

### 🟡 Standard — Regular Study (2d–2mo)

#### Solving quadratics

Three equivalent methods:

1. **Factoring:** write ax² + bx + c = a(x - r)(x - s); solutions are x = r and x = s.
2. **Completing the square:** write a(x + b/2a)² + (c - b²/4a) = 0; solve for x.
3. **Quadratic formula:** x = (-b ± √(b² - 4ac)) / 2a.

#### Vertex and parabola

The vertex of y = ax² + bx + c is at x = -b/2a. The y-coordinate is y = f(-b/2a) = c - b²/4a.

The parabola opens up if a > 0 (minimum at vertex), down if a < 0 (maximum at vertex).

#### Polynomial operations

- **Addition:** combine like terms.
- **Multiplication:** distribute (use FOIL for binomials).
- **Division:** use long division or synthetic division.

The remainder theorem states that when P(x) is divided by (x - r), the remainder is P(r). If P(r) = 0, then r is a root.

### 🔴 Deep — Long-Term Mastery (1mo–6mo)

#### Where Quadratics and Polynomials appears across the SAT Math section

Quadratics and polynomials items appear throughout the SAT Math section. They test the candidate's ability to manipulate and solve polynomial equations.

#### Common misconceptions (and the correction)

- "The discriminant is the solution." No — it tells you the number of solutions.
- "All quadratics factor." No — only those with rational roots over the reals.

#### Exam technique

- For quadratic equations, choose the solving method (factoring, completing the square, formula) based on the coefficients.
- For vertex problems, use x = -b/2a.
- For polynomial division, use long division or synthetic division.

#### Step-by-step worked College Board test example

**Problem**:
Solve for x in the radical equation sqrt(2x + 15) = x + 6 and identify any extraneous roots.

**Solution**:
1. Square both sides of the equation:
   (sqrt(2x + 15))^2 = (x + 6)^2
   2x + 15 = x^2 + 12x + 36.
2. Rearrange into standard quadratic form:
   x^2 + 10x + 21 = 0.
3. Factor the quadratic:
   (x + 3)(x + 7) = 0 -> x = -3 or x = -7.
4. Test both candidate roots in the original radical equation:
   - For x = -3: sqrt(2(-3) + 15) = sqrt(9) = 3; right side is -3 + 6 = 3. Valid root!
   - For x = -7: sqrt(2(-7) + 15) = sqrt(1) = 1; right side is -7 + 6 = -1. Since 1 != -1, x = -7 is extraneous.
   - The unique real solution is x = -3.
