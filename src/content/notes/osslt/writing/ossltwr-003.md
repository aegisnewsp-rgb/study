# Developing a Main Idea with Supporting Details — OSSLT Writing

Developing a main idea with supporting details is the foundation of every successful OSSLT writing response. The EQAO OSSLT rubric scores "idea development" as one of the four dimensions, and a response that has a clear main idea and relevant supporting details scores higher than one that drifts or pads. This skill underlies both long-writing tasks and most short-writing tasks.

> Verify the live rubric and any in-year task changes on https://www.eqao.com/the-assessments/osslt/ before planning around the figures below.

---

### Lite — Quick Review (1h-1d)

#### What "developing a main idea" means on the OSSLT

- A **main idea** is the central claim of the response. In the News Report task, the main idea is the event being reported. In the Series-of-Paragraphs task, the main idea is the opinion being argued.
- **Supporting details** are the specific facts, examples, quotes, and reasons that make the main idea believable. They come from the supplied information source — never from the student's invention.
- A well-developed response has the main idea stated clearly (in the lead for News Report, in the first paragraph for Series-of-Paragraphs) and supporting details distributed across the body paragraphs.

#### How to test a main idea

A clear main idea passes three tests:

- It can be stated in one sentence.
- It is supported by at least two specific facts from the source.
- It is the central claim of the response — every body paragraph relates back to it.

If the response fails any of these tests, the main idea is not yet developed.

#### Examiner traps

- A main idea that is too broad. "Schools are important" is too broad to support with specific facts. "Schools should offer more hands-on science labs" is narrow enough.
- Supporting details that are repeated rather than developed. The same fact stated three times is not three reasons; it is one reason repeated.
- Supporting details that are not connected to the main idea. A fact that does not support the main idea is a distraction, not a detail.

### Standard — Regular Study (2d-2mo)

#### Strategy for developing the main idea

**Plan the main idea before writing.** Before drafting, write the main idea in one sentence. Then list the supporting details you will use to develop it. If you cannot list at least two details, the main idea is too narrow or the source is too thin — pick a different main idea.

**State the main idea in the first paragraph.** The first paragraph is the reader's first impression. State the main idea clearly in the first sentence, then preview the supporting details in the rest of the paragraph.

**Distribute the supporting details across the body paragraphs.** Each body paragraph should develop one supporting detail. Do not stack multiple details in one paragraph, and do not stretch one detail across multiple paragraphs.

**Connect each supporting detail back to the main idea.** A body paragraph that develops a supporting detail should end with a sentence that links the detail to the main idea. This is what the rubric calls "idea development."

**Avoid padding.** Padding is content that fills space without developing the main idea. Examples: repeating the main idea in different words, adding unrelated background, inserting generic statements. The rubric scores padding down.

#### Practice routine for idea development

- Take one EQAO sample task (either News Report or Series-of-Paragraphs). Plan the main idea in one sentence. List the supporting details you will use.
- Write the first paragraph (main idea + preview). Time yourself: under 5 minutes.
- Write two body paragraphs, each developing one supporting detail. Time yourself: under 10 minutes total.
- Read each body paragraph and ask: "does this paragraph develop the main idea?" If not, rewrite it.
- Total target: under 20 minutes for the long-writing task.

#### How this skill connects to the OSSLT reading tasks

The main idea of a reading selection is identified using the same logic: a clear, one-sentence statement of the central claim, supported by specific details in the selection. Practising main idea development in Writing reinforces Reading 1 work on Information Paragraph and News Report selections.

### Deep — Long-Term Mastery (1mo-6mo)

#### How idea development connects to the other OSSLT items

- **Reading 1** (explicit information) is needed to locate the supporting details in the source.
- **Reading 2** (inference) is needed to interpret the supporting details — what they imply, why the source included them.
- **Reading 3** (making connections) is useful for the wrap-up sentence, which often connects the main idea to the reader's experience or to a broader context.

#### Common errors and the correction

- **"I should pad the response with general statements."** The rubric scores padding down. A response with a clear main idea and two developed paragraphs scores higher than a response with five padded paragraphs.
- **"The supporting details can come from my own experience."** The supporting details must come from the supplied information source. Personal experience alone does not count.
- **"I do not need to restate the main idea."** Restating the main idea at the end of the response is what the rubric calls "closure." Without closure, the response feels unfinished.

#### Exam technique

- Read the source twice. Mark the supporting details.
- Plan the main idea in one sentence. List two or three supporting details.
- State the main idea in the first paragraph. Distribute the supporting details across the body paragraphs.
- Close with a sentence that restates the main idea in light of the supporting details.
- Re-read for spelling, grammar and punctuation. Use the platform's spell-check if available.
