# Computer

### 🟢 Lite — Quick Review (1h–1d)
> Rapid summary for last-minute revision before your exam.

A computer is an electronic device that accepts **input**, processes data through the **CPU (ALU + CU + Registers)**, stores results in **primary (RAM/ROM/Cache)** or **secondary (HDD/SSD)** memory, and produces **output**. SSC CGL asks factual recall from Class 8–10 NCERT-level basics.

#### Must-know facts

| Fact | Value |
|---|---|
| 1 Byte | 8 bits |
| 1 KB | 1024 Bytes (binary) |
| ASCII range | 0–127 (7-bit) |
| IPv4 size | 2³² ≈ 4.29 × 10⁹ addresses |
| 4th generation | Microprocessors (VLSI) |

#### High-yield shortcuts

- **Ctrl + C / V / X / Z / S** → Copy / Paste / Cut / Undo / Save
- **Alt + F4** → Close window; **Ctrl + Alt + Del** → Task Manager
- **Ctrl + B / I / U** → Bold / Italic / Underline in MS Word

### 🟡 Standard — Regular Study (2d–2mo)
> Standard content for students with a few days to months.

#### Generations of computers

The five generations map directly to the switching technology used.

| Generation | Period | Switching device | Key feature |
|---|---|---|---|
| 1st | 1940s | Vacuum tubes | ENIAC, huge size |
| 2nd | 1950s–60s | Transistors | Smaller, reliable |
| 3rd | 1960s–70s | Integrated Circuits (ICs) | Minicomputers |
| 4th | 1970s–present | Microprocessors / VLSI | PCs, laptops |
| 5th | Present | AI, parallel processing | Neural chips |

#### CPU and memory hierarchy

The **CPU** contains the **ALU** (arithmetic and logic operations), **CU** (decodes and executes instructions), and **registers** (fastest storage). Memory is tiered by speed: **Registers > Cache > RAM > Hard Disk**. RAM is **volatile** (loses data on power-off); ROM is **non-volatile** and stores boot instructions (BIOS/UEFI).

#### Software categories

- **System software**: Operating System, device drivers, utilities — runs the hardware.
- **Application software**: MS Word, Excel, Tally, browsers — solves user tasks.
- **Translators**: **Compiler** converts the whole program to machine code before execution (faster, e.g., C++); **Interpreter** converts line-by-line (slower, easier debugging, e.g., Python).

#### Input vs Output devices

> A **Plotter and Printer** are output devices, while **Scanner, MICR, OMR, and Barcode Reader** are input devices — MICR (Magnetic Ink Character Recognition) is used on bank cheques.

#### Number systems

**Binary (base-2)** uses 0–1; **Octal (base-8)** uses 0–7; **Decimal (base-10)** uses 0–9; **Hexadecimal (base-16)** uses 0–9 and A–F. Binary-to-decimal conversion uses Σ dᵢ × 2ⁱ, where dᵢ is the bit at position i counted from the right starting at 0.

### 🔴 Extended — Deep Study (3mo+)
> Comprehensive coverage for students on a longer study timeline.

#### Networking and internet protocols

A **LAN** covers a room or building (≤ few km); **MAN** covers a city; **WAN** spans countries — the Internet is the largest WAN. **TCP/IP** is the foundational protocol suite; **HTTP** transfers web pages (invented by Tim Berners-Lee, 1989, CERN); **HTTPS** adds SSL/TLS encryption; **SMTP** sends email; **FTP** transfers files; **DNS** resolves domain names to IP addresses.

> **WWW is a service running on the Internet, not the Internet itself** — the Internet is the global TCP/IP network, while the WWW (also Tim Berners-Lee, 1989) is a hypertext system accessed via browsers.

#### Malware distinctions

| Malware | Spread mechanism |
|---|---|
| Virus | Attaches to a host file; needs user action |
| Worm | Self-replicates across networks autonomously |
| Trojan | Disguised as legitimate software |

#### IPv4 vs IPv6

**IPv4** uses **32 bits** giving ≈ 4.29 × 10⁹ addresses (exhausted by 2025 in practice). **IPv6** uses **128 bits** giving 3.4 × 10³⁸ addresses, written as eight colon-separated 16-bit hex blocks (e.g., `2001:0db8:85a3::8a2e:0370:7334`).

#### Practice prompts

1. A file of 8 MB is downloaded in 16 seconds over a 4 Mbps link. Given 1 MB = 1024 KB and 1 KB = 1024 Bytes, calculate the actual transfer rate in Mbps and state whether the link is fully utilised. (Answer key: file = 8 × 1024 × 1024 × 8 = 67,108,864 bits; rate = 67,108,864 / 16 ≈ 4.19 Mbps, slightly above the 4 Mbps link.)
2. Match each item to its generation: (a) ENIAC, (b) IBM PC, (c) Intel 4004 microprocessor, (d) AI chip — and justify why microprocessors are placed in the 4th, not the 3rd, generation.
