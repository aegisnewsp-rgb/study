# Apply algebraic methods in solving problems (91261) — NCEA Level 2 Mathematics Notes

Achievement Standard 91261 is one of three external NCEA Level 2 Mathematics standards, carrying 4 credits and assessed by an end-of-year NZQA examination. The standard covers manipulation of algebraic expressions, expanding and factorising, solving linear and quadratic equations, simultaneous equations, and exponential equations. The algebra here underpins the Level 2 calculus standard 91262 and the Level 3 calculus standards 91578-91579.

> Verify the live assessment specification on https://www.nzqa.govt.nz/nqfdocs/ncea-resource/specifications/2026/91261-spc-2026.pdf before planning revision around the figures below.

### 🟢 Lite — Quick Review (1h–1d)

#### Core facts in one pass

- **4 credits**, external NZQA examination at the end of Year 12.
- Topics: expanding and factorising, algebraic fractions, quadratic equations (factorising, completing the square, quadratic formula), simultaneous equations (substitution and elimination), exponential equations, simple rational equations.
- **Merit** requires relational thinking — choosing the most efficient method for the given equation.
- **Excellence** requires extended abstract thinking — generalising algebraic patterns, connecting different methods.

#### Examiner traps

- Sign errors when expanding (especially with negative brackets).
- Dividing by zero when solving rational equations — check the domain.
- Forgetting the ± when taking a square root (x² = 9 has solutions x = 3 AND x = −3).
- Stopping at one solution when a quadratic has two.

### 🟡 Standard — Regular Study (2d–2mo)

#### Expanding

Distribute each term in the first bracket across the second:

(a + b)(c + d) = ac + ad + bc + bd

Special cases:

- (a + b)² = a² + 2ab + b² (perfect square)
- (a − b)² = a² − 2ab + b²
- (a + b)(a − b) = a² − b² (difference of squares)

#### Factorising

Reverse the expansion. Common techniques:

- **Common factor:** 2x² + 4x = 2x(x + 2).
- **Difference of squares:** x² − 9 = (x − 3)(x + 3).
- **Trinomial:** x² + 5x + 6 = (x + 2)(x + 3). Look for two numbers that multiply to c and add to b.
- **Grouping:** x³ + 2x² + 3x + 6 = x²(x + 2) + 3(x + 2) = (x² + 3)(x + 2).

#### Quadratic equations

The standard form is ax² + bx + c = 0, where a ≠ 0.

Three methods to solve:

1. **Factorising** (when factors are obvious): x² − 5x + 6 = 0 → (x − 2)(x − 3) = 0 → x = 2 or x = 3.
2. **Completing the square**: x² + bx + c = 0 → (x + b/2)² = (b/2)² − c → x = −b/2 ± √((b/2)² − c).
3. **Quadratic formula**: x = (−b ± √(b² − 4ac)) / (2a).

The discriminant is b² − 4ac:

- b² − 4ac > 0: two distinct real roots.
- b² − 4ac = 0: one repeated real root.
- b² − 4ac < 0: no real roots (two complex roots).

#### Simultaneous equations

**Substitution method:**

1. Solve one equation for one variable.
2. Substitute into the other equation.
3. Solve for the remaining variable.
4. Substitute back to find the first variable.

**Elimination method:**

1. Multiply one or both equations to make the coefficients of one variable match in magnitude.
2. Add or subtract to eliminate that variable.
3. Solve for the remaining variable.
4. Substitute back.

For nonlinear systems (one linear, one quadratic), use substitution.

#### Exponential equations

For a^x = b:

x = log(b) / log(a)

Or rewrite both sides with the same base if possible (e.g., 2^x = 8 → 2^x = 2³ → x = 3).

#### Algebraic fractions

Simplify, add, subtract, multiply, divide. To add or subtract, find a common denominator first. To divide, flip the second fraction and multiply.

Watch for domain restrictions (the denominator cannot be zero).

### 🔴 Deep — Long-Term Mastery (1mo–6mo)

#### Method selection heuristic

For a quadratic equation, choose the method based on the form:

- **Easy factors visible?** Factorise. Fastest when it works.
- **Coefficient of x² is 1 and the constant is small?** Try factorising first.
- **Coefficient of x² is not 1?** Quadratic formula is usually faster.
- **Need exact surd form?** Complete the square.

For a system of equations:

- **One variable already isolated?** Use substitution.
- **Coefficients match after a simple multiplication?** Use elimination.

#### Connecting methods

The Excellence move is showing how the three quadratic methods agree:

- Factorising produces (x − p)(x − q) = 0, so x = p or x = q.
- Completing the square produces x = −b/2 ± √(b²/4 − ac), which simplifies to the quadratic formula.
- The quadratic formula gives the same roots as factorising but works for any coefficients.

For exponential equations, the connection is: log is the inverse of exponentiation. So 2^x = 8 becomes x = log_2(8) = 3 because log is asking "2 to what power equals 8?"

#### Common misconceptions (and the correction)

- "Factorising always works for quadratics." It works when the discriminant is a perfect square; otherwise use the quadratic formula or completing the square.
- "Negative square root is invalid." x² = 9 has x = ±3; both are real solutions.
- "Substitution and elimination give different answers." They shouldn't — they are different paths to the same solution. If the answers differ, there is an arithmetic error.
- "Log is only for base 10." No — log is for any base. log_2, log_e (ln), log_10 are all logs with different bases.
