# Para Completion & Assertion

### 🟢 Lite — Quick Review (1h–1d)
> Rapid summary for last-minute revision before your exam.

**Para Completion** tests whether you can fill one or more blanks in a paragraph so the result reads as a coherent passage. **Assertion–Reason** asks you to judge two linked statements: an Assertion (a claim) and a Reason (a justification), and then decide whether the Reason correctly explains the Assertion.

- Scan 2–3 sentences **before and after** the blank before picking an option; tone, tense, and theme must match.
- Eliminate any choice that breaks the **pronoun–antecedent chain** or reverses cause–effect.
- For Assertion–Reason, evaluate in **three sub-steps**: Assertion true/false → Reason true/false → Reason explains Assertion?
- Standard MAT answer codes: (A) Both true, Reason explains; (B) Both true, Reason does not explain; (C) A true, R false; (D) A false, R true; (E) Both false.

> 💡 **High-Yield Memory Hook:** **A-R-E-3** — Assertion → Reason → Explanation link, three independent checks.
> Pronoun rule: **PAPS** — Person, Antecedent, Person, Singular/plural must match.

### 🟡 Standard — Regular Study (2d–2mo)
> Standard content for students with a few days to months.

#### Core Mechanism in Para Completion
A paragraph is a **cohesive unit**, not a stack of independent sentences. Each blank sits inside a **discourse frame** carried by connectives (`however`, `therefore`, `moreover`, `consequently`, `yet`) and by a **reference chain** (pronouns → antecedents). Your job is to extend the chain without snapping it.

#### Core Mechanism in Assertion–Reason
Treat it as a **two-axis classification**: (i) independent truth values of A and R, (ii) the causal/logical link "R is the correct explanation of A". Only one option survives both axes simultaneously.

#### Para Completion vs Assertion–Reason vs Inference

| Feature | Para Completion | Assertion–Reason | Inference |
|---|---|---|---|
| Input | A paragraph with blanks | Two statements (A and R) | A short passage + conclusion |
| Task | Choose the option that fits the discourse frame | Judge truth + link | Pick the logically warranted conclusion |
| What to test | Tone, tense, pronoun chain, causality | Validity of A, validity of R, explanatory link | Whether the conclusion must follow, only can follow, or does not follow |
| Common error | Locally correct, globally off | Marking true but ignoring the causal link | Confusing *inference* with *implication* |
| Best strategy | Read 2–3 sentences on each side | Three-step A.R.E. check | Diagram premise → conclusion, then test necessity |

#### Step-by-Step Resolution Protocol
1. **Read the paragraph once** for macro-theme; identify the author's stance (supportive / critical / neutral).
2. **Locate discourse markers** around the blank (`although`, `despite`, `hence`).
3. **Match pronoun–antecedent** in every candidate sentence; reject mismatches immediately.
4. **For Assertion–Reason**: classify A independently, classify R independently, then check the explanatory link.
5. **Choose the option** that satisfies *all* the constraints — grammar, register, logic.

#### 🎯 Exam-Level Worked Problem
**Question:** *Assertion (A):* AIMA-MAT deducts 0.25 marks per wrong MCQ under the Computer-Based Test pattern. *Reason (R):* Negative marking discourages random guessing and improves the validity of percentile scores. Which option is correct?
(a) Both A and R are true and R is the correct explanation of A 
(b) Both A and R are true but R is NOT the correct explanation of A 
(c) A is true but R is false 
(d) A is false but R is true 
(e) Both A and R are false 

#### Solution:
- Step 1 — *Is A true?* Yes, the AIMA MAT Information Bulletin lists **−0.25 mark** per incorrect response in both IBT and CBT modes.
- Step 2 — *Is R true?* Yes, negative marking is a standard psychometric device to discourage random attempts and stabilise percentile ranks.
- Step 3 — *Does R correctly explain A?* No. The **reason** AIMA imposes −0.25 is score-validity and rank-stability; the *purpose of negative marking* and the *specific punitive rate* are linked only by convention, not by logical necessity. A 0.25 rate can co-exist with a different rationale (exam-design symmetry with +1) just as easily.
- Therefore the correct code is **(b)**.

> ⚠️ **Examiner Trap:** Candidates see two plausible truths and reflex-mark option (a). The trap exploits exactly this — they skip the *third* A.R.E. sub-step. Always ask: "Would R have to be true **specifically because** A is true?" If not, downgrade from (a) to (b).

### 🔴 Extended — Deep Study (3mo+)
> Comprehensive coverage for students on a longer study timeline.

#### Edge Cases That Decide the Top Percentile
- **Triple blanks** in MAT Para Completion force a cross-dependency: the first blank constrains vocabulary for the second, which then fixes the register of the third. Solve them in **left-to-right, top-to-bottom** order, never by intuition.
- **Negation pivots** (`although`, `despite`, `however`, `rather than`) flip what comes next. Students match the **opposite** polarity to the pivot, which is the single most common Para Completion error in MAT retests.
- **Assertion–Reason independence rule**: a Reason can be a true statement and still *fail* to explain the Assertion if it talks about a different cause, a wider cause, or a consequence rather than a cause.
- **Reference-chain breaks**: a sentence can grammatically accept any pronoun, but only one antecedent is logically alive (the most recent, plausible, same-gender/same-number noun).

| Trap | What it Sounds Like | Why It Fails | Fix |
|---|---|---|---|
| "Locally true" choice | Fits the sentence around the blank | Breaks macro-theme or register | Re-read 2 sentences upstream |
| Negation pivot missed | Continuation agrees with prior clause | Pivot demanded contrast | Mark every `although/yet/however` before reading the blank |
| A-R true=true assumed | Both statements factual | Explanatory link untested | Run the third A.R.E. check |
| Implication ≠ Inference | "This passage implies X" taken as "must be true" | Implication = hinted; Inference = warranted | Distinguish *can follow* vs *must follow* |
| Register clash | Formal academic option vs informal passage | Voice mismatch | Note first sentence's register first |

#### Deduction vs Induction vs Assumption
- **Deduction**: conclusion *must* follow from premises. Used in Assertion–Reason whenever R is presented as logical proof of A.
- **Induction**: conclusion *probably* follows from observed cases. MAT rarely tests pure induction in Para Completion, but RC passages in many papers do.
- **Assumption**: an *unstated* premise the author needs for the argument to hold. Hidden assumptions are the usual culprit behind "Assertion false, Reason true" code (d).

#### How MAT Tests This Cluster
MAT's Language Comprehension contributes approximately **3% of the composite score** (≈4–6 questions per paper). Para Completion appears as single-, double-, and occasionally triple-blank passages, while Assertion–Reason in most keys comes bundled with Reading Comprehension rather than as standalone items in the CBT mode. Time target: **≤90 seconds per Para Completion item and ≤60 seconds per Assertion–Reason item** to stay within the 60-question / 120-minute envelope.

#### Advanced Practice Prompts
1. Take any 150-word MAT-style RC and design an Assertion–Reason pair where A is **false** but R is **true**, then justify which option code applies.
2. Construct a triple-blank Para Completion in which the first blank requires a *contrast marker*, the second requires a *noun phrase* locked by the first, and the third requires a *verb* locked by the second. Solve it backwards to test your dependency logic.
